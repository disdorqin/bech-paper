## 0. 设计目标（一句话 + 三个约束）

> 在**冻结基座点预测**之上，构建一个即插即用的校正头：以**基座残差**为对象做**有符号双尾**事件感应，在**极端事件集**上以**分布无关、有限样本**的方式保证校正**不劣于基座**，并在此前提下最大化极端期尾部/经济收益；跨市场时通过**市场条件校准层**显式消费各市场价格规则。

三个硬约束（对应 v3 必须守住的红线）：
1. **模型无关**：不触碰基座内部；对基座的全部假设 = 输出点预测 + 可回算滚动 OOS 残差（+ 可选特征对齐）。
2. **保证诚实**：保证是"**不劣**"（non-degradation），不是"更好"；经济收益是**实证**结果，不是保证。
3. **规则显式**：市场规则（价格下限/上限、是否负价、结算机制、颗粒度）作为**先验进入阈值与可行性约束**，不作为普通特征。

## 1. 数学符号与问题设定

| 符号 | 含义 |
|---|---|
| $$t$$ | 时间下标（市场颗粒度：山东/山西 15min 或 1h，EPEX 1h，NEM 5min） |
| $$x_t \in \mathbb{R}^d$$ | 原始特征（负荷、新能源出力、日前自相关特征等） |
| $$f_\theta$$ | 冻结基座预测器（AR/Linear / MLP / Transformer / STGNN） |
| $$\hat{y}_t^{0} = f_\theta(x_t)$$ | 基座点预测 |
| $$r_t = y_t - \hat{y}_t^{0}$$ | 基座残差 |
| $$R_t = (r_{t-w}, \ldots, r_{t-1})$$ | 滚动残差窗口（供感应/校准使用） |
| $$M = (L_m, U_m, \mathrm{neg}_m, n_m, \mathrm{settle}_m)$$ | 市场配置：价格下限、上限、是否启用负价、颗粒度、结算机制 |
| $$E^{-} = \{t : y_t \le L_m\}$$, $$E^{+} = \{t : y_t \ge U_m\}$$ | 极端事件集（**外生、按市场规则定义**，非按模型预测） |
| $$E = E^{-} \cup E^{+}$$ | 极端事件全集 |
| $$G_t \in \{-, 0, +\}$$ | 三态感应信号（负极 / 正常 / 正极） |
| $$a_t \in \{0, \lambda, 1\}$$ | 修补动作：回退 / 缩减 / 完整修补 |
| $$\hat{\delta}_t$$ | 感应头估计的（有符号）修正量 |
| $$\hat{y}_t^{(a)} = \hat{y}_t^{0} + a_t \hat{\delta}_t$$ | 校正后预测 |
| $$\ell(y, \hat{y})$$ | 误差损失（MAE 为主；极端期可换非对称损失） |
| $$s_t(a) = \ell(y_t, \hat{y}_t^{0} + a \hat{\delta}_t) - \ell(y_t, \hat{y}_t^{0})$$ | **相对不校正的增量损失（counterfactual excess loss）**——全文风险对象 |

**关键设定（与既有文献的差异在此）：** 事件集 $$E$$ 用**市场规则**定义（$$y_t \le L_m$$ 或 $$y_t \ge U_m$$），而不是用感应头预测定义。这使校准集**外生**于模块——避开"selection-conditional"问题（见 §7 不足 #2），也直接兑现"规则显式消费"。

## 2. 总体架构与数据流

```
   冻结基座 f_θ ──点预测 ŷ⁰_t ──┐
                                ▼
 X_t ──► 模块0 残差结构门控 ──►  [结构上下文(可选)模块1: 图/关系先验 h_t]
                                    │
 R_t ──► 模块2 极端感应头 ────────►  (p⁻_t, p⁺_t, δ̂⁻_t, δ̂⁺_t, G_t)
            │  ↑                         │
   M(市场规则) ┘  └──► 模块3 预算化修补器 ◄── 市场条件校准层 MCCL(§6)
                                │   a_t ∈ {0, λ, 1}
                                ▼
                     ŷ_t^(a) = ŷ⁰_t + a_t·δ̂_t   (经 [L_m, U_m] clamp)
```

**四模块分工（含模块 0 为新增）：**
- **模块 0（新增）残差结构门控**：先验判定"残差里还有没有可纠结构"；没有就 `a≡0`。回答 Q1（模型无关边界）。
- **模块 1（可选）结构上下文**：v1 的"图结构"降级为可选编码器，只在残差结构检验显著时启用。回答阶段二"图换皮"批判。
- **模块 2 极端感应头（核心）**：有符号双尾残差混合（occurrence–magnitude 作用在残差上）+ 三态信号。回答 Q3（负值独到性）。
- **模块 3 预算化修补器（核心）**：counterfactual excess loss + tail-conditional 非降级保证 + 三档动作。回答 Q4（措辞与保证）。
- **MCCL（贯穿）市场条件校准层**：分桶 + 收缩 + 规则先验 + 在线更新。回答 Q2（市场迁移）。

## 3. 模块 0 — 残差结构门控（Residual-Structure Gate）

**动机**：阶段二/三已确认——基座若已捕获全部可纠结构（如 STGNN 自带时空依赖），残差近似白噪声，任何校正只是加噪（[CoRel, ICML 2025](https://arxiv.org/abs/2502.09443) 已观察到该现象；图信号残差白化检验提供诊断工具，[Polimi](https://re.public.polimi.it/bitstream/11311/1233899/1/2204.11135.pdf)）。"模型无关"不等于"对所有基座都有效益"，必须把**效益∝残差结构**写进架构。

**检验统计量（Ljung–Box，单序列版）**：

$$
Q = n(n+2)\sum_{k=1}^{h}\frac{\hat{\rho}_k^2}{n-k}
$$

其中 $$\hat{\rho}_k$$ 为滚动 OOS 残差在滞后 k 的样本自相关，n 为窗长，h 为检验滞后阶数。**门控判据**：若 $$Q \le \chi^2_{h}(1-\nu)$$（在水平 $$\nu$$ 上不拒绝白噪声原假设），则残差无可纠结构，**强制 $$a_t = 0$$**。对多元/图序列可用图信号白化检验替代。

**该门的三个用途**：
1. **机制性降级**：给出"哪些基座下模块不激活"的可验证答案（多基座消融时出示"残差结构强度 × 校正增益"散点，增益应单调于结构强度）。
2. **防复审回归**：这是 v1"图换皮"批判的正式回应——图模块只在结构检验显著时启用。
3. **对"模型无关"主张的诚实边界**：贡献句写为"在残差保留结构的基座上有效"，而非"所有基座"。

**现有不足（§7 不足 #1）**：门是"先验测试后校正"，测试本身有统计功效问题（n 小、h 选择、多重测试）——门本身不提供有限样本保证，只提供启发式保护。

## 4. 模块 1 — 结构上下文（可选，Structural Context）

**对象**：特征矩阵 $$X \in \mathbb{R}^{T \times d}$$、预测列 $$\hat{y}^{0}$$、（可选）残差窗口。构建关系图 $$G = (V, E, A)$$：
- 节点：$$d$$ 个特征节点 ∪ 预测节点 $$p$$；
- 边权：统计相关 / 偏相关 / Granger 领先-滞后 / Attention 权重（选一或组合），阈值化后得到邻接矩阵 $$A \in \mathbb{R}^{(d+1)\times(d+1)}$$；
- 预测列节点的边权：$$A_{ip} = |\rho(X_i, \hat{y}^{0})|$$（v1 的"预测列作节点"在此保留为**可消融项**，不作为贡献）。

**编码**：$$h_t = \mathrm{GNN}(X_t, A)$$ 或轻量 Attention 读出，作为感应头的额外输入（可选拼接）。

**启用判据**：仅当模块 0 的残差结构检验显著且 $$h_t$$ 在验证集上带来极端条件误差改善时才启用（stage-2 结论：图可折叠进校正器，[CRC](https://arxiv.org/abs/2512.22428) 已证明先验邻接矩阵可直接服务校正器；[CoRel](https://arxiv.org/abs/2502.09443) 已证明残差上图可做后处理——故本模块**唯一合理定位是"可选增强"**）。

**公式化的必要性检验**：启用仅当

$$
\frac{\mathrm{MSE}_E\big(\hat{y}^{0}+S(x_t, h_t, \cdot)\big) - \mathrm{MSE}_E\big(\hat{y}^{0}+S(x_t, \cdot)\big)}{\mathrm{MSE}_E\big(\hat{y}^{0}\big)} < -c_{\rm enable}
$$

即图上下文让极端条件误差下降超过阈值 $$c_{\rm enable}$$（可消融）。

**现有不足（§7 不足 #3）**：图是**构造启发式**（相关/因果/注意力）而非端到端学习的结构；"预测列作节点"的信息增益在经验上常可忽略（与直接拼接 $$\hat{y}^{0}$$ 到特征等价），价值有限。

## 5. 模块 2 — 极端感应头（Signed Two-Tailed Residual Mixture）

**核心思想**：把 **occurrence–magnitude（两段式）分解作用在基座残差上**（而非价格本身），输出有符号双尾残差状态与条件修正量——这是与"价格空间两段式负价预测"（[Flinders ICCE26](https://researchnow.flinders.edu.au/en/publications/a-hybrid-classification-regression-method-for-forecasting-negativ/)、[Loizidis AE25](https://www.sciencedirect.com/science/article/abs/pii/S0306261925007433)、[TSEP](https://www.sciencedirect.com/science/article/abs/pii/S0378779621003977)）及"价格空间 spread 双尾"（[Trading Electrons](https://arxiv.org/abs/2601.05085)）的差异所在。

### 5.1 事件定义（外生、市场自适应）

$$
Z_t^{-} = \mathbf{1}\{y_t \le L_m\}, \qquad Z_t^{+} = \mathbf{1}\{y_t \ge U_m\}
$$

- 山东（启用负价，下限 −80/−100 元/MWh，[中国储能网](https://www.escn.com.cn/news/show-2255103.html)）：$$L_m = -80$$（一级/申报）——"−"态 = 负价时段。
- 山西（**不设负价，现货价格下限 0 元/MWh**，[国网山西](http://www.sx.sgcc.com.cn/articles/202408/a1159881.html)）：$$L_m = 0$$ 且 $$\mathrm{neg}_m=\mathrm{false}$$ → "−"态自动退化为"**近零/极低残差态**"（$$y_t \le \gamma_m$$，$$\gamma_m$$ 为市场校准的低价阈值）。**这是 MCCL 规则表消费的试金石案例**：模块必须能表达"该市场无负价"，否则山西验证直接失败。

### 5.2 Occurrence（双尾分类头）

$$
p_t^{-} = \sigma\big(f^{-}(x_t, h_t, R_t; M)\big), \qquad p_t^{+} = \sigma\big(f^{+}(x_t, h_t, R_t; M)\big)
$$

训练标签 $$\{Z_t^{-}, Z_t^{+}\}$$；损失用 **成本加权/焦点损失**（极端稀疏 + 漏报惩罚重——捕获率优先）：

$$
\mathcal{L}_{\rm occ} = -\sum_{t} \Big[ c^{-} Z_t^{-} \log p_t^{-} + (1-Z_t^{-}) \log(1-p_t^{-}) \Big] + \text{(对称项)} 
$$

其中漏报权重 $$c^{-}$$ 按捕获率目标设定（如负价捕获率 ≥ 目标值）。

### 5.3 Magnitude（条件修正量，地板/天花板感知）

对 $$E^{-}$$ 上样本，拟合下尾条件修正（可选 Tobit 截断或低分位回归 / EVT-GPD 平均超量）：

$$
\hat{\delta}_t^{-} = \max\Big( m^{-}(x_t, h_t, R_t; M),\; L_m - \hat{y}_t^{0} \Big)
$$

$$
\hat{\delta}_t^{+} = \min\Big( m^{+}(x_t, h_t, R_t; M),\; U_m - \hat{y}_t^{0} \Big)
$$

**可行性约束内建于修正量**：校正后的价格不会越过市场地板/天花板（$$L_m, U_m$$ 由 MCCL 提供）。

**两段式残差模型（本模块的形式化）**：

$$
r_t = Z_t^{-} m_t^{-} + Z_t^{+} m_t^{+} + \varepsilon_t
$$

**三态信号（感应→修补的接口）**：

$$
G_t = \begin{cases}
+ & p_t^{+} \ge \tau^{+} \text{ 且 } p_t^{+} \ge p_t^{-} \\
- & p_t^{-} \ge \tau^{-} \text{ 且 } p_t^{-} > p_t^{+} \\
0 & \text{否则}
\end{cases}
$$

阈值 $$\tau^{-}, \tau^{+}$$ 在市场校准子集上按捕获率目标标定（MCCL 第 1 步）。

**"−态"通用语义（写进论文的定义）**：$$G_t=-$$ ⟺ 残差落入**下尾极端**（$$r_t \le Q_{\tau^{-}}(r)$$ 或 $$y_t$$ 触碰市场地板），语义 = "该时点经济失配方向为价格过低/负值（供过于求或制度性下限触碰）"。把"负值"泛化为"**下尾极端 + 方向性经济失配**"，同一模块可迁移到负需求 / 风电预测负误差 / 电池 SoC 下限等负值序列——支撑跨域泛化主张。

**现有不足（§7 不足 #4、#5）**：感应头的**漏报直接等于"无收益"**（漏报 → $$G_t=0$$ → $$a_t=0$$ → 保护但不改善）；捕获率因此是经济收益的第一杠杆。感应头误差会传播到保证评估（若校准用感应头输出分桶，则出现选择偏差，见 §6/MCCL 的规避）。

## 6. 模块 3 — 预算化修补器 + 市场条件校准层 MCCL

### 6.1 风险对象：counterfactual excess loss

对固定动作 $$a$$：

$$
s_t(a) = \ell\big(y_t,\; \hat{y}_t^{0} + a\,\hat{\delta}_t\big) - \ell\big(y_t,\; \hat{y}_t^{0}\big)
$$

- $$s_t(0) \equiv 0$$；$$s_t(a) \le 0$$ 表示校正有净收益；$$s_t(a) > 0$$ 表示校正有害（harm）。
- 所有保证针对 $$\{s_t(a)\}_{t \in E}$$，即**极端事件集上、相对不校正**的增量损失。

### 6.2 Tail-conditional 非降级保证（有限样本、分布无关）

在极端校准子集 $$E_{\rm calib}$$ 上，取 excess loss 得分的分位数：

$$
\hat{q}_{\alpha}(a) = \mathrm{Quantile}\Big(\{s_t(a)\}_{t \in E_{\rm calib}},\; \frac{\lceil (|E_{\rm calib}|+1)(1-\alpha)\rceil}{|E_{\rm calib}|}\Big)
$$

在 $$E_{\rm calib}$$ 得分的可交换性（见 §7 不足 #1 的边界）下：

$$
P\big(s_{t_{\rm new}}(a) \le \hat{q}_{\alpha}(a)\big) \ge 1 - \alpha
$$

**非降级** ⇔ $$\hat{q}_{\alpha}(a) \le 0$$（极端集上以 ≥1−α 比例不劣于基座）。

### 6.3 动作选择（预算化、三档）

```
a_t^* = max { a ∈ {0, λ, 1} :
             q̂_α(a) ≤ 0            (tail-conditional 非降级)
        且   s̄_+(a) ≤ ε₀           (极端集上期望 harm 幅度受预算约束)
        且   正常期保护成立(§8-G1) }
```

其中 $$s̄_+(a) = \frac{1}{|E|}\sum_{t \in E} \max(s_t(a), 0)$$ 为**期望伤害幅度**，$$\varepsilon_0$$ 为预注册的 harm 预算。$$a$$ 取满足条件的最激进档（优先 $$a=1$$，其次 $$\lambda$$，否则 $$0$$）。$$\lambda$$ 与 $$\varepsilon_0$$ 在 MCCL 中按市场校准。

**与既有保证的差异（写成对照）**：
- 相对 [CRC](https://arxiv.org/abs/2512.22428)（逐点/验证级、大概率非降级 PAND）：本保证是**极端事件集上的条件保证**——CRC 是"全样本平均意义上的安全"，本模块是"模块真正激活的极端集上的安全"。两者不等价，CRC 更强（逐点）但覆盖全部时点；本保证更贴合"只在极端期校正"的用法。
- 相对 [COSA](https://iclr.cc/virtual/2026/poster/10010061)（学习型连续门控 $$g$$，无风险保证）：本模块是**带有限样本保证的离散动作**。
- 相对 [Conformal Policy Control](https://icml.cc/virtual/2026/poster/61296)（安全参考策略 + 共形校准决定攻击性，ICML 2026）：同源思想（安全参考 = 不校正），但**应用到电价校正策略 + 极端条件校准**。
- 相对 [action-conditional CP](https://arxiv.org/abs/2606.05551)（逐动作条件保证）：本模块保证的是"校正动作 a 在极端集上不劣于不校正"，动作条件 + 事件条件。

### 6.4 市场条件校准层 MCCL（贯穿三个模块的预算/阈值/上限）

四个组成（全部可在模块内实现）：

**(a) Mondrian 分桶（组条件）**：校准数据按 `市场 × 机制标签` 分组（机制标签 = 是否负价、结算类型、节点/系统价），每组独立取分位数：

$$
\hat{q}_{\alpha}^{(g)} = \mathrm{Quantile}\Big(\{s_t(a)\}_{t \in E_{\rm calib}^{(g)}},\; \frac{\lceil (n_g+1)(1-\alpha)\rceil}{n_g}\Big)
$$

获得**桶内条件**保证（组条件覆盖理论见 [MAPIE/Mondrian](http://contrib.scikit-learn.org/MAPIE/stable/theory/mondrian/)）。

**(b) 层次化收缩（应对稀疏极端样本）**：Mondrian 的已知缺陷是桶太小则失稳（<200 样本高危）。用 pooled 全局 + 每市场偏移：

$$
\tilde{q}^{(g)} = \omega_g\, \hat{q}^{(g)} + (1-\omega_g)\, \hat{q}^{({\rm all})}, \qquad \omega_g = \frac{n_g}{n_g + n_0}
$$

$$n_0$$ 为收缩强度超参。诚实代价：小桶的保证从"严格组条件"退化为"向全局收缩后的近似"——**这是条件性与样本量的本质权衡，必须写进论文**。

**(c) 规则先验（可行性约束，不当特征）**：
- 修正量 clamp：$$\hat{\delta}_t \leftarrow \mathrm{clamp}\big(\hat{\delta}_t,\; L_m - \hat{y}_t^{0},\; U_m - \hat{y}_t^{0}\big)$$；
- "−态"阈值取市场地板（山东 −80/山西 0/EPEX 负值下限）而非通用残差分位数；
- 规则表 $$M$$ 为**模块输入**（每市场一份配置），非硬编码。先例：Trading Electrons 用日前报价栈构建**结构性**价格影响模型（闭式 INC/DEC 解），证明"市场规则结构性消费"是被认可的做法（[arXiv 2601.05085](https://arxiv.org/abs/2601.05085)）。

**(d) 在线再校准（ACI 风格）**：市场规则/供需结构漂移时（山东 2025 年曾触发二级 −100 限价的连续低价时段），对覆盖/非降级指标做单参数在线更新：

$$
\alpha_{t+1} = \alpha_t + \gamma\big(\alpha - \mathrm{err}_t\big)
$$

保证长期覆盖频率（[ACI, NeurIPS 2021](https://papers.nips.cc/paper_files/paper/2021/hash/0d441de75945e5acbc865406fc9a2559-Abstract.html)）。诚实边界：在线更新恢复的是**长期覆盖频率**，不是重新给出有限样本条件保证。

## 7. 训练与推理算法（伪代码）

### 7.1 离线（每市场 × 每基座）

```
输入: OOS 预测 ŷ⁰_t, 真实 y_t, 特征 x_t, 市场配置 M
1.  r_t ← y_t − ŷ⁰_t；E⁻,E⁺ ← 按 M 的地板/天花板定义（外生）
2.  模块0: Q ← LjungBox(r)；若 Q ≤ χ²_h(1−ν) → 全局关闭校正，结束
3.  模块1(可选): 若启用判据(§4)成立 → 训练 GNN 得 h_t
4.  模块2: 训练 f⁻,f⁺(occurrence, 加权/焦点损失)；
          训练 m⁻,m⁺(magnitude, 仅在 E 样本上, 地板/天花板 aware)
5.  MCCL: 分组 E_calib^(g)；Mondrian 分位数 q̂^(g)_α；
          收缩 ω_g；设定 τ±, λ, ε₀, n₀, γ
6.  模块3: 对 a∈{0,λ,1} 算 q̂_α(a), s̄_+(a) → 确定动作决策表
输出: {f⁻,f⁺,m⁻,m⁺, 决策表, 规则表}
```

### 7.2 在线（逐时点）

```
for t:
  if 模块0 门关: a_t←0
  else:
    (p⁻,p⁺,δ̂⁻,δ̂⁺) ← 模块2(x_t, h_t, R_t; M)
    G_t ← 三态判定(τ±)
    if G_t==0: a_t←0
    else:
      a_t ← 决策表[G_t, 置信档]
      ŷ_t ← clamp(ŷ⁰_t + a_t·δ̂_t, L_m, U_m)
      校准账户更新: err_t ← 1{s_t(a_t) > q̂_α(a_t)}; α ← ACI 更新
```

## 8. 证据清单（实验设计要点，非实验章节）

**G1 正常期保护**：正常日（$$G_t=0$$ 占主导时段）上 校正 vs 基座 MAE 比值（期望 ≈1，受 $$a=0$$ 门控保护）＋ **误报率**（0 态被误判为 ± 态的比例 = 不必要校正率）。

**G2 极端期提升**：极端集上 条件误差（相对基座下降 X%）、负价捕获率（漏报/虚警）、非降级率（≥1−α 实证覆盖）、经济指标（度电套利 PnL 与 CVaR、最差 1% 小时平均误差）。经济指标带 Diebold–Mariano 检验或 bootstrap CI。

**G3 多基座**：AR-Linear / MLP / Transformer / STGNN 四族 × {模块开/关}，出示"残差结构强度 × 校正增益"散点（模块 0 门控的验证）。

**G4 多市场矩阵**：山东/山西/EPEX/NordPool/NEM × {模块开/关 × 基座×2}；**MCCL 消融**（去 MCCL 版的退化量）为必交证据。

**基线**：基座（上界为无校正）、CRC（同族校正头上限）、COSA、CQR（仅区间不校正，[NeurIPS 2019](https://nips.cc/virtual/2019/poster/13524)）、两段式分类-回归负价法。

## 9. 现有不足与开放问题（诚实声明，供交叉验证方攻击）

1. **可交换性边界**：tail-conditional 非降级保证依赖 $$E_{\rm calib}$$ 得分的（块）可交换性；电价残差自相关、机制突变，严格有限样本条件保证在现实市场不严格成立。**缓解**：块自举加权校准 / ACI 在线更新（恢复长期覆盖）；**诚实说法**：保证为"在（块）可交换校准子集上的有限样本保证 + 在线市场下的长期覆盖频率"，**不得写成无条件有限样本**。
2. **选择偏差**：若用感应头输出分桶校准，极端校准集与感应头共线 → selection-conditional 问题（[SCoRE 族](https://ui.adsabs.harvard.edu/abs/2026arXiv260324704B/abstract)）。**规避**：事件集 $$E$$ 由市场规则（$$y_t \le L_m$$）**外生**定义，感应头不参与分桶标签。
3. **图模块价值存疑**："预测列作节点"常与直接拼接等价；图是构造启发式非学习结构。**缓解**：降级为可选 + 启用判据消融 + 诚实报告（若无可测收益就砍掉）。
4. **漏报 = 无收益**：感应头漏报极端事件 → $$a_t=0$$ → 保护但不改善；捕获率是经济收益的第一杠杆，而捕获率无法由保证覆盖（保证只管"校正了不伤"，不管"该校正没校正"）。
5. **三档动作的离散化代价**：$$\{0,\lambda,1\}$$ 是最优连续门控的量化；对 $$\lambda$$ 的搜索会破坏保证（多重测试）——需 LTT/Bonferroni 校正，进一步保守化；或放弃搜索、按固定 $$\lambda$$ 预注册。
6. **误差保证 ≠ 经济保证**：$$s_t \le 0$$（误差不劣）不蕴含 PnL 不劣（效用非平滑、套利函数非 Lipschitz 于价格误差）。经济收益只能是实证。若要决策聚焦（[SPO+](https://arxiv.org/abs/1710.08005) 路线），会与"误差保证"冲突——v3 选择保住误差保证、经济做实证。
7. **极端集稀疏性 vs 条件性**：市场 × 机制分桶下，每桶极端样本可能 <<200（山东年负价 ~1330h，山西无负价只能退化为近零态）——条件性与样本量的权衡不可避免，收缩是唯一工程出路，但会稀释"严格组条件保证"。
8. **规则数据可得性**：规则表需准确、实时（山东二级 −100 限价、山西 0 元下限等会随细则修订漂移），配置错误直接污染阈值与可行性约束；工程上需要市场规则监控，这是额外负担。
9. **"−态"语义在不同市场的漂移**：山东=负价、山西=近零、EPEX=负值下限各异——"−态"的可比性定义需要一份跨市场语义映射表，否则跨域泛化主张难以统一。
