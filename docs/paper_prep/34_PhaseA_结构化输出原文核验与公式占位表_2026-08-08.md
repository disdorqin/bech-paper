## 3. Collision implications

1. **Event-level non-additive loss is not novel by itself.** The Ciliberto frameworks
   already cover broad structured losses and loss-aware decoding. A candidate must add
   a genuinely different object, not merely replace pointwise MAE with an episode loss.
2. **Absolute interval prediction is mature.** ActionFormer and Yuan directly predict
   start/end structure; DETR supplies the standard unordered-set plus matching reduction.
3. **Duration modeling is mature.** Rabiner's explicit-duration HMM is an old, direct
   collision for any claim based only on episode persistence.
4. **Edit scripts are mature.** LevT is the strongest collision: it learns insertion and
   deletion relative to an initial sequence using target-derived edit supervision.
5. **The remaining narrow distinction is compositional, not yet innovative:** a frozen
   numerical base, event-level edit/correction, continuous magnitude reconstruction, and
   selective base-relative harm control with exact no-action return. No verified source in
   this eight-paper set contains that whole conjunction, but absence from this small set is
   not evidence of a global literature gap.

## 4. Phase A decision

**Phase A source repair: PASS. Method novelty: still NOT ESTABLISHED.**

The only candidate allowed into the next collision analysis is:

> Base-relative correction of negative-price episodes under a non-additive event loss.

Its first attack must be an explicit reduction to:

`absolute interval/set prediction + residual/value regression + standard selective risk control`.

If that reduction preserves the candidate's learning target, inference operator, and claimed
guarantee without introducing a new non-standard property, the decision is **NO-GO** and the
project returns to Route E. No experiment is authorized by this Phase A pass.
