# BECH v6 算法创新重新发现审计

> 日期：2026-08-07
> 范围：冻结电价预测基座的后处理；本轮只检查能否形成不可替换的算法对象。
> 结论：**没有候选达到主算法创新门槛**。下列三项是最接近的候选和失败原因，不应直接写入贡献。

## 判定标准

候选必须同时满足：

1. 有明确的训练/推理算子或优化问题；
2. 不能还原为 selective risk、RCPS/LTT/e-process、普通投影、条件共形、特征工程或已有残差校正的换场景；
3. 至少有一个非平凡、可在两周内完成的命题；
4. 有明确的失败判据和最小实验。

本轮检索覆盖本地第二、三轮主题库，重点核对了 P1/P2/P3 全景、P3 30 篇后处理/价值对齐笔记、图结构近邻、条件共形、动态因果、负价/尖峰、行政边界和持续时间/事件聚集关键词。

## 候选 A：机制条件的日轨迹连续修补

### 算子

对冻结基座的一日预测向量 `b_{1:P}`，先由日前可得机制证据产生负尾/正尾状态得分 `s_{t,g}`，再求整段修补：

\[
\hat y_{1:P}^{\rm rep}
=\arg\min_{y\in\mathcal C}
\sum_t w_t\lvert y_t-b_t-d_t\rvert
 +\gamma\sum_{t=2}^{P}\lvert d_t-d_{t-1}\rvert
 +\eta\,N_{\rm switch}(d),
\]

其中 `C` 包含市场价格边界、预测的尾状态和最小持续时长约束。可用动态规划或 fused-lasso 求解，而不是逐点叠加 `delta_t`。

### 为什么看起来有空白

现有库中的 CAViaR-SE/X-flexForecast 建模尾部，RIGS-Refiner 做预测空间递归细化，电价预测文献做日内局部依赖；没有发现同一篇工作把**冻结基座的极端后处理**写成带持续时间约束的整段修补。

### 直接组合攻击

- `TV/fused-lasso` 轨迹平滑 + HMM/CRF 持续时间状态 + 残差校正：三者均为成熟结构化预测组件；
- RIGS-Refiner 已占冻结输出空间的递归修补位置；
- 约束集 `C` 中的 floor/cap 只是普通投影/可行集约束；
- 事件持续时间指标和 semi-Markov 解码不是新统计对象。

因此“整段修补”目前只是**结构化后处理的电价换场景**。

### 可证明命题

给定 `C` 非空且状态序列固定，动态规划可在有限 `P` 上求得全局最优路径；若 `C` 是闭凸集且没有 `N_switch` 离散项，投影算子是非扩张的。两条都属于标准优化/动态规划，不是新理论。

### 失败判据

- 相比逐点校正，持续时间算子不能显著改善 event-level duration、峰值误差和 worst-day harm；
- 去掉 TV 或 duration 约束后性能不降；
- 证明只能复述 fused-lasso/Viterbi 的标准最优性。

**裁决：淘汰，不进入主方法。**

## 候选 B：行政边界上的边界原子残差传输

### 算子

把市场真实价格视为边界原子加内部连续部分：

\[
Y=\pi_-\,\mathrm{floor}+\pi_+\,\mathrm{cap}
 +(1-\pi_--\pi_+)Y_{\rm int},
\]

对冻结预测 `b` 学习边界命中概率和内部残差的条件分位传输 `T_g`，最后输出

\[
\hat y=T_Z(b,Z),\qquad \hat y\in[\mathrm{floor},\mathrm{cap}].
\]

### 直接组合攻击

- `T_g` 是 Tobit/censored regression 或 hurdle model 的直接应用；
- 条件分位传输是 quantile mapping/optimal transport；
- 边界截断是 CRC/普通 clamp；
- 边界命中概率是分类头，不是新的决策对象。

它比简单 admin clamp 更完整，但仍是“删失分布 + 分位映射 + 投影”的领域组合。

### 可证明命题

若真实支持集确为 `[floor, cap]`，clamp 后预测保持可行；若 `T_g` 单调，则在一维 Wasserstein 距离下具有标准的单调传输性质。均为已有结果。

### 失败判据

- 边界原子分解相对普通 clamp/quantile mapping 无显著增益；
- 边界命中率过低导致原子头不可辨识；
- 理论只剩 Tobit 的一致性或投影的非扩张性。

**裁决：作为 C1 的可选实现，不作为算法创新。**

## 候选 C：残差可修复性证据（Repairability Gate）

### 算子

令冻结基座残差为 `e=Y-b`，对可用证据 `Z` 定义 MAE 下的 Bayes 修复增益：

\[
\Gamma(z)=\mathbb E[|e|\mid z]
 -\min_a\mathbb E[|e-a|\mid z]
=\mathbb E[|e|\mid z]
 -\mathbb E[|e-\operatorname{Med}(e\mid z)|\mid z].
\]

仅在估计的 `Gamma(z)` 超过预注册阈值时训练/启用校正头；若 `Gamma(z)=0`，任何只使用 `Z` 的后处理都不能改善条件 MAE。

### 直接组合攻击

- 条件中位数是 Koenker--Bassett 的 Bayes 最优解；
- `Gamma` 是条件 Bayes risk reduction/value-of-information；
- 阈值触发是 Elkan/Chow reject-option 或 selective correction；
- “残差白噪声则禁用”已经出现在项目旧稿的 residual-structure gate。

所以它是一个有用的**不可修复性诊断/激活准则**，但不是新算法对象。

### 可证明命题

在可积残差下，`Gamma(z)>=0`；`Gamma(z)=0` 意味着条件中位数为零时，任何 `Z`-可测常数修正都不能降低条件 MAE。该命题严格但属于标准 Bayes 决策论。

### 失败判据

- `Gamma` 门控与简单残差方差/白噪声门控性能无差；
- `Gamma` 估计误差在尾部使激活率不稳定；
- 论文无法证明它超出条件 Bayes 风险或 selective risk 的已有定义。

**裁决：保留为方法诊断性质，不作为主创新。**

## 其他已排除方向

| 方向 | 直接还原 |

| 条件共形极端闭环 | Mondrian/局部共形 + 残差校正 |

| 在线自适应校正 | ACI/Conformal PID/OCO/e-process |
| 尾部依赖图 | copula/tail-dependence graph + GNN |

## 最终结论与下一步

本轮**没有发现符合“非直接组合、两周可证明、可实现”的新算法候选**。A4 不应因为“动作自指功效”而复活；上述三项也不能包装成新的主算法。

最稳妥的研究路线是：

1. 把 BECH 收缩为“电价领域的结构化校正实例”，主张集中在已明确的校正级双尾不对称、市场规则边界和跨基座实证；或
2. 改换问题锚点，离开“冻结基座后处理”赛道，再进行新的算法发现。

在没有新的不可替换算法对象前，继续扩大图、证书或动作菜单只会增加组合攻击面，不建议开始大规模实现。
