## 0. 诚实结论(先行)

1. **第一轮"图在电价上只有3篇(GCGNet/NSTM/ERCOT)"的判定不充分,已过时。** 第四轮更广检索确认:**2024-2026 图+电价预测层已出现 10+ 篇**(PriceFM 时空基础模型 / MVFSTGNN / TSGT / TransGraph-Opt / 自适应时空卷积 / ASTGCN 电价变体 / NSTM 网络效应 / Yang-R-vine-STGNN 等),"图在电价预测上稀疏"不再成立。
2. **但"图在残差校正/事件层"仍基本是空白——前提是必须显式承认并划界三个最接近的先例**: ResCAL(CIKM'22,交通图残差校正)、COREL(2502.09443,图+共形+残差)、STOIC(2606.31804,图+能源+共形+残差表格化)。它们占据了"图×残差×即插即用/共形"的组合,但**无电价专用、无双尾事件节点化、无认证约束**。
3. **"图+尾部事件"有先例**(自适应可视性图尖峰预测、Hüsler-Reiss 极值图双尾网络、尾部 copula),故"无极端事件专用图"的说法需修正为"有尾部*估计*图,无尾部*校正*图"。
4. **结论: 图模块调研不充分→需补本轮清单;但"残差层双尾事件图+SCARR认证"的组合仍是真空白,且比第一轮判断更窄、更需要引用先例划界。**

## 2. 最接近 BECH 图模块的 3 个工作及其差异

BECH 图模块定位: **残差层事件图**(节点=被检测的双尾极端事件/残差,边=共享外生原因或机制先验,受 SCARR 认证约束,未认证即弃权)。

### 2.1 ResCAL(CIKM 2022, arXiv:2209.05406)—— 最接近的"图残差校正"先例
- **输入**: 交通网络每个路段的**历史预测误差** + **图信号**(路网邻接)。
- **结构**: 残差估计模块,估计未来误差 r̂,校正 ŷ ← ŷ + r̂;add-on 可接多种基座。
- **差异**:
  1. **领域不同**: 交通(路网节点语义天然存在),非电价;无负价/尖峰双尾概念。
  2. **节点是路段**,不是事件;图是全量邻接,非稀疏事件图。
  3. **无认证**: 无"校正不劣于基座"的统计保证,可任意加噪;BECH 用 SCARR 两层证书约束。
  4. **无极端特化**: 目标是一般误差的实时修正,非尾部条件修正。
- **引用方式**: 承认"图残差校正"在交通已被 ResCAL 提出,定位差异在**电价双尾事件节点化 + 认证式零退化**。

### 2.2 COREL(2502.09443, "Relational Conformal Prediction for Correlated Time Series", ICML'25)
- **输入**: 基座预测残差 + 可学习节点嵌入,ResQP(Relational Quantile Predictor)= 时间-空间 STGNN 残差分位数回归。
- **输出**: 预测区间(共形),非点校正。
- **差异**:
  1. 做**区间预测**,BECH 做**点校正**——目标不同。
  2. 图节点=时序变量(如各能源/区域),非极端事件。
  3. 无"校正头"概念: 它不修改点预测,只给覆盖区间;BECH 的 ŷ_bech = ŷ_base + λ·δ 是点级修正。
  4. 无弃权/无双尾非对称。
- **引用方式**: 支撑"图×残差×共形"组合已被探索,强调 BECH 把图从"不确定性量化"转到"带认证的点校正"。

### 2.3 STOIC(2606.31804, "Relational and Sequential Conformal Inference for Energy Time Series over Graphs via Foundation Models")
- **输入**: STGNN 点预测 → 把时空残差改写成表格 → 表格基础模型零样本共形校准。
- **输出**: 预测区间。
- **差异**:
  1. 直接命中"图+能源时序+残差后处理+共形"交集——**但做区间,不做点校正,不极端特化**。
  2. 图节点=能源网络节点(电力/区域供热),非事件。
  3. 无尾部条件覆盖,无经济认证。
- **引用方式**: 这是最需要划界的——STOIC 已占"能源×图×残差×共形区间";BECH 占的是"电价×图×残差×**点校正**×双尾非对称×认证"。

**小结**: 三先例证明"图 + 残差 + 模型无关/即插即用"大方向已有人走,但全部落在**区间预测**或**非电价领域**;BECH 的独特组合(电价日前 + 残差层事件图 + 双尾非对称 + 认证式零退化点校正)未被占据。

## 3. "图+残差校正"与"图+尾部事件"先例证据

### 3.1 图+残差校正(已存在,但非电价)
- ResCAL(2209.05406): "residual estimation module ... add-on module to existing traffic forecasting models",估计未来误差用"previous errors and graph signals"(摘要原话)——**确凿的图残差校正先例**。
- Jia & Benson, "Residual Correlation in GNN Regression"(KDD 2020): 图回归中残差存在空间相关性,论证残差联合建模的必要——BECH"残差共动可建模"的学术依据。
- Correct & Smooth(2021): 图半监督分类的后处理(标签传播),证明"图上后处理有效"但不涉时序与极端值。

### 3.2 图+尾部事件(有估计,无校正)
- **自适应可视性图 + 电价尖峰预测**(EPSR 2026): 用自适应可视性图(Adaptive Visibility Graph)捕捉多变量间依赖来预测尖峰——**图+尖峰预测的直接先例**(做预测,非校正)。
- **Hüsler-Reiss 极值图模型**(2606.17723, EU ETS 碳市场): 对**正尾(尖峰)与负尾(崩塌)分别建极值图**,并证明尾部网络与均值依赖网络结构显著不同(更密、中心节点不同)——**这几乎就是 BECH"双尾分别建图"的统计版先例,但领域是碳市场、只做静态推断、不做预测/校正**。
- **尾部 copula**(澳洲 NEM 5区): 证实跨区价格尖峰联合出现(tail dependence)——与我们的 NEM 门禁(Spearman>Pearson)独立互证。

**诚实表述**: 我们此前说"无双尾/极端事件专用图"不准确——存在尾部估计图(极值图/可视性图),准确说法是"**无用于校正/预测的双尾事件图**"。

## 4. 图模块是否已被占据?——判断

| 判断项 | 结论 |
|---|---|
| "图做电价预测" | **已被占据且密集**(10+篇,2024-2026),BECH 不能以此立论 |
| "图做残差校正"(一般时序/交通) | **已被 ResCAL 提出**;BECH 若只做"图残差校正"会被判换皮 |
| "图做能源共形区间" | **已被 STOIC/COREL 占据**;BECH 若做图+区间会被撞车 |
| "图做双尾事件校正 + 认证" | **仍空白**——无任何工作把图放在电价残差校正层、节点事件化、双尾非对称、且受认证式零退化约束 |

**结论**: 图模块**未整体占据,但可占据的缝显著变窄**。BECH 图模块能否成立,取决于:
1. 图层级必须放**残差/校正层**(ResCAL 唯一先例在交通,非电价);
2. 节点必须**事件化**(双尾事件图,呼应 Hüsler-Reiss 但用于校正);
3. 必须与 **SCARR 认证**耦合(图输出可证明不劣于基座——校正图文献无此约束,是护城河);
4. 必须与 **Transformers-are-GNNs 换皮批评**拉开距离(见 §5)。

## 5. 防换皮额外论据(呼应 Transformers-are-GNNs, 2506.22084)

Transformers-are-GNNs 形式化证明: **稠密可学习邻接矩阵 + 序列预测 = Transformer 层**。这意味着"学一个邻接矩阵再跑 GNN"在数学上与 Transformer 等价,会被审稿人判为换皮。

BECH 图模块的**防换皮论据**:
1. **边不来自可学习稠密矩阵**: 边来自**机制来源**——因果发现(ERCOT 式)、物理电网拓扑(NSTM 式)、或**共享外生原因/尾部同动统计**(NEM 门禁: Spearman>Pearson 证尾部同动、Granger 证传导)——不是自由参数,故不落入"可学习邻接=Transformer"的等价类。
2. **图不作用于预测序列,作用于残差/事件**: 即使图消息传递与注意力形式相近,其**对象**(残差过程、双尾事件)与**约束**(认证零退化)不同——统计目标与安全约束是换皮批评免疫区。
3. **稀疏性**: 事件图是稀疏的(仅尾部事件间连边),而 Transformer 是稠密全连接;稀疏机制图与稠密自注意力在表达能力与可解释性上不同。
4. **必须的消融证据**: 单变量优先做下限(先每节点单变量校正),再用跨通道相关性检验证明图增量(Anomalies-in-MTS 教训: 8 基准中不存在需跨通道建模才能检测的异常)——若图增量不显著,应诚实弃权该模块。

## 7. 对 BECH 论文写作的建议

1. **Related Work 图模块段落必须引用**: ResCAL(CIKM'22)、COREL(ICML'25)、STOIC(2026)、Hüsler-Reiss 极值图(2026)、PriceFM(2025)、Dynamic Granger-Causal Networks(2014),缺一不可——否则审稿人会以"图残差校正已有人做"拒稿。
2. **第一轮结论修正**: 文档/汇报中"图在电价上只有3篇"应改为"图在电价预测层已 10+ 篇密集;图在电价*校正层*仍空白,最接近先例是交通的 ResCAL 与能源区间的 STOIC/COREL"。
3. **图模块定位收敛**: 若做图模块,定位必须是"**残差层双尾事件图 + 机制边 + SCARR 认证零退化**",且预留"图增量不显著则弃权"的诚实出口(对应 §5.4 消融)。
4. **呼应 NEM 门禁**: §2 的 Spearman>Pearson(尾部同动)与 Granger(跨区传导)是"边=尾部同动"的实证基础,可引用尾部 copula 文献与 Hüsler-Reiss 双尾图为独立佐证。
