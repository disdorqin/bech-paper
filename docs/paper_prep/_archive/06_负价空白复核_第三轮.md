## 3. 与 BECH 最接近 / 最危险的 3 个工作

### 3.1 ★ 最危险:Vahedi et al. 2026 (IEEE ICCE)——"负价分类→幅度回归"两阶段,就在 NEM-SA

- **为什么危险**:它的模块结构 = BECH 的 `P(neg|Z)`(分类器)+ 幅度头(回归器)几乎同构;且数据集就是 **NEM-SA(5min)**,与我们主实验市场相同;还做了储能经济评估(95.9% 理论最优)——切中 BECH 的经济价值主张。
- **关键差异(使 BECH 仍安全)**:
  1. 它是**完整重训的预测框架**(分类+回归直接出最终预测),**不是外挂冻结基座之上的校正头**——没有"模型无关/可叠加"属性。
  2. **无认证**:没有 bootstrap LCB / 共形分位的效能与安全证书,修正何时安全无统计保证。
  3. **无弃权/零退化预算**:不保证"不劣于基座",也没有"未认证即恒等返回"的拒识设计。
  4. **单向**:只做负价,不做正尖峰分支的主动弃权(无 BECH 的结构性不对称)。
  5. 其"经济评估"是**事后报告**,不是把储能利润作为**认证 gate**(达标才触发校正)——BECH 是"经济价值即认证目标"。

### 3.2 ★ 次危险:Loizidis et al. 2025 (Applied Energy)——负价专用分类+条件取点,日前 DE

- **为什么危险**:这是**绝对日前电价**上的负价专用机制,直接反驳第二轮"无一篇日前负价专用"的措辞;且已用**供需不对称 misclassification cost**,含经济不对称思想。
- **关键差异**:
  1. 预测选择规则("负价日取下界/正价日取均值")是**启发式取点**,非经认证的校正动作;无"校正不劣于基座"约束,无法证明在正常期/正尖峰期零退化。
  2. 分类+区间来自**同一套重训 ELM**,非跨基座模型无关;非外挂。
  3. 无弃权机制,无两层证书,无幅度头学习"修正量 δ"(它是选区间边界,不是学增量)。
  4. 单侧(负价),无正尖峰弃权分支。

### 3.3 Trading Electrons (arXiv 2601.05085)——"双向极端分别建模"先例(但对象是价差)

- 确认第二轮结论:**它是目前唯一显式"正负尖峰分别建模"的工作,但对象是 DART 价差(DA−RT)**,不是绝对日前电价。所以 BECH 的"双向极端分别建模"若只字面主张会被抢;但"绝对日前电价 + 校正头 + 认证 + 弃权 + 双向非对称"组合仍无先例。
- 差异:TE 是交易信号模型(输出尖峰概率 + 仓位),不做数值校正、不做认证/弃权、不保证零退化;它是预测层而非后处理层。

## 4. 最终结论

### 4.1 空白审计:原卖点措辞需修正,核心空白仍成立

| 原卖点(第二轮) | 第三轮判定 | 修正 |
|---|---|---|
| "没有一篇为日前电价设计负价专用机制" | **不成立** | 已发现 Loizidis 2025(Appl Energy)与 Vahedi 2026(ICCE)两篇日前/SA 负价专用预测机制。必须删除"没有一篇"绝对表述。 |
| "负价专用**损失函数**"空白 | 成立 | 无训练端负价专用 loss 的日前电价工作(综述 2602.10071 亦确认自定义 loss 稀疏)。 |
| "负价专用**校正头**(外挂冻结基座、认证、弃权、零退化)"空白 | **成立** | 上述两篇都是重训预测框架,非外挂校正头;无认证/弃权/零退化/经济认证。 |
| "双向(负价+尖峰)分别建模"先例 | Trading Electrons 占据(价差层) | 绝对日前电价上的双向分别**校正**仍空白。 |

### 4.2 BECH 卖点安全性判定:**安全,但必须收敛措辞**

- **可安全主张**:①外挂**冻结**基座的负价专用**校正头**;②三段 tail-conditional **认证**(效能 LCB+共形安全分位);③**未认证即弃权 + 弃权纳入共形论证**(零退化);④**经济价值(储能利润/CVaR)作为认证目标**;⑤**双向非对称**(负价分支触发、正尖峰分支主动弃权)。
- **必须放弃/修正**:"首个负价专用机制"、"首个双向极端建模"——均被上述工作占据。
- **新增必引用的最接近工作**(写作 related work 必须正面划界):Vahedi 2026、Loizidis 2025、Trading Electrons 2601.05085、Galarneau-Vincent 2023、DART 三机制混合 2025。

### 4.3 风险等级

- **Vahedi 2026(ICCE)**:高。结构同构 + 同数据集(NEM-SA)+ 经济评估。BECH 的护城河 = 外挂/认证/弃权/零退化,必须在 intro 用一页表与它划清。
- **Loizidis 2025(Appl Energy)**:中。它是被引证的最强"负价专用机制"先例,审稿人可能拿它质疑"负价专用"新意;需强调其"启发式取点、无认证、无零退化"。
- **Trading Electrons 等 DART 族**:中低。价差 vs 绝对电价的差异清晰,划界容易。

**一句话结论**:负电价专用**预测**机制已非空白(Vahedi 2026 / Loizidis 2025),但负电价专用**认证式外挂校正头**(冻结基座 + tail-conditional 认证 + 未认证即弃权 + 经济认证 + 双向非对称)仍是真实空白——BECH 卖点安全,前提是措辞收敛到"校正头 + 认证 + 弃权"而非"负价专用机制"。
