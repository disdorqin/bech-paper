## 2. NEM 5区 —— ✅ 完全真实

**官方来源**: AEMO 官网聚合数据
- URL: https://aemo.com.au/energy-systems/electricity/national-electricity-market-nem/data-nem/aggregated-data
- 文件模式: `PRICE_AND_DEMAND_{YYYYMM}_{REGION}.csv`(RRP = Regional Reference Price, AUD/MWh)
- 本地: `data/raw/nem_aemo/`(raw/ 原始月文件 + clean/ 清洗小时文件)
- 抓取脚本: `fetch_aemo.py`(REGIONS=NSW1/VIC1/SA1/QLD1/TAS1, YEARS=2021-2025)

**核验结果**:
- 原始文件: 5区 × 60 个月(2021-01 ~ 2025-12)= 300 个月文件,全覆盖无缺失。
- 清洗小时文件: 每区 **43,825 行** = 2021-01-01 00:00 ~ 2026-01-01 00:00(5整年),零缺失(43825 = 5×8765)。

**关键特征交叉核验**(vs AEMO QED 报告):
- **SA1 负价占比 24.02%** —— 与任务引用的 AEMO QED 报告 "~24%" **高度吻合** ✓
- VIC1 19.94%、QLD1 10.97%、TAS1 6.04%、NSW1 5.97%。
- 价格下限触底 -1000(AUD/MWh,AEMC 规定下限,QLD1 出现),上限 ~16600 级别(AEMC 上限),符合现货市场限价。

## 3. GEFCom2014-P —— ✅ 完全真实

**官方来源**: GEFCom2014 官方竞赛(New England / NEPOOL 2011-2013)
- 论文: Hong et al., "Probabilistic energy forecasting: Global Energy Forecasting Competition 2014 and beyond", IJF 32(3):896-913, 2016
- 本地: `data/raw/gefcom2014/`(原始 `Price/Task N/TaskN_P.csv` + 合并的 `GEFCom2014P_hourly.csv`)
- 构建脚本: `build_price_series.py`(拼接 Task15 历史 + Solution 预测)

**核验结果**:

**数据质量注记**: 拼接基于官方 Task 15(历史最长)+ Solution(最后24h预测),是官方公开数据,非自造。

## 4. UniElecPrice —— ⚠️ zip 真实,平铺 by_country 缺 Canada/USA

**官方来源**: Mendeley Data(Global Day-Ahead Electricity Price Dataset)
- DOI: `10.17632/s54n4tyyz4.1`
- Zenodo 镜像: record 16284828(mirror)
- 论文: Ullah et al., "Descriptor: Unified Cross-Regional Time-Series Day-Ahead Electricity Price Dataset (UniElecPrice)", IEEE Data Descriptions, vol.2, pp.329-339, 2025, doi:10.1109/IEEEDATA.2025.3609683
- 本地: `data/raw/unielecprice/`(UniElecPrice.zip + meta.json + by_country/)

**核验结果**:
- **zip MD5 MATCH**: 本地 `UniElecPrice.zip` 56,837,313B,md5=`582d6a62...` == meta.json 官方 checksum(md5:582d6a62...) ✓
- zip 结构: 554 条目,顶层 **40 个国家级目录** + `Price_Unit_by_Country.csv`(各市场时间范围与价格单位清单,如 India IEX Rs/MWh、Japan JEPX JPY/kWh、EU €/MWh)。
- by_country 平铺: **38 个 CSV**。

**发现的问题(重要)**:
- **Canada 与 USA 数据在 zip/extract 中完好**(Canada 26文件/5.2MB, USA 103文件/79.6MB),但 **by_country/ 缺这两个国家的平铺 CSV**。
- 根因: `build_unielec.py` 只扫描 `os.listdir(cdir)` 顶层 `*.csv`,而 Canada/USA 的数据在 `Canada/IESO/`、`USA/CAISO/` 等**子目录**,故被跳过(非数据缺失)。
- **影响评估**: 若论文只用负价高的欧盟市场(Germany 3.48% / Austria 1.83% / Belgium 1.29% 等),Canada/USA 缺失不影响;若要用北美数据(CAISO/IESO),需补跑脚本(递归子目录)。
- 注: Germany 与 Luxembourg 在 by_country 中数据完全相同(243452 行,中位数/分位数/负价完全一致)——这是 UniElecPrice 官方数据本身的特点(ENTSO-E 同一来源?),需留意潜在重复。实际上两列数据逐点相同,可能官方文件本身如此,或构建时某处出错。**建议标注待确认**。
