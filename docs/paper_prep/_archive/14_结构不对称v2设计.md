## 0. 一句话

BECH 的两条尾不再是"同一机制换参数"，而是**机制本身不同**：负尾（可预测）走**校正分支**主动修正，正尖峰（不可预测）走**保护分支**主动弃权——弃权的目标不是"放弃"，而是"在尖峰窗口提供保护标记且证明零退化"。可预测性差异（AUC vs AP）是这一不对称的**数据驱动先验**，不是拍脑袋。

## 1. v0 现状 vs v3 的差距（诚实复盘，先看清再改）

### 1.1 v0 实际实现（src/bech.py）

```
负尾分支:  P(neg) 感应器 → 幅度头 δ⁻ → tau⁻ 门 → SCARR λ⁻ 认证 → 修正 ŷ+λ⁻δ⁻
正尾分支:  P(spike)感应器 → 幅度头 δ⁺ → tau⁺ 门 → SCARR λ⁺ 认证 → 修正 ŷ+λ⁺δ⁺
```

现状是**程序对称的（procedurally symmetric）**：两条尾都走"感应→幅度→门→认证→修正"五件套，区别只在各分支自己的 tau/λ 数值。这带来三个问题：

| # | v0 的问题 | 审稿人会怎么说 |
|---|---|---|
| P1 | 正尾也在做"点修正"（λ⁺δ⁺），但尖峰 AP 只有 0.04-0.21（不可预测），点修正大概率是噪声 | "既然不可预测，你为什么要修它？SCARR 认证只是兜底，不是理由。" |
| P2 | 不对称只体现在 tau/λ 数值，没有机制差异 | "这就是两个独立分类器+回归器，不是'结构不对称'。" |
| P3 | 没有用"可预测性差异"作为设计依据 | "为什么负尾校正、正尾也校正？你的 AUC/AP 数据在哪用上了？" |

### 1.2 v2 → v3 要修复的核心

v2 已把不对称从"参数层"上移到"机制层"（负尾修正 / 正尾保护），但 v2 仍有隐患：**分支类型是设计时拍死的**（负尾=修正、正尾=保护）。用户质疑：尖峰可预测性 0.04-0.21 是**公开集稀疏特征**下测的，山东特征丰富，尖峰可能可预测——那么"正尾一定保护"就是拿公开集结论硬套山东主战场，是逻辑漏洞。

**v3 的核心修复**：分支类型（修正/保护）**由每条尾在 S2 实测的可预测性决定**，不是设计时拍死。山东可能双尾都走修正，公开集一修一保。

## 2. v3 设计：可预测性自适应的分支选择

```
                        ┌────────────────────────────────────────────┐
                        │  Z = 校正模块特征（轨道A最小 / 轨道B增强）       │
                        └────────────────────────────────────────────┘
                                        │
                    ┌───────────────────┴───────────────────┐
                    ▼                                       ▼
        ┌─── 负尾感应器 P(neg) ───┐            ┌─── 正尖峰感应器 P(spike) ───┐
        │  AUC 0.82-0.97 (可预测)   │            │  AP 0.04-0.21 (不可预测)    │
        └──────────┬───────────────┘            └──────────┬──────────────────┘
                   ▼                                       ▼
        ┌─── 校正分支 (Correction) ───┐      ┌─── 保护分支 (Protection) ───┐
        │  δ⁻ = 幅度头(条件中位数)        │      │  不做点修正                    │
        │  tau⁻ 门 →  λ⁻ SCARR 认证      │      │  tau⁺ 门 → λ⁺ 认证            │
        │  认证目标: 改进 (lcb>0)         │      │  认证目标: 零退化 (harm≤budget)│
        │  动作:      ŷ ← ŷ + λ⁻δ⁻       │      │  动作:      ŷ ← ŷ (返回基座)    │
        │  附加:      —                   │      │  附加:      输出"尖峰窗口保护   │
        │                                │      │             标记"(调度层消费)   │
        └──────────┬───────────────────┘      └──────────┬──────────────────┘
                   │                                     │
                   └──────────────┬──────────────────────┘
                                  ▼
                        ┌─── 认证层 (SCARR 分尾) ───┐
                        │  λ⁻: bootstrap LCB>0 + 共形  │  → 改进证书
                        │  λ⁺: 共形 harm ≤ ρ×基线MAE  │  → 零退化证书
                        └──────────────────────────────┘
```

### 2.1 分支类型由可预测性决定（v3 核心，不是设计时拍死）

```
对每条尾 b ∈ {neg, pos}，在 S2 段用 Z 特征实测可预测性：
    metric(b) = AUC(neg 标签) 或 AP(pos 标签)
    ┌ metric(b) ≥ 阈值(如 AUC≥0.7 或 AP≥0.3) → 修正分支
    └ metric(b) < 阈值                    → 保护分支
```

**预计行为（15_山东数据盘点 已完成，实测回填）**：

| 市场 | neg 分支 | pos 分支 | 说明 |
|---|---|---|---|
| 山东（特征丰富） | **修正**（外样本 AUC 0.975、AP 0.81） | **保护**（S1-OOF AP 0.15，外样本事件 S2=13/S4=17 过少，AP 0.05-0.20 波动；尖峰 AUC 0.96 系小样本虚高） | 山东负尾 AP ≫ 尖峰 AP 约 5.4 倍 |
| 公开集（Lago/NEM，稀疏特征） | 修正（AUC 0.82-0.97） | 保护（AP 0.04-0.21） | 一修一保 |

**关键实证（15 文档 §2.2）**：山东负尾外样本 AP=0.84（基线 0.11）、尖峰 S1-OOF AP=0.15（基线 0.01）——负尾可预测、尖峰难精确定位，**v3 的结构不对称在山东验证通过**。但注意山东特殊性：尖峰事件近年骤减（S1 尖峰率 1% → S2/S3/S4 仅 0.15-0.2%），用绝对 S1-p99 阈值时 S2 尖峰训练事件仅 13 个——实际跑 BECH 需用段内相对标签（pos_q=0.99 ≈ 80 事件）才够训练（15 文档 §4.2）。

**两种分支的差异**：

| 维度 | 修正分支（Correction） | 保护分支（Protection） |
|---|---|---|
| **触发** | metric ≥ 阈值（可预测） | metric < 阈值（不可预测） |
| **动作类型** | 点修正（改预测值） | 点弃权 + 窗口保护标记（不改预测值） |
| **幅度头** | 有（δ） | **无**（不学幅度，学了也是噪声） |
| **认证目标** | **改进**（λ 使 segment MAE 显著下降） | **零退化**（λ 使任何单点 harm ≤ ρ×基线） |
| **失败模式** | 认证不过 → 弃权（退化恒等） | 恒等返回本身就是安全态 |
| **输出消费方** | 预测用户 | 调度/储能（尖峰窗口不进非尖峰动作） |

### 2.2 为什么这样设计能主张（对应 12 文档检索）

1. **校正级弃权（correction-level abstention）**——12 文档 §6.1 判定新意最高：把 selective prediction 的"弃权"从**预测层**搬到**校正层**。v3 精确落位：基座已预测，可预测的尾叠加 δ、不可预测的尾不叠加——弃权对象是"校正动作"，不是"预测"。
2. **可预测性驱动**——12 文档 §6.1：AUC vs AP 的实测差异作为"为何这条尾校正如 A、那条尾弃权如 B"的**数据驱动论据**。v3 把 AUC/AP 从"事后评估指标"提升为"事前结构先验"——而且是**每市场每尾自适应**的先验，不是全局拍死。
3. **认证式不对称**——12 文档 §6.1：分尾认证（改进证书 / 零退化证书），证明"即使不对称动作，每条尾的校正/弃权仍不劣于基座"。这是全部先例（ResCAL/COREL/STOIC/selective regression）缺席的护城河。
4. **可预测性自适应**（v3 新增）——不对称结构本身随市场/数据自适应：山东可能双修正、公开集一修一保。这回应"三层自适应"主线（输入契约按可用性、GAFE 按丰富度、**分支类型按可预测性**），且**天然防审稿人"你只是逃避尖峰"质疑**——可预测的市场里尖峰也修正。

### 2.3 与用户三点诉求的对应

| 用户诉求 | v3 的回应 |
|---|---|
| "尖峰和负电价**都预测**怎么办" | 两条尾**都有感应器**（P(neg) 和 P(spike) 都预测），感应层对称；分支类型由各自可预测性决定 |
| "结构不对称要再创新" | 不对称从参数层升到**机制层**，且分支类型**可预测性自适应**（不拍死） |
| "预测（模块②）是大头" | 尖峰预测（P(spike)）始终保留；**若山东尖峰实测可预测（特征丰富很可能），尖峰就走修正分支，预测价值回归**——这是 v3 对用户质疑的直接回应 |

## 3. 关键澄清：保护分支"弃权"≠"放弃尖峰"

最容易被人误读的点，先钉死：

**弃权的是"点预测修正"，不是"尖峰这一现象"。** 保护分支仍然：
1. **预测**尖峰事件（P(spike)，感应器工作）——模块②预测是保留的大头
2. **标记**尖峰窗口（峰点 ±1~2h 的窗口区间，旁路输出）
3. **为调度层消费**：尖峰窗口内储能不放电、不追高买入；窗口外正常

所以当尖峰走保护分支时，价值主张从"把尖峰预测准"（不可预测，做不到）转变为"**诚实承认不可预测 + 提供不劣于基座的点预测 + 给调度一个可消费的保护信号**"。**但当山东尖峰实测可预测时，尖峰改走修正分支，"把尖峰预测准"的主张回归**——这正是 v3 相对 v2 的核心升级。

## 4. 与认证层（SCARR）的接口

v3 不改变 SCARR 的机制（bootstrap LCB + 共形分位），只改变**认证目标**的语义（按分支类型）：

| 分支类型 | 现状 SCARR 目标 | v3 目标 | 实现差异 |
|---|---|---|---|
| 修正（neg 或 可预测的 pos） | λ 最大化 LCB>0 + harm≤ρ·baseline | **改进证书**（不变） | 无 |
| 保护（不可预测的 pos） | λ 最大化 LCB>0 + harm≤ρ·baseline | **零退化证书**：λ 只取"恒等也通过"的平凡解，认证的主体变成"保护标记的 harm 为零" | 保护分支不再学 reg；λ 固定语义 = 不修改预测；认证退化为验证"标记不误伤正常时段" |

**实现层面的含义**：
- 保护分支删掉 `_fit_reg`/`_raw_delta`（幅度头），只留感应器 + 标记输出
- 保护分支的 SCARR 认证目标从"证明改进"改为"证明**标记的精确率/误伤率**"——即保护标记只在真正的尖峰窗口点亮，不在正常时段点亮（否则调度层被误导）
- 这给保护分支一个新的、可认证的对象：**保护信号的 precision/recall**，而不是预测的 MAE
- **分支类型选择器**（新增）：S2 段测每条尾 AUC/AP，≥阈值走修正、<阈值走保护——这是 v3 新增的"第 0 步"

## 5. 实验验证设计（v3 是否真的更好）

关键问题：**"分支类型由可预测性决定"是否真的优于固定不对称？** 必须用实验回答，不能拍脑袋。

### 5.1 主消融（决定 v3 是否成立）

| 消融 | 对比 | 验证什么 | 预期 |
|---|---|---|---|
| A-v0 | 对称版（现状，pos 也修正） | 基线 | 现状已测：负价市场增益 +0.22→+1.69% |
| **A-v2** | 固定不对称版（neg 修正 / pos 保护） | v2 是否 ≥ v0 | 公开集预期：负价市场持平或更好 |

| A-v3+ | v3 + 保护标记的调度价值 | 标记是否被调度层消费 | 储能利润对比（有/无标记）——**future work**（用户确认后补） |

## 6. 撞车划界（写进 Related Work 的话术）

| 先例 | 我们的差异（一句话） |
|---|---|
| selective regression / L2A（2020-2021） | 它们弃权"预测"，我们弃权"**校正动作**"；它们全局置信度驱动，我们**尾部可预测性（AUC/AP）驱动** |
| skew-t / TrUST（2025） | 它们把不对称编码进**分布**，我们把不对称编码进**决策动作** |
| pinball / 非对称损失 | 它们把不对称放进**训练目标**，我们不碰训练（模型无关），只在推理期做不对称决策 |
| ResCAL / COREL / STOIC（图残差校正） | 它们做"安全残差修正"，无**尾部不对称动作**、无**弃权门**、无**可预测性先验** |
| 我们的 v0 | v0 对称机制+数值不对称；v3 机制级不对称 + 可预测性自适应分支 + 认证目标分级 |

**防换皮核心**：v3 的主张锚定在"**校正级弃权 × 尾部可预测性先验 × 分尾认证目标 × 可预测性自适应分支**"四者交集——任一先例都只占其中之一。
