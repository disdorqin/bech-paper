## A · opencode-b1：公式级查新与还原攻击

### 任务标题

`v7-A 事件编辑后处理的公式级碰撞审计`

### 输入

- `experiments/05-episode-audit/results/P0_DECISION.md`
- `experiments/05-episode-audit/results/episode_audit.md`
- `docs/paper_prep/15_算法创新重新发现_本地检索审计.md`
- `docs/paper_prep/22_BECH_v5_round3_strict_peer_review_2026-08-07_v1.md`
- 第二、三轮本地文献库

### 候选对象

给定冻结基座日向量 `b in R^P`，提取基座负价事件集合 `E_b`；训练时从真值提取 `E_y`。通过带 dummy 节点的最小代价二部匹配生成相对基座的编辑脚本：

- `KEEP/SCALE`：保持事件并修正幅度/内部形状；
- `SHIFT`：修正开始/结束边界；
- `DELETE`：删除虚假基座事件；
- `INSERT`：插入基座完全遗漏的事件。

校正头从 `b + cutoff-safe Z` 预测编辑集合，仅修改选定支持；无编辑时 exact fallback 到基座。

### 必查文献族

1. temporal action localization / boundary regression / proposal refinement；
2. DETR-style temporal set prediction / Hungarian supervision；
3. edit-based sequence refinement / insertion-deletion models；
4. HMM/HSMM/CRF duration decoding、fused-lasso/TV trajectory repair；
5. post-hoc forecast refinement、residual correction、RIGS、CRC、delta-Adapter、PIR；
6. extreme-event episode/duration forecasting；
7. negative electricity price occurrence、duration、spell/episode forecasting。

### 强制还原攻击

逐一回答：

1. 是否等价于 `ActionFormer/DETR + residual magnitude head`？
2. 是否等价于 `HSMM/CRF + regression`？
3. 是否只是 RIGS 的一维时间版本？
4. “相对冻结基座的 edit script”是否已被 forecast refinement 文献直接使用？
5. `INSERT` 是否只是 pointwise event classifier 经连通分量解码？
6. 匹配代价或编辑监督是否产生了已知模型无法表达的新统计对象？

### 交付

写入 `docs/paper_prep/28a_事件编辑公式级碰撞审计.md`，必须包含：

- 至少 12 篇核验到原文的文献，其中至少 5 篇公式级最近邻；
- 候选与最近邻的输入、输出、监督、匹配、推理、回退六维矩阵；
- 每个最近邻至少一处原文公式/算法/章节坐标；
- “四同”判定与最强还原攻击；
- `GO / CONDITIONAL GO / NO-GO` 裁决；
- 若 GO，只允许给出一个不可还原落点；若 NO-GO，明确最接近可发表的应用定位；
- 检索局限和未获取全文清单。

### 验收标准

- 不以“没人把所有组件放一起”作为新颖性理由；
- 不把跨领域应用自动视为创新；
- 结论能够直接决定是否实现正式编辑网络。

## B · opencode-b2：最小原型与强基线实验

### 任务标题

`v7-B 事件编辑最小原型与可证伪实验`

### 文件边界

只允许创建/修改：

- `experiments/_archive/retired-methods/06-event-edit-prototype/**`（已判 INVALID/BLOCKED，仅作历史追溯）

不得修改 `src/`、现有实验和文档。数据根为项目内 `data/raw`，不要沿用旧的 `D:/作业/data`。

### 实验目标

回答的不是“最终模型能否刷分”，而是：相对点级校正和普通 24 点网络，显式 `INSERT/SHIFT/SCALE/DELETE` 编辑监督是否有独立价值。

### 数据与基座

第一阶段只跑：

- `LAGO_DE`；
- `NEM_SA1`；
- `UNIELEC_DE`、`UNIELEC_FI`、`UNIELEC_NL`。

基座：`Linear`、`GBDT`。UniElec 德国若为 15 分钟，先按小时均值形成 24 点任务。完整日才进入事件指标。

### 协议

- 严格复用 S1(50%)/S2(20%)/S3(10%)/S4(20%)；
- S1 训练冻结基座；S2 训练后处理；S3 只选超参数/门；S4 只评估；
- 负价事件阈值固定为 `<0`；
- `Z` 只能使用基座预测、日历、至少滞后 24h 的价格/残差和安全外生预测；
- 所有方法使用相同基座预测和 S4 样本。

### 必做方法

| ID | 方法 | 目的 |
|---|---|---|
| B0 | frozen base | 原点 |
| B1 | 当前 pointwise BECH | 现方法 |
| B2 | pointwise residual GBDT/MLP | 普通残差头 |
| B3 | 直接 24-vector correction MLP | 强拼接/整向量基线 |
| B4 | duration/TV 或简单 HSMM-style contiguous decoder | 旧结构化方案还原基线 |
| E0 | event matching + edit supervision 最小原型 | 候选 |

E0 最低实现要求：

1. 从 S2 的 base/truth 日向量提取事件集合；
2. Hungarian/最小代价匹配，dummy 负责 insert/delete；
3. 生成 `KEEP/SCALE/SHIFT/DELETE/INSERT` 监督；
4. 推理时预测最多 `K` 个编辑，`K` 仅在 S3 选择；
5. 只修改编辑支持，未选择编辑时 bit-exact 返回 base；
6. 先实现最小可用版本，不引入 Transformer/图网络掩盖对象价值。

### 指标

- episode recall / precision；
- complete-miss rate；
- boundary L1 error；
- duration absolute error；
- event magnitude MAE；
- point recall/precision；
- overall MAE；
- normal-hour MAE/harm；
- exact-fallback 数值检查；
- 按日 block bootstrap CI，比较 E0 对 B1-B4。

### 强制消融

- E0 without INSERT；
- E0 without SHIFT；
- E0 without edit matching，改为 pointwise mask；
- oracle edit upper bound（只作上限，严禁进入正式比较）。

### 停损条件

任一成立即报告 NO-GO，不继续加模型容量：

1. B3/B4 与 E0 无稳定差异；
2. 去掉 INSERT 或 SHIFT 不降；
3. event 指标提升靠 normal-hour harm 换来；
4. 仅 NEM 成立，日前市场不成立；
5. S3 有效但 S4 失效。

### 交付

- 可运行代码、README 和固定 seed；
- `results/pilot_metrics.csv`；
- `results/ablation_metrics.csv`；
- `results/PILOT_VERDICT.md`；
- 命令、环境、运行时间和所有失败日志。

### 验收标准

- 能从干净环境复跑；
- 不改共享代码；
- 不因原型失败而临时换阈值、数据集或指标；
- 结论必须是 `PROCEED / REVISE / STOP` 之一。

## C · opencode-b3：数学对象与性质闸门

### 任务标题

3. 匹配代价中 IoU、边界、幅度项的量纲与归一化；

### 性质候选审计

逐项判定 `标准事实 / 可作方法性质 / 可能新 / 错误`：

- 最小匹配代价与 edit-script minimality；

- 相比 pointwise correction 的 hypothesis-class 或 sample-complexity 差异；
- episode-level calibration 对小时内依赖的有效样本解释；
