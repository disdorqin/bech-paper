## 一、裁决① 三项贡献是否真实且非显然组合？

**结论：依赖链自洽（部分成立）；"非显然组合"不成立（as stated）；最弱项 = ①。**

1. **①"leak-safe + exact fallback"无独立贡献**。`exact fallback`（恒等回退）就是 [CRC（arXiv 2512.22428）](https://arxiv.org/abs/2512.22428) 四重防火墙最后一重 shrink-to-base 的"回退到基座"；"leak-safe"是实验卫生，不是方法。①只能作为 ③ 的安全策略实现细节，不能当贡献点。
2. **②的三个"未还原"都不构成方法级创新**：跨态掩码异质性 = "按动作状态条件化的重要性"，是条件化的平凡扩展；决策感知选边 = 决策聚焦学习（decision-focused learning）里"以决策损失选特征"是既有研究领域，把损失从 accuracy 换成 H 是"换目标函数"不是"新方法"；0/1 掩码不作权重 = **限制**而非进步（更粗粒度，一般更弱）。
3. **③的认证机制不新**（见⑤-4，RCPS/LTT 例化）。
4. **"非显然组合"的证据链缺口**：组合的三零件均被占，唯一的非平凡交互候选是"**决策感知选边（H 基）→ 同一策略被认证**"——这条链只证明了**架构自洽**，没有证明**非平凡交互**。审稿人对组合类主张的标准要求是：给出一个"只有此组合才成立、任一组件的单用不成立"的性质。你们最该主张的这个性质是：
   > **H-based 选边（而非 accuracy-based 选边）可证地收紧认证证书**（如：条件风险的置信区间宽度、或可认证策略族的大小）。

   这是可证伪、可消融检验的；拿不出这个，"组合 = 拼盘"的判决成立。

**若判定"非显然组合"须补的证据**：G0–G4 消融中加"**accuracy-based 选边 vs H-based 选边 vs 全特征**"三对照，指标落在**证书结果**（被认证策略的条件风险 / 证书宽度 / 可认证率）而非预测精度上。

## 二、裁决② utility router 是否构成独立方法对象？

**结论：不成立。撤销或并入 ①③ 作实现细节。**

1. **LOCO/CPI 家族确已把"条件移除效用 + 推断"做透**。[CPI（Watson & Wright，*Machine Learning* 2021，条件置换/knockoff + Wald 统计量）](https://arxiv.org/abs/2210.03047)、LOCO（leave-one-covariate-out）都给出分布无关的重要性推断；[RCPS](https://arxiv.org/abs/2101.02703) 更是把"在风险证书约束下选择参数"做成了通用框架。04 包自己列的三条"未还原"——跨态掩码、决策感知、0/1 掩码——前两条见裁决①，第三条是限制。
2. **"按状态分列 + Holm"是标准工程**（分组重要性 + 多重性校正），无方法地位。
3. **最强可辩护版本**（若团队坚持保留）：改为**"决策感知的感应输入构造器"**——特征按 H-based 移除效用、分动作状态、0/1 掩码，作为 §-claim 而非贡献点，且必须满足：这个选边**可证地收紧认证证书**（否则只是"换个特征选择器"）。以现状论，这大概率做不到严格证明，所以实际结论是**并入**。

## 三、裁决③ 风险保证是否数学成立？

**结论：不成立（需重大修正）。** 逐问：

### (a) 证书条件化在哪个 $$G_g$$？（最高优先，未定义即无法裁决）

- 若 $$G_g$$ = **感应头预测的分组**（双尾状态分类）：校准集 = 被模型过滤出的点，**selection-conditional**（conformal-after-selection）。感应头在 S3 上训练，其"尾部判定"与 harm 分数共线，校准样本不再是从目标条件分布采样，标准 split-conformal / Hoeffding–Bentkus 上界**不直接成立**。这是 BECH v3 已识别的问题（§7 不足 #2 的 selection bias），04 包完全没处理。
- 若 $$G_g$$ = **市场规则外生的极端事件集**（$$y_t \le L_m$$ 或 $$y_t \ge U_m$$，如 BECH v3 §1 的做法）：则组内可交换性是"近似成立"的真假设，无选择偏差，但要接受下面的 (b)(c) 代价。
- **还有第三个坑**：即使证书条件化在外生 E 上，模块实际**激活**（$$a_t \ne 0$$）是由预测 $$G$$ 决定的——"外生集上安全"与"模块激活时安全"是两个不同事件。诚实的证书应是"条件化在模块决策上"，而那正是 selection-conditional 难题。**这一条必须在包内明确选择并论证，否则③没法裁。**

### (b) 安全证书的统计对象混淆：发生率 vs 分位（硬伤）

`$$P(H(\hat{\pi}) > \delta_{harm} \mid G_g) \le \alpha$$` 是一个**发生率/期望风险控制**（bad times 的占比 ≤ α）——这是 RCPS 型对象，对应 Hoeffding–Bentkus（对指示变量 $$\{H>\delta\}$$ 的均值上界）或 RCPS 的 UCB 校准。**split-conformal 给的是分数分位（逐点覆盖），不是发生率上界**——两者是不同统计对象、不同校准机制。04 包把 split-conformal 与 Hoeffding–Bentkus 并列为"上界工具"，是概念混淆。选哪个必须先钉死：若主张"平均 harm 受控"用 RCPS/Bentkus；若主张"逐点 harm 界"用分位数共形。**写混 = 审稿人当场发现不严谨。**

### (c) A1 块可交换性可辩护吗？（不可，严格意义上）

电价逐时残差：强自相关（日内/周周期）、厚尾、机制突变（山东 2025 二级限价、规则修订）。块可交换要求"依赖结构可按块完整切分且块间同分布"——对强周期 + 漂移序列，这是近似中的近似。你们已诚实声明"否则只能给 mixing 下的近似/渐近"——那么结论就是：
- **"安全证书"主张在严格意义上不能成立**，只能降为 **"经验 harm 率 + 渐近近似"**；
- 若要保住有限样本语言，换机制：EnbPI 式滚动重校准（但给出的是**长期经验覆盖**，不是有限样本条件保证），或块自助（块长需覆盖自相关 → 块数骤减 → 功效崩）。
- **不得写"分布无关、有限样本"**——除非把保证类型如实改掉。

### (d) 双约束同时成立（漏洞存在，需联合控制）

效能 LCB 与安全上界各 1−β，在同一 S4 上估计（**相关**）。联合置信 ≤ 1−2β（Bonferroni）；分尾 ×2 后 → **4 个证书 → 联合 1−4β**。若 04 不说明，审稿人必问。最干净：用 [LTT（Learn then Test，arXiv 2110.01052）](https://arxiv.org/abs/2110.01052) 的 de-valuing 对"（安全×效能）×（尾⁻×尾⁺）"四元组做联合控制，或明示每证书 β 已按 Bonferroni 除 4。另外"效能最优策略"与"安全达标策略"可能不是同一个——**选策略的决策规则要预注册**，否则 S4 就成了"选完再证"，选择偏差从后门进来（见 ③-1）。

### (e) C0 正常组误校正 harm，触发稀疏时样本量不足

若正常组内校正动作触发很少（感应头只在极端态激活），C0 约束的样本 ≈ "被误校正的正常点"，数量小 → 上界松弛/失稳。不足时应：**收窄为"仅报告经验 harm 率"**（不声称证书），或正常组默认 $$a=0$$（只保护不动作），把 C0 当报告项而非保证项。

### ③-1（预注册 + S3/S4 分离能否排除 λ 选择偏差）

**部分排除，堵不住全部**。预注册 δ/α/β + S3/S4 分离能挡住"在 S4 上选 λ"；堵不住：(i) 感应头在 S3 训练、但校准集是感应头预测分组时的 selection bias（见 a）；(ii) S4 若用于"多个候选策略中挑最好的再报告其证书"，选择偏差从策略族层面进来。干净做法：**S4 只用一次，策略族在 S3 全定，S4 只做一次证书计算**；若必须用 S4 选策略，对整个策略族做 LTT/Bonferroni 全族校正。

### ③-2（A1 可辩护性 → 证书降级）

见 (c)：**不可辩护（严格意义）**；mixing 渐近近似**不足以支撑"安全证书"主张**，应降为"经验 harm 率 + 长期覆盖频率（ACI 式在线更新恢复）"，并区分"有限样本保证"（换机制才有）与"经验报告"（当前机制只有这个）。

### ③-3（双约束联合漏洞）

见 (d)：**存在**；需要对 4 证书做联合控制（Bonferroni / LTT de-valuing），并预注册"效能 vs 安全冲突时选哪个策略"。

### ③-4（C0 稀疏功效）

见 (e)：**不足**；收窄为经验 harm 率报告。

## 四、裁决④ 整体贯穿还是拼盘？

**结论：部分成立。** 单一 $$H_t(\pi)$$ 贯穿选边→选策略→认证→报告，是**真实的架构自洽主张**（强于"三篇独立工作"），但不足以构成"贯穿性"的完整证据。

**裂缝**：感应头的核心输出——**双尾状态 G（occurrence 分类）不是 H_t(π)**。②"选边基于 H"与"状态预测基于 occurrence"是两个目标函数，耦合只在"选边"这一条线上。审稿人最可能的攻击路径：
> "你说单一原始变量贯穿，但感应头的核心输出（双尾状态）就不是 H。所谓贯穿 = 用 H 做选边 + 认证 + 报告，唯独不贯穿最核心的状态预测。"

**防御（预写进包）**：把 G 定义为**辅助条件变量**（外生的市场规则事件集，或 H 的函数），明确论证"H 是唯一的目标 / 认证 / 报告度量，G 只是定义条件域的辅助量"。若能把 G 定义成 $$G = \arg\min_{\text{策略族}} \mathbb{E}[H]$$ 的分组，则裂缝闭合。**第二条攻击**："统一度量 = 记号便利，不是方法创新"——防御只有一条实证出路：**H-based 选边可证收紧证书**（同裁决①/②）。拿不出这个，贯穿性 = 架构品味，不是贡献。

## 五、裁决⑤ 与六近邻的边界（逐条）

### ⑤-1 PIR：差异成立，但被高估

[PIR（NeurIPS 2025，实例感知事后修订）](https://neurips.cc/virtual/2025/loc/san-diego/poster/118913) 的不确定度模块 = 两层 MLP 直接预测 MSE（训练损失即 MAE）——04 说"其不确定度模块学习且无保证"**事实成立**。但注意：PIR 的**选择性细化本身就是"按不确定度决定改多少"**（不确定性自适应的 α,β 权重）——这与你们"可预测性驱动分支"在思想上**同源**。
- **"选择性"不是你们与 PIR 的差异**（PIR 也做选择，只是软权重 vs 硬策略）；
- 真正的差异 = **双尾/电价领域 + 策略级保证（PIR 无）**。措辞应改为"PIR 是软性不确定度加权修正、无保证；我们是硬离散策略族 + 事件条件证书"，把"选择"从差异清单里拿掉。

### ⑤-2 δ-Adapter：差异成立，但必须重写措辞（不要写"它无保证"）

[δ-Adapter = "The Forecast After the Forecast"（arXiv 2601.20280，ICLR 2026）](https://arxiv.org/abs/2601.20280) 带 **Conformal Corrector（有限样本区间覆盖）** + **逐样本 trust-region δ**（每个校正样本相对基座的位移被限制）。所以：
- "它无认证/无安全保证"是**错句**——它有逐样本位移界 + 区间覆盖；
- 你们与它的真实关系是**两类安全范式**：它给**逐样本位移约束**（稠密小动作，逐点强），你们给**事件条件的组级风险证书**（稀疏大动作，事件条件）。**逐样本界在"单点安全"上比组均值界更强**（组均值允许个别大 harm 被平均掉）——所以不要说"我们比它安全"，要说"我们是事件条件的组级风险证书，它是逐样本位移约束，两类保证互补，且我们没有落在它的保证空间里"。
- 这就是 04 包要求的最强版本：**逐样本 trust-region 界 vs 事件条件组级风险证书，并排对照，不声称优次**。

### ⑤-3 CRC：差异清单里两项不成立（最必须修）

[CRC（arXiv 2512.22428）](https://arxiv.org/abs/2512.22428) 四重防火墙 = **方向门控 / 分位数截断 / 逐点选择 / shrink-to-base**，并给出逐点 + 验证级 + PAND 非降级保证（$$Error(\hat{Y}) \le Error(\hat{Y}_{base})$$）。因此 04 的差异清单**四项里有两项直接不成立**：
- **"弃权"不是差异**——CRC 的逐点选择就是"逐点决定要不要校正"＝校正级弃权（启发式）；
- **"认证"不是差异**——CRC 的 PAND 就是非降级证书；
- **"双尾"部分重叠**——CRC 的方向门控本身就是 signed/方向感知机制（虽非电价双尾）;
- 真正剩下的差异只有：**事件分支**（CRC 全样本逐点安全，你们极端事件集上的条件保证）+ **分尾动作族**（每尾不同动作族）。
- **强制结论**：CRC 必须从"近邻"升级为 **M0–M9 主基线 + 划界表首位**，划界句改写为："CRC 是全样本逐点安全 + PAND 非降级；我们是极端事件集条件保证 + 分尾动作族"。若不改，20 号审稿的"唯一/首个"教训会原样重演。

### ⑤-4 RCPS/LTT：例化，不是实质差异

[RCPS（arXiv 2101.02703，JACM 2021）](https://arxiv.org/abs/2101.02703)：holdout 校准 + UCB（Hoeffding–Bentkus 型）控制 $$E[L(Y,T(X))] \le \gamma$$（概率 ≥ 1−δ），要求单调损失 + 嵌套预测器。把"预测器"=策略 π、损失=H、γ=δ_harm、置信=1−β——**就是你们的安全证书逐字例化**。"双尾"=两个风险函数/两个校准子集，LTT 的 de-valuing 正是处理多风险的。结论：**认证机制不能当创新点**；novelty 落在"策略族 + 电价双尾动作设计 + 事件条件"上，认证要写为"应用 RCPS/LTT 于电价校正策略的例化"。

### ⑤-5 CPI：并列方法（目标不同），非子案例；无独立地位

[CPI（条件置换/knockoff，含混合数据扩展 arXiv 2210.03047）](https://arxiv.org/abs/2210.03047) 检验的是**条件独立性**（$$Y \perp X_j \mid X_{-j}$$），给 Wald 统计量/p 值；04 的"移除差分 + Holm"是 **LOCO 式边际移除效用**（检验"移除 X_j 对 H 的影响"）。两者测的是**不同对象**（条件 vs 边际）——所以是**并列的、不同定义的重要性度量，不是子案例**。"按状态分列 + Holm"是标准工程。结论：与 CPI 的关系要写成"我们测的是边际移除效用，非条件独立性"；"移除效用选特征"本身成熟，无独立方法地位（同裁决②）。

### ⑤-6 COSA：已定位，可划界，不碰撞

COSA = Contextual Output Space Adapters（[ICLR 2026 poster 10010061](https://iclr.cc/virtual/2026/poster/10010061)）：冻结基座之上学习 **tanh(g) 连续门控**的上下文输出空间适配器，**无风险保证**。04 的 utility mask 是**离散 0/1 掩码 + 独立认证**——对象不同（连续学习门控 vs 离散效用判定），可划界。但若论文把掩码描述为"门控"，须与 COSA 划清（连续/学习 vs 离散/效用判定 + 认证）。

## 六、裁决⑥ 实验前必须删除/收窄清单（最终版）

### 必删（实验前从贡献/差异清单移除）

4. **"分布无关、有限样本"**（对安全/效能证书）——在 A1 下不成立，除非换机制。

6. **δ_efficacy**：从"保证改善"降为"**预注册效应量 + 置信区间**"——$$E[H]\le-\delta_{efficacy}$$ 是严格改善承诺，比"不劣"强得多，极端样本不足时必然被"统计功效不足"否决。
7. **安全证书**：A1 不成立 → 降为"**经验 harm 率 + 渐近近似 + 长期覆盖频率**"，与"有限样本保证"明确分列。
8. **认证机制作为贡献点**：写为 RCPS/LTT 例化（⑤-4）。
9. **C0 正常组 harm 约束**：触发稀疏时降为经验 harm 率报告。

### 保留但必须标注推断

10. **ΔR 尾部可辨识性**（§9-1）、**C0 触发稀疏功效**（§9-6）、**块可交换性**（§9-7）——保留，但标注为"推断，未验证"。

### 必须补（不算删除，但缺了证书无效）
