## 1. 文献遍历发现（三族综合）

### 1.1 P1 图结构/特征族：图在电价上的真论文极少，残差层图是空白

**现状**（30 篇，家族 A+E）：
- 真正把图用在电价上的只有 **3 篇**：NSTM（39 个欧洲竞价区，物理电网拓扑 + 图论最短路径边权）、GCGNet（ICLR'26，Graph VAE 学习邻接矩阵 + 图一致性对齐）、ERCOT 因果图（LPCMCI 因果发现，边权=偏相关强度）。
- 其余家族 E 图论文（RFID/海冰/ILC/NeuroCoreX）为物理/工程/理论背景，与电价无关，应剔除。
- **Transformers-are-GNNs (2506.22084)** 形式化证明：稠密可学习邻接矩阵跑在预测序列上 = Transformer 层——这是「图预测换皮」批评成立的数学依据。

**空白**：
1. **无图作用在校正/残差层**——30 篇里的图全部用于预测/表示，无一用于事后残差校正（BECH 的「残差图」是空白）。
2. **无双尾/极端事件专用图**——无「节点=被检测极端事件（负价/尖峰）、边=共享外生原因或时间邻近」的事件级图。
3. **无动态图**——NSTM 静态拓扑、ERCOT 静态窗口、GCGNet 逐样本重学（弱动态）。
4. **无市场规则/物理先验作边权**——NSTM 用电网拓扑、ERCOT 用因果，但都未把定价规则结构编码进边权。

**可吸收（按优先级）**：
1. **GCGNet 图一致性对齐**（生成图与真实图 L1 对齐作为正则）→ 迁移为「残差图与因果/物理先验图对齐」；
2. **ERCOT 因果发现的稀疏有向边先验**（风电预测→电价、负荷→价格）→ 作为固定残差图骨架；
3. **NSTM 区域邻域 + 两阶段残差校正**（B_z^r 邻域构造；「均值预测+残差后处理」是 BECH 架构的统计版先例与强基线）；
4. **Structure-Aware Set Transformers 软注意力偏置**（不加图卷积、只加参数高效的亲和+时间偏置）→ 最轻量图插件范式；
5. **Top-k 稀疏化 + 单变量优先诊断**（Anomalies-in-MTS 论文：8 个基准中不存在需要跨通道建模才能检测的异常）→ 加图前必须做跨通道相关性门禁。

**结论**：「残差序列作节点、在残差层做图消息传递」在 P1 家族内是真实空白，且是自然的下一步；但它在更广文献中属「空气中已存在的想法」，必须靠**图的位置（残差/校正层）+ 边的来源（因果/物理/机制）+ 与 SCARR 认证约束的耦合**拉开距离，否则易被审稿人判为换皮。

### 1.2 P2 极端电价/不确定性族：负电价专用机制确为空白，但撞车点已确认

**负价建模现状**（30 篇，家族 B+C）：
- **没有一篇为日前电价设计负电价专用损失/分类机制**。唯一显式双向极端建模是 **Trading Electrons**（正/负 DART 尖峰两个独立二分类标签），但对象是**价差 spread**，不是绝对电价。
- **已归档的 07_新颖性碰撞报告**更早一轮 54 篇调研已把「负电价专用触发/校正机制」判定为**真正空白**。
- 因此 BECH 的「负电价专用分支 + 正尖峰分支主动弃权」确实踩在真实缺口上；但**「双向极端分别建模」这个动作在 Trading Electrons 已出现**（DART spread），写作时新颖性必须界定在「**日前电价 + 与校正模块耦合 + 双向非对称处理**」。

**可吸收（M3 事件感应器 / M5 风险认证层）**：
- M3：**Trading Electrons** 双标签逻辑回归模板（市场特定阈值定义标签 + 稳健线性分类器）；**X-flexForecast** 的 QR+GPD 尾部混合（加性分位数主体 + 离散广义帕累托尾部，BMA 融合）；**TimeCatcher** 动态掩码触发（窗口振幅+方向+自适应阈值）；**CALIBURN** 等渗回归把原始分数映射为条件概率（感应器输出必须是已校准概率）。
- M5：**GLCP 的 ESS 回退本地化**（尾部样本稀少时本地化权重退化，回退到无加权分位数——M5 处理极端子集校准样本不足的现成工具）；**SA-MSCP 承认 bootstrap 无有限样本保证**（反向论证 BECH 两层 SCARR 的理论必要性）；**CP-in-Data-Assimilation 的 CQR 对重尾最优**（支撑 M5 上/下分位分别校正）。

**两个新威胁（必须正面处理）**：
1. **Weather 论文 (2606.19642) 撞车**：它已完整发表「外挂冻结基座的模型无关在线共形后处理、不牺牲 CRPS」，且实证了「边际覆盖在极端子集失效」。BECH 不能把「模型无关共形后处理」当定位，必须收敛到「**尾部条件 + 双尾非对称 + 电价日前**」。
2. **Barber 不可能性定理**（R.F. Barber 2020, "Is distribution-free inference possible?"）：分布自由下**任意**条件覆盖不可能。对极稀疏尾部子集，精确的分布自由有限样本条件覆盖在信息论上不可行。→ BECH 的 tail-conditional 主张必须措辞为「**相对基座的非降级 / 相对风险控制**（weaker but achievable）」，**不可宣称「尾部精确条件覆盖 ≥ 1−α」**，否则会被拒。

### 1.3 P3 校正头/价值对齐族：拥挤度确认 + 经济价值认证是真空白

**拥挤度盘点**（30 篇家族 D+F + 增量笔记）：
- 「通用时序残差校正」槽位已被 **6 个并列工作**占满且 2026 密集出现：CRC（四重安全防火墙 + NDR 指标）、δ-Adapter（信任区 + 局部下降 Prop 2.1 + O(δ) 稳定界）、UEC（ICML'26，chunk 自回归误差校正）、Post-Training Corrections（Theorem A：仿射校正永不恶化）、PnP-Corrector（ICML'26）、PIR。
- **「安全性/不退化」子赛道也已占**：CRC 明确声称任意节点与视界不退化、δ-Adapter 有局部下降保证、Post-Training Corrections 有仿射永不恶化定理。
- **「进模前平滑尖峰」槽位**已被 STL-KF 占据（与 BECH 的事后修补划清边界）。

**真实空白（BECH 可占据，三个）**：
1. **tail-conditional 的认证式极端值校正**（按正常/负尾/正尾三段各认证各的预算，条件保证而非边际保证）——30+4 篇中无先例；
2. **校正模块的经济价值认证**——储能调度利润/regret/CVaR 作为**认证目标**而非后验报告（家族 F 只做评估不做校正、家族 D 只做统计不做经济，交集为空）；
3. **分布自由的「弃权零退化」**——把弃权本身纳入共形安全论证。

**可吸收（理论武器库）**：
- **GRS 定理**：递归仿真一步误差 ε、Lipschitz 常数 L>1 时误差可达 O(L^(N-1)·ε)——长视界残差必须显式校正，且校正器 Lipschitz 常数必须受控；
- **δ-Adapter Prop 2.1** 二次型论证（R(δ)=½E‖r‖²−δE⟨r,g⟩+½δ²E‖g‖²，E⟨r,g⟩>0 时 δ 有界保证下降）→ M4 幅度头的 δ 可直接套用；
- **Post-Training Corrections Theorem A**（最优仿射校正风险=Var(Y)−Cov²/Var(Z) 非负下降）→ 弃权恒等返回的解析锚点；
- **TATS 命题 3.1**（趋势分类器准确率 > 数值预测器方向准确率时校正必降误差）→ 双尾事件感应器的设计判据；
- **CRC 四重防火墙**（方向门控、分位裁剪、逐点选择、shrink-to-base）→ M4 逐条对照清单。

**必补指标（来自家族 F）**：**MPD（Min-Max Price Deviation，极值点价格偏差）**——与 BESS 套利利润相关 0.89–0.97，比 MSE 更贴合 BECH 主张；同时报告 **Corr-f**（校正不得扭曲日内价格曲线形状）。

1. **负电价专用，正尖峰主动弃权**——结构性不对称（负价可预报、尖峰不可预报）是方法论支柱，P2 族验证「负电价专用机制」为空白。
2. **tail-conditional 认证**：按正常/负尾/正尾三段各认证各的预算（bootstrap 效能 LCB + 共形安全分位），是条件保证而非边际保证——P2/P3 均确认无先例，但措辞必须受 Barber 定理约束（「相对基座非降级」而非「精确条件覆盖」）。
3. **未认证即弃权（恒等返回）+ 弃权纳入共形论证**——分布自由的零退化。
4. **经济价值认证**（储能利润/regret/CVaR 作为认证目标）——P3 确认为家族 F×D 交集空白。
5. **可叠加性**：M8/M9 证明可叠加在同行方法或重训基座之上（0/18 退化）——正面回应新鲜度威胁。
6. **评估方法学贡献**：负价漏判率按事件数加权、增益归因审计、五段隔离防泄漏、MPD 指标。

**论文一句话定位（建议）**：
> 不是更强的通用后处理器，而是一个**可叠加在任意冻结预测器之上、按三段做 tail-conditional 风险认证、未认证即弃权、并以经济价值为认证目标的负电价专用校正头**。

## 4. 三模块设计风险

### 4.1 图结构模块（M2）——文献已给出复活路线，但换皮风险高

**现状**：已从核心模块降级为可选插件。P1 遍历确认「残差层图」是真空白，但也给出了**6 条防换皮设计规则**：

1. **图层级放残差校正层而非预测层**：图建模的是冻结基座的*误差过程*（哪些时刻/变量的残差共动），家族内无先例；
2. **边语义必须因果/物理/机制来源**（ERCOT 因果发现、NSTM 电网拓扑），而非相似性；
3. **节点可事件化**：双尾事件图（负价/尖峰事件为节点、二分图连接尾部类型），而非裸时间步；
4. **机制条件化/时变边**：同一对残差节点在高 TTF/低水库状态下连接、正常态断开；
5. **与 SCARR 认证层耦合**：图插件输出必须可证明不劣于基座——校正图文献没做过的约束，是防换皮的护城河；
6. **单变量优先 + 跨通道诊断门禁**：先每节点单变量校正做下限，再用跨通道相关性检验证明图增量。

**两个可选出路**：
- **(a) 放弃图模块**（推荐若时间紧）：M2 不作为贡献，ablation 一句话说明「不加图也达当前结果」。
- **(b) 合法复活**：利用 **NEM 5 区真实空间结构**（跨区价格联动、风水互补）或 **残差层图**，按上述 6 条规则设计，定位为可选 C3 插件而非核心创新。需先做相关性/格兰杰检验证明跨区联动显著。

### 4.2 极端概率分析（M3）——核心，负电价机制空白已获独立验证

- 负价分支：AUC 0.82–0.97（判别力强），`P(事件|Z)>0.5` 常见 → 触发有意义。
- 正尖峰分支：AP 仅 0.04–0.21，`P(事件|Z)>0.5` 几乎从不成立 → **主动弃权是正确行为**。
- P2 族独立验证：30 篇内无日前电价负价专用机制，唯一双向建模在 DART spread 上。**无风险**。
- 注意事项：感应器输出必须是**已校准的条件概率**（CALIBURN 等渗回归做法）；新颖性界定在「日前电价 + 与校正模块耦合 + 双向非对称」，不宣称「首个双向极端预测」。

### 4.3 概率修补（M4/M5）——核心，安全机制有证据，两个风险已识别

- 条件中位数幅度头（L1）避免过校正；SCARR 两层证书把最坏伤害从 1615 压到 124；去掉证书后净退化组合 0→9。
- 理论支撑：δ-Adapter Prop 2.1 二次型（δ 有界保证零退化）、TATS 命题 3.1（感应器准确率判据）、GRS 定理（校正器 Lipschitz 受控）。
- **风险 1**：MAE 最优收缩 ≠ 符号判别最优（证据文档局限 2）——如实呈现。
- **风险 2**：标定段事件稀缺导致过度弃权（LAGO_DE 局限 1）——滚动重标定作为未来工作；GLCP 的 ESS 回退是现成工具。
