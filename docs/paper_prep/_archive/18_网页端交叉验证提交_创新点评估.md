## 1. 论文一句话

**BECH（Budgeted Extreme-Conditional Correction Head）**：一个**模型无关**的极端电价校正后处理模块，挂在任意冻结日前电价预测器之后。只在"校正动作不劣于基座且有风险证书"时才触发，否则原样返回。核心主张：**校正级弃权 + 可预测性自适应的结构不对称 + 分尾认证**。

## 2. 三大创新点（C1/C2/C3）当前表述

### C1 · 自适应特征契约（Adaptive Feature Contract）
- **层**：输入层
- **一句话**：校正模块内置最小自足特征构造器（公开集零配置开箱即用），出现日前可得的业务预报时自动升级为增强特征，行级可用性由特征掩码管理，两轨训练/部署行为一致。
- **主张**：首个**按可用性掩码自适应**的校正输入契约（六篇对照无人做特征可用性自适应）。
- **证据**：07 文档 §1.2 对比表 + gain audit（NEM_SA1 特征贡献 0.53% ≈ 最小就够；LAGO_DE 7.02% 增强值回票价）。

### C2 · 图结构自适应特征合成器 GAFE（Graph-Adaptive Feature Encoder）
- **层**：特征构建层
- **一句话**：任意输入自动组织成"特征关系图"（节点=特征，边=统计/因果先验），GNN 消息传递合成高阶交互特征；特征多→图丰富，特征少→图退化但保持最小结构。
- **主张**：图在**特征关系**上的自适应合成（区别于文献里节点=时间序列通道的时空图）；边=统计先验（相关top-k/格兰杰因果）可解释。
- **证据**：11 文档（GAFE 先例检索）——特征图+残差校正+电价+认证唯一位置；待消融 G0-G4。

### C3 · 可预测性自适应的结构不对称校正头（BECH + SCARR，v3）
- **层**：校正 + 认证层
- **一句话**：每条尾（负电价 / 正尖峰）在 S2 段实测可预测性（AUC/AP），**可预测 → 修正分支**（点校正），**不可预测 → 保护分支**（弃权 + 保护标记 + 零退化认证）；未通过 SCARR 两层证书（bootstrap 效能 LCB + 共形安全分位）即弃权（恒等返回）。
- **主张（四要素交集，先例只占其一）**：
  1. **校正级弃权（correction-level abstention）**——把 selective prediction 的"弃权"从预测层搬到校正层
  2. **可预测性驱动的分支选择**——AUC(负尾) vs AP(正尖峰) 实测差异作为结构先验，每市场每尾自适应
  3. **分尾认证目标分级**——修正分支"改进证书"（LCB>0），保护分支"零退化证书"（单点 harm ≤ ρ×基线）
  4. **结构不对称**——负尾修正如 A、正尾保护如 B，机制本身不同（非参数不同）
- **证据**：山东实测负尾 AP 0.81 vs 尖峰 AP 0.15；NEM_SA1 负价 24.6%；M0-M9 同行对照 198 行（BECH 唯一零退化+漏判率显著↓+最坏伤害低一个数量级）。
