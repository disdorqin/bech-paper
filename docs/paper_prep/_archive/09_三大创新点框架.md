## 0. 一句话框架

**BECH = 三层自适应的极端电价校正头**：输入契约按数据可用性自适应（C1）、特征按丰富度自适应构建关系图（C2）、校正动作按 tail-conditional 认证自适应触发（C3）。

三个创新点 = 三层自适应，每层一个 A 会可主张的点，且三层有一条贯穿主线（"自适应"）。

## 1. 三大创新点明细

### C1 · 自适应特征契约（Adaptive Feature Contract）
- **层**：输入层
- **一句话**：校正模块内置最小自足特征构造器（公开集零配置开箱即用），环境中出现日前可得的业务预报时自动升级为增强特征，行级可用性由特征掩码管理，两轨训练/部署行为一致。
- **卖点**：首个**按可用性掩码自适应**的校正输入契约（六篇对照无人做特征可用性自适应）。
- **证据**：07 文档 §1.2 对比表 + gain audit（NEM_SA1 特征贡献 0.53% ≈ 最小就够；LAGO_DE 7.02% 增强值回票价）。
- **文档**：`07_校正模块输入契约设计.md`

### C2 · 图结构自适应特征合成器 GAFE（Graph-Adaptive Feature Encoder）
- **层**：特征构建层
- **一句话**：任意输入自动组织成"特征关系图"（节点=特征，边=统计/因果先验），GNN 消息传递合成高阶交互特征；特征多→图丰富，特征少→图退化但保持最小结构。
- **卖点**：图在**特征关系**上的自适应合成（区别于文献里节点=时间序列通道的时空图）；边=统计先验（相关top-k/格兰杰因果）可解释，呼应"真实场景特征多、有相关性、可落地"。
- **证据**：待消融 G0-G4（08 文档 §5）；前期靠文献检索验证空白（待派 opencode）。
- **文档**：`08_图结构自适应特征合成器_设计雏形.md`

### C3 · tail-conditional 三层认证校正头（BECH + SCARR）
- **层**：校正 + 认证层
- **一句话**：负价专用（正尖峰主动弃权）+ 正常/负尾/正尾三段各认证各的预算（bootstrap 效能 LCB + 共形安全分位）+ 未认证即弃权（恒等返回，弃权纳入共形论证）+ 经济价值认证（储能利润/regret/CVaR）。
- **卖点**：tail-conditional 认证 + 未认证即弃权 + 经济认证三重交集空白（06 撞车划界：Weather 无 tail-conditional/无弃权/非电价，双尾非对称留作 future work；家族 D 无人做经济认证）。
- **证据**：45 组合主矩阵 + 消融 + M0-M9 同行对照 + 增益审计 + 06 撞车划界。
- **文档**：`05_论文准备建议报告_综合.md`、`06_撞车划界_Weather与校正头.md`、`06_负价空白复核_第三轮.md`

## 2. 三创新点的关系（不是拼盘，是一条主线）

```
        "自适应" 主线贯穿三层
  输入层       特征层       动作层
C1 按可用性    C2 按丰富度    C3 按认证
自适应        自适应        自适应
契约          建图          触发
```

- C1 回答"校正头吃什么"：有多少特征就用多少（掩码自适应）。
- C2 回答"怎么把特征组织起来"：特征多就建图交互，特征少就退化（图自适应）。
- C3 回答"什么时候真的改预测"：认证通过才改，否则恒等（风险自适应）。

**叙事一句话**：BECH 在"输入→特征→动作"三个层面都做自适应——公开数据开箱即用、业务特征自动利用、尾部风险认证后才出手。
