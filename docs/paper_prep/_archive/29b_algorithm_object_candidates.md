## 1. 10 个候选算法对象

### C1: 事件级代价敏感学习（Episode-Level Cost-Sensitive Learning）

**数学对象**：
```
min_θ Σ_{t∈S4} w(y_t, ŷ_t, base_t) · L(y_t, ŷ_t)
```
其中 w 是事件级代价权重：负价 episode 内权重高，正常时段权重低。

**训练目标**：最小化加权损失
**推理映射**：θ* → ŷ_t = f(x_t; θ*)
**监督**：S2 真值 + 基座预测
**泄漏审计**：✅ 无（权重基于 S2 真值，推理不使用）
**回退**：无编辑时返回基座

**还原攻击**：
- ❌ **Hurdle/two-part 模型**：两阶段结构 = P(event) × magnitude，结构同构
- ❌ **代价敏感分类**：标准 ML 方法，已有大量文献
- ❌ **Focal Loss**：Lin et al. 2017，已占"类别不平衡加权"
- **裁决**：❌ 被击溃

### C2: 事件边界回归（Event Boundary Regression）

**数学对象**：
```
(ŝ_start, ŝ_end) = g_φ(x_t)
```
预测每个事件的起始和结束边界。

**训练目标**：最小化边界 L1 距离
**推理映射**：g_φ → 边界 → 在边界内插值
**监督**：S2 Hungarian 匹配后的事件边界
**泄漏审计**：✅ 无
**回退**：无预测事件时返回基座

**还原攻击**：
- ❌ **ActionFormer**：边界回归 + 时序定位，已占
- ❌ **DETR**：集合预测 + 匈牙利监督，已占
- ❌ **时序动作定位**：标准任务，已大量文献
- **裁决**：❌ 被击溃

### C3: 持续期感知校正（Duration-Aware Correction）

**数学对象**：
```
δ_t = d_ψ(x_t, duration_t)
```
校正量基于预测事件的持续期。

**训练目标**：最小化事件级 MAE
**推理映射**：持续期 → 校正量
**监督**：S2 Hungarian 匹配后的持续期
**泄漏审计**：✅ 无
**回退**：无事件时返回基座

**还原攻击**：
- ❌ **HSMM/CRF**：持续期建模的标准方法
- ❌ **Fused-lasso/TV**：轨迹修复的标准方法
- ❌ **Duration modeling in speech**：已有大量文献
- **裁决**：❌ 被击溃

### C4: 事件插入预测（Event Insertion Prediction）

**数学对象**：
```
P(insert_t = 1 | x_t) = σ(f_θ(x_t))
```
预测每个时段是否需要插入事件。

**训练目标**：二分类交叉熵
**推理映射**：P(insert) > τ → 插入事件
**监督**：S2 Hungarian 匹配后的 INSERT 标签
**泄漏审计**：✅ 无
**回退**：无插入时返回基座

**还原攻击**：
- ❌ **点级事件检测**：标准二分类任务
- ❌ **异常检测**：已占"检测罕见事件"
- ❌ **稀有事件预测**：标准任务
- **裁决**：❌ 被击溃

### C5: 事件幅度校正（Event Magnitude Correction）

**数学对象**：
```

```

**训练目标**：最小化幅度 MAE

**监督**：S2 Hungarian 匹配后的幅度差
**泄漏审计**：✅ 无

**还原攻击**：

- ❌ **BECH 现有方法**：已实现
- **裁决**：❌ 被击溃
