## 1. 总体裁决：NOT READY 终判**维持**，但"为何 NOT READY"三处改写

**先肯定三件对的事**：
1. **组合攻击纪律执行到位**——11 个候选逐一拆组件，拆得动的（A1/A2/A3/B3/C2/C4）果断淘汰，拆不动的诚实标"部分失败 + 需证明"，没有为凑数保留。这是用户契约的正确执行。
2. **e-BH→FWER 修正是正确的**。[e-BH（Vovk & Wang 2021）](https://arxiv.org/abs/2103.05861) 控 FDR 不控 FWER；命题"任一组超预算"是 ∃-型联合事件，必须 FWER 工具。12 §3.1 的修正（Bonferroni/e-Holm/closed testing）**数学上正确**，是包内最有把握的环节。
3. **NOT READY 本身是诚实姿态**——"不是没搜到，而是每个候选都能拆成已知零件；唯一拆不开的需新理论"，这句收束是对的。

**但终判的支撑理由有三处需改写**：

- **① B1′ 的"新应用对象"定位被 CSA 打穿**（见 §2）。v5 把 CSA 列为"对象更近，但域=LLM/通用"，这在**机制层面**是低估：CSA 与 B1′ 共享"Ville e-process + 分组 + Bonferroni 联合 + anytime-valid + acted-on 选择性"整套骨架。按 v5 **自己**的组合攻击标准（"换对象 = 应用非算法"），B1′ vs CSA 必须判"应用为主"。
- **② C1 的 P1 被描述得比实际宽**（见 §4）：符号决定论只给出**方向**，不给出**幅度**；且 clamp 到价格边界在应用电价预测里是**惯例**，novelty 只能押在 P1（省符号学习）与 P3（fill-to-bound）上，P3 还是条件性命题。
- **③ A4 的"无先例"说法过头**（见 §5）："动作决定自身检验对象"恰恰是 CSA selective-risk-on-acted-rounds 和选择性预测文献已有的设定；A4 真正未占的是"**功效自指 + 不动点存在性**"。

**战略含义**（不改变终判，改变论文写法）：v5 的 NOT READY 是"**无可还原的独立算法/理论对象**"意义上的 not-ready，**不是"没有论文"**。论文的可辩护贡献仍是前序各阶段判定的 **组合（事件条件 × 分尾动作族 × 策略级审计）+ 实证市场结构发现（负尾可预测/尖峰不可预测）+ C1 领域机制**——v5 的价值在于给"为什么没有独立新算法"留下了一条可核验的诚实审计轨迹。

## 2. 最严重发现：B1′ 与 CSA 是机制级碰撞（v5 必须正面划界）

### 2.1 机制对照

| 维度 | **CSA**（[arXiv 2605.20270](https://arxiv.org/abs/2605.20270)，已核） | **B1′**（13 §2.1） |
|---|---|---|
| 构造 | Ville 型 e-process，**per threshold** 各维护一个 | 组级 e-process `E_t^{(g)} = ∏(1+λ_g·max(H_s−δ_g,0)/M_g)^{1{A_s=g}}` |
| 联合控制 | **Bonferroni 网格** | **Bonferroni / e-Holm / closed testing**（12 §3.1 修正后） |
| 时效 | anytime-valid | anytime-valid |
| 选择性 | **acted-on rounds**（只对实际采取动作的轮次控制风险） | **动作条件分组**（`A_s=g` 驱动） |
| 保证对象 | 选择性风险（per-round 概率） | 累积 censored harm ≤ **预算路径** `B_g·t/T` |
| 应用域 | RLVR 训练 LLM 的部署轮次 | 电价校正的 harm 预算 |

### 2.2 用 v5 自己的攻击标准裁决

v5 淘汰 A1/A2/A3 的核心论据是"换对象（把约束从一般优化换到校正幅度）= 应用非算法"。**同样的刀砍向 B1′ vs CSA**：e-process 构造 = [Waudby-Smith & Ramdas](https://arxiv.org/abs/2010.09686)（14b 自认），分组 + Bonferroni + anytime = CSA（2026），剩下的差异 = **"累积预算路径" vs "per-round 选择性风险"** 的对象差 + 电价域。按 v5 自己的标准，这一刀**基本砍得开**——"组级 e-process + Bonferroni + acted-on 选择性"的骨架已被 CSA 占据。

**尚存的对象差异只有一条**：CSA 控的是 per-round 风险率，B1′ 控的是**累积花费 ≤ 线性预算路径**。这个差异是真的（率 vs 累积花费是两个控制对象），但"预算/累积花费"控制本身在 e-process / 选举审计（[RiLACS](https://arxiv.org/abs/2107.11323)）文献里是标准对象，不是 BECH 独有。**结论：B1′ 只能作为"应用 CSA 机制族 + 预算路径对象"的工程组件，不能作为理论贡献。**

### 2.3 审稿人裁决

- **B1′ 的"可证明理论候选"地位：撤销**。改为"在线安全门的工程组件（构造来自 [Waudby-Smith & Ramdas](https://arxiv.org/abs/2010.09686)，分组-联合框架与 [CSA](https://arxiv.org/abs/2605.20270) 同构）"。
- **论文必须正面划界 CSA**：正文写"与 CSA 相比，我们把每阈值 e-process 换成动作条件组 + 把风险率对象换成累积预算路径"，并承认机制同族。不写 = 撞 2026 最新近邻，比撞 CRC 更糟（CSA 是 2026 年、机制逐点对应）。
- **14b 内部自相矛盾（审稿人必抓）**：14b §② 表把 CSA 标为"我们的 harm-budget **是其特化**"（诚实），但 §④"反驳自己一遍"又说"action-conditional 组级 e-process 在时序风险控制中**无先例**"。若前者成立则后者必假（CSA 的 per-threshold 组级 e-process 正是该先例）；这两句在**同一份文档**里。13 §2.5 收敛后把 CSA 降格为"域=LLM/通用"，等于放弃了 14b 原本更诚实的"特化"措辞——**最终包件对 CSA 的碰撞是低估的**，这正是本审稿 §2 要纠正的。
- 若 v6 硬要把 B1′ 立为贡献，唯一出路是**证明"预算路径对象"不可约**——但目前连"预算路径与 e-process 阈值如何对齐"的引理都没给（见 §3），不满足。

## 3. B1′ 定理的技术缺口（诚实标注：需补三个引理，缺一个证书不成立）

### 3.1 预算路径 $$B_t = B\cdot t/T$$ 与 e-process 阈值不对齐

定理声称 `P(∃g,∃t: Σ_{s≤t} max(H_s−δ_g,0)·1{A_s=g} > B_{g,t}) ≤ α`，其中 $$B_{g,t}=B_g\cdot t/T$$ 是**线性增长的预算路径**。但 e-process 的 Wilks/Ville 界给的是：

$$
P\!\Big(\sup_t E_t^{(g)} \ge 1/\alpha\Big) \le \alpha,\qquad
\log E_t^{(g)} \approx \frac{\lambda_g}{M_g}\sum_{s\le t} X_{s,g}
$$

即 **e-process 越过 1/α 对应"累积 censored harm 超过一个（近似）常数"** `≈ (M_g/λ_g)·log(1/α)`，而**不是超过线性增长的 `B_g·t/T`**。要让"越过预算路径"与"E_t ≥ 1/α"等价，需要 `λ_g` 随 t 缩放或预算路径取 e-process 阈值诱导的特定函数——**这条引理（λ 与 B/T、δ 的校准关系）在 14b 与 13 里都没有推导**，只有一句"选择 λ = min(1, B·λ_opt/M)"的启发式。缺这个引理，"线性预算路径"的声明就是空的。

### 3.2 `{A_s = g}` 的 selection-conditional 问题（与 v3 自识别的 SCoRE 问题同源）

组指标是**动作选择的结果**（`A_s` 由 π̂ 对协变量 Z 的映射决定），所以组内子序列不是从原分布采样，而是**被策略过滤过的**。e-process 的鞅性要求组内条件期望在零假设下 ≤ 0：

$$
\mathbb{E}\big[X_{s,g} \mid \mathcal{F}_{s-1}\big] \le 0, \qquad X_{s,g}=\max(H_s-\delta_g,0)\cdot 1\{A_s=g\}
$$

若 `A_s` 依赖 `Z_s`、而 `H_s` 也依赖 `Z_s`，则 `1{A_s=g}` 与 `H_s` 相关，**组内条件期望不等于全样本条件期望**——这正是 BECH v3 §7 已自识别的 selection-conditional 问题（SCoRE 一族）。13 §2.4 把"action-conditional 无选择偏差的严格证明"标为 [需证明]，诚实，但这不是边角假设：**它是 e-process 成立的前提**，不是可后补的改进。

### 3.3 记号问题（小事，但审稿人会揪）

14b 定理陈述写 `P(...) ≤ 1/E_T ≤ α`——`1/E_T` 是随机变量，不是固定数；正确写法是"拒绝域 `{E_T ≥ 1/α}`，零假设下 `P(拒绝) ≤ α`"。同样一处，14b/13 的 `λ_g ∈ (0, 1/M_g)` 与"non-negative supermartingale"的核对——`(1+λX/M)` 在 `E[X|F]≤0` 下确为非负超鞅，✓，这部分成立。

**裁决：三个引理（预算路径对齐 / selection-conditional 无偏 / λ 预注册后界）补齐前，B1′ 不得在任何文档里写"可证明"二字。** 缺 3.1，声明落空；缺 3.2，e-process 的前提不成立。

## 4. C1：真实但薄，且"先例空缺"只是 WebSearch 空档

### 4.1 正确的地方

- P1（`ŷ_base < floor ⟹ e>0 a.s.`）**数学正确且有用**：它精确覆盖 BECH 的目标子集（基座预测冲出行政边界的极端尾部），在该子集上**方向零学习**。这是通用后处理（[CRC](https://arxiv.org/abs/2512.22428) 分位 clip、[δ-Adapter](https://arxiv.org/abs/2601.20280) 位移界）确实不提供的信息。
- P2（clamp 是 L2 投影、1-Lipschitz、不增误差）恒真，✓。
- "外生规则常量 vs 数据内生分位"的界来源区分——**成立**，是 C1 最站得住的点。

### 4.2 审稿人挑出的三处

1. **P1 只给符号，不给幅度**。`ŷ_base < floor ⟹ e>0` 只免掉符号分类器；**幅度头仍然要估 `E[y|Z]−ŷ_base` 填到哪**。因此 P1 的收益 = "省一个符号分类器（在该子集上）"，不是"校正幅度免费"。13/14c 的叙述（"符号决定论"作卖点）读起来像方向+幅度都免费，**必须收窄为"方向已知、幅度仍需估计"**。
2. **"未检索到先例"是 WebSearch 空档，不是文献空档**。把预测 clamp 到价格边界是应用电价预测的**常见工程做法**；[CRC](https://arxiv.org/abs/2512.22428) 的分位 clip、以及大量工业实现的 [−500, 3000] 类硬限幅，都有"限制预测到已知界"的雏形。v5 的 novelty 只能押在**"外生规则 + P1 + P3"三者组合**上，P3 还是条件性命题（低估单调性，需边界段条件分布）。**13 §1.6 的 R2（admin-clamp vs 分位-clamp 打平即证伪）设计正确，是 C1 的生死实验**——但在此之前，包内不得把 C1 写为"空白已确认"。
3. **规则漂移未处理**。行政边界不是静态常量：山东有申报 −80 / 出清 −100 两级限价（v5 包自己也引了）。若测试期内规则修订（如二级限价触发变频繁），clamp 用的"当前规则"与保证分析用的"规则"必须一致，否则证书条件漂移。v3 的 MCCL 有规则表 + ACI 在线更新来处理这类漂移，**v5 的 C1 完全没接上**——这是包内自洽性缺口。

### 4.3 裁决

**C1 保留为领域机制组件（薄），定位正确；但 v6 前必须**：① 量化 P1 覆盖率（`P(ŷ_base<floor)` 在各市场的实测占比——这决定 C1 的全部价值）；② 跑 R2 生死实验；③ 接上规则漂移处理；④ 在 IEEE Xplore/ScienceDirect 复核"外生边界注入"空档。

## 5. A4：诚实，但"无先例"过头

A4（动作-功效自洽不动点）是 v5 唯一被诚实判定"拆不开"的机制，**这个判断大体对**。但"动作↔功效因果箭头无先例"的表述过头了：

- **"动作决定自身检验对象"= CSA 的 selective-risk-on-acted-rounds**（[arXiv 2605.20270](https://arxiv.org/abs/2605.20270)）与选择性预测文献的"风险定义在所选子集上"——**已有**；
- A4 真正未占的 = "**动作量 → acted 样本量 → 检验功效**"的**正反馈**与"动作量 → 误校正暴露 → 风险"的**负反馈**，以及两者**不动点**的存在性。**这部分需要新理论，判 NOT READY 正确**。

审稿人意见：若 v6 投入，先证明"功效-动作单调性"（14a 已给出正反两个方向，这一步有戏），不动点存在性作为第二步；且第一步必须与 CSA 的"acted 子集自选"划清——否则一半已占。**结论维持 NOT READY，但把"无先例"改为"半占：selection-self-coupling 已有，power-self-coupling 未占"。**

## 7. 给论文的落地建议（把 v5 的结果用起来）
