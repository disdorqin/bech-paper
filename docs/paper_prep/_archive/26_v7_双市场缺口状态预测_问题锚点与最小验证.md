## 1. 冻结任务

山东主场景在第 D 天 14:00 预测。跨市场复现实验使用市场本地 cutoff `c_m`：它必须早于 D+1 日前出清价的首次公开时刻，并取该时刻已经发布的最后一个 RT 时段。不能机械地对所有市场使用 14:00，因为部分市场在该时刻可能已经公开 D+1 DA，继续把它当目标会产生标签泄漏。

信息集为

\[
\mathcal I_{D,c_m}=\sigma\!\left(
Y^{DA}_{\le D,1:24},
Y^{RT}_{<D,1:24},
Y^{RT}_{D,1:k},
X^{\mathrm{asof}}_{\le D+1}
\right),
\]

其中山东 `c_m=14:00`；其他市场由官方发布制度冻结。`k=k(m,c_m)` 是 cutoff 对应的最后已发布 RT 时段，`X^{asof}` 只包含当时已发布且可重建版本的外生预测。目标是同时预测

\[
(Y^{DA}_{D+1,1:24},\;Y^{RT}_{D+1,1:24}).
\]

禁止使用：cutoff 后 RT、D+1 真实 DA/RT、事后修订的外生量，以及由这些字段计算的统计量。

## 2. 问题锚点

普通多变量预测把输入当作规则矩形；本任务在预测时刻具有稳定的“缺口边界”：

- D 日 DA 轨迹完整；
- D 日 RT 只观察到前缀；
- 两个市场通过日内价差联系，但信息质量和尾部机制不同；
- 输出是 D+1 的 DA/RT 两条完整轨迹，而不是填补 D 日 RT 后缀。

定义当前日已观测 spread 前缀

\[
S^{obs}_{D,1:k}=Y^{RT}_{D,1:k}-Y^{DA}_{D,1:k}.
\]

核心科学问题不是“能否把两组特征拼起来”，而是：

> `S_D^{obs}` 是否包含在完整 DA 轨迹、历史价格和外生预测之外，对 D+1 双尾事件仍稳定有效的市场状态；若有，如何只迁移可持续的状态、抑制一次性噪声造成的负迁移？

## 3. 推荐中央算法对象（候选，不作最终命名）

### 3.1 Prior-to-posterior dual-market state update

先由完整 DA 轨迹和历史信息形成当前市场状态先验：

\[
z_D^- = E_{prior}(Y^{DA}_{D,1:24},\mathcal H_{D-1},X^{asof}_{D+1}).
\]

再用 RT-DA spread 前缀做带 mask 的状态更新：

\[
z_D^+ = z_D^- + G_\theta(z_D^-,M_k)\odot
U_\theta(S^{obs}_{D,1:k},Y^{DA}_{D,1:24},M_k),
\]

其中 `M_k` 明确编码可观测边界，`G` 控制哪些状态可从 RT 前缀迁移。两个输出头联合预测：

\[
\widehat Y^{DA}_{D+1}=F_{DA}(z_D^+,X_{D+1}),
\]

\[
\widehat \Delta_{D+1}=F_{spread}(z_D^+,X_{D+1}),\qquad
\widehat Y^{RT}_{D+1}=\widehat Y^{DA}_{D+1}+\widehat \Delta_{D+1}.
\]

这保留了 `RT = DA + spread` 的市场结构，同时让 DA 与 RT 任务共享状态而不强迫输出相同。

### 3.2 Signed-extreme objective

主损失不能只有平均 MAE。候选目标为

\[
\mathcal L = \mathcal L_{point}^{DA}+\mathcal L_{point}^{RT}
+\gamma_o\mathcal L_{occ}
+\gamma_m\mathcal L_{mag}
+\gamma_c\mathcal L_{cons},
\]

其中：

- `L_occ` 分别学习负价与正尖峰 occurrence；
- `L_mag` 只在对应真实事件上学习有符号 magnitude；
- `L_cons` 约束 RT 输出与 DA+spread 分解一致；
- 尖峰阈值只从训练段冻结，负价阈值由 0 或市场规则定义。

### 3.3 负迁移回退

并行计算不使用当天 RT 前缀的 prior 预测与使用前缀的 posterior 预测：

\[
\widehat Y^- = F(z_D^-),\qquad \widehat Y^+=F(z_D^+).
\]

门控只决定是否采用状态更新：

\[
\widehat Y=(1-a_D)\widehat Y^-+a_D\widehat Y^+,
\quad a_D\in\{0,1\}.
\]

`a_D=0` 时函数上 exact fallback 到 prior 分支。这个恒等性质可以证明，但“统计上不劣于 prior”仍需独立验证或风险控制，不能混写。

## 4. 可能成立的支撑性质

在历史 paired spread 满足低维状态模型

\[
S_D = \Lambda z_D+\varepsilon_D
\]

且 D+1 目标依赖 `z_D` 的条件下，可以分析：

1. RT 前缀使后验状态不确定度相对 prior 缩小多少；
2. 哪些 horizon/事件组的条件风险因此下降；
3. 当 prefix innovation 与 D+1 条件独立时，最优门应回退 prior。

这些结论主要用于解释算法与设置停损条件。它们可能是已知条件估计结果的领域化推论，未完成查新前不称新定理。

## 5. 为什么时间边界不能由普通封闭划分替代

训练/验证/测试划分只回答“测试标签是否参与拟合”；它不回答“测试样本的某个特征在预测时是否已经发布”。例如，即使测试日期完全封闭，若输入包含 D 日 18:00 的 RT 值，而 forecast origin 是 D 日 14:00，测试分数仍然泄漏。

本任务至少需要：

- 按自然日/交易日顺序切分，不能随机打散；
- 每个样本保存 `forecast_origin=D 14:00`；
- 每列保存 `available_at` 或 as-of 版本语义；
- 特征、标准化、阈值和模型选择全部只在相应历史段拟合；
- 测试只做一次最终报告。

## 6. P0 最小信息增益实验

先在山东内部数据做低成本可行性审计，不训练复杂 v7：

| 编号 | 输入/模型 | 要回答的问题 |
|---|---|---|
| B0 | 历史 + 外生，不用 D 日 DA/RT | 基本可预测性 |
| B1 | B0 + D 日完整 DA | DA 曲线本身的增量 |
| B2 | B0 + D 日 RT 前缀 | RT 前缀本身的增量 |
| B3 | B0 + DA + RT 前缀直接拼接（Ridge/GBDT/MLP） | 强组合基线 |
| B4 | B3 + 显式 spread 前缀 | 价差分解是否有价值 |
| B5 | prior/posterior 状态更新最小原型 | 专门算子是否超越强拼接 |

所有比较必须按日 rolling-origin，在同一测试日配对。指标分别报告：

- DA/RT 总体 MAE、RMSE；
- 负价 AP、F1、加权漏判率；
- 正尖峰 AP、条件 magnitude MAE；
- daily worst-group harm；
- DM 或 block bootstrap 置信区间。

额外做按日块置换：在相似 DA 形状/季节分层内置换 RT 前缀，检验增益是否来自真实跨日状态，而不是模型容量或日历代理。

## 7. 停损条件

出现任一情况就不继续包装 v7：

1. B2/B4 相对 B1 在严格样本外没有稳定增益：RT 前缀不是有效状态信号；
2. B3 与 B5 无稳定差异：专门算子还原为普通拼接；
3. 增益只存在山东，两个公开 paired DA/RT 市场无法复现：只能作为内部应用发现；
4. 增益只来自平均误差，负尾/正尾没有独立改善：撤销 extreme 主张；
5. 原文检索发现 known-future-covariate TSF/TTA 已有同构 prior-update 算子：重新划界或停止。
