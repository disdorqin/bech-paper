## 1. 候选1(条件): 事件级延迟标签驱动的 signed-group magnitude 校正

### 1.1 正式 problem statement

> 设基座预测 ŷ_BASE(冻结)对电价极端的 magnitude 系统性失真:负价事件 y_t≤L⁻ 的幅度 |y_t−ŷ_BASE| 被低估,尖峰事件 y_t≥L⁺ 的幅度被高估。真实价格 y_t 在延迟 L 步后到达(结算)。目标: 学习一个 signed-group 校正函数 δ_g(z; ĝ),使校正后预测 ŷ_BASE+λ·δ 在事件组上幅度更准,且校正幅度**由事件级延迟标签辨识性驱动**(非由漂移类型)。

```
输入: Z_t(日前可得特征), ŷ_BASE(冻结), 延迟真实价格 y_{t−L}(结算后到)
输出: 校正幅度 δ_{t,g} = f_g(z_t; 事件级延迟标签), 动作 A_t ∈ {BASE, NEG, POS}
学习算子: 在 S2 段,用"事件组 G_g × 延迟 y_{t−L}"构造幅度目标,
          d_g(z) = Median(y − ŷ_BASE | Z=z, G_g, 延迟结算),校正幅度对事件 magnitude 条件化。
核心主张: 事件级延迟标签(y_{t−L} 真值按事件组到达)使幅度辨识性优于"非事件聚合"或"漂移响应"。
```

### 1.2 输入输出和学习算子

- **输入**: Z_t(日前电价形状/残差历史/日历), ŷ_BASE(冻结), y_{t−L}(延迟真实)。
- **输出**: δ_{t,g}(有符号幅度), A_t(动作), ŷ_t = ŷ_BASE + λ·δ_{t,g}·1{A_t=g}。
- **学习算子**: `min_θ Σ_{t∈G_g} | y_t − (ŷ_BASE + δ_θ(z_t)) |`(在 S2 事件组上,用延迟标签);或 L_mag(§4.4 v4 的条件幅度损失)在"延迟结算"语义下重定义。

### 1.3 为什么不是 hurdle/Elkan/PIR/CRC/δ-Adapter/RCPS/CSA/SCORC 的组合

| 还原攻击 | 结果 |
|---|---|
| 两段结构(occurrence→magnitude) | hurdle 同构(10c 已证)——**不是新** |
| 决策规则 p>C/(B+C) | Elkan 同构——**不是新** |
| 选择性校正(act/abstain) | PIR/selective regression 已占——**不是新** |
| 校正幅度约束 | δ-Adapter/CRC 已占(trust-region/clip)——**不是新** |
| 风险审计 | RCPS/LTT/CSA/SCORC 已占——**不是新** |
| **事件级延迟标签驱动的幅度辨识性** | **Drift2Act 做漂移响应门控,不做"事件 magnitude 数值校正";"事件组条件化的延迟结算幅度学习"未检索到直接同构** [我的推断] |

→ **唯一潜在不可还原点**: "事件 occurrence 触发 + 延迟结算标签 + magnitude 条件化校正"三者的**辨识性耦合**。但须证明: 事件级延迟标签给出的幅度估计,严格优于"用全样本延迟标签"或"用漂移响应替代"——若等价,则还原为 Drift2Act/分位数回归。

### 1.4 可独立陈述的算法性质/定理(候选)

> **命题(需证明)**: 设事件组 G_g 的出现率 π_g ∈ (0,1),延迟 L 固定。校正幅度 δ̂_g(z) 由事件组内延迟标签估计。若事件组内残差分布与全样本残差分布的**位置偏移** θ_g = E[e|G_g] − E[e] 非零且可辨识,则事件组条件化幅度估计的均方误差 < 全样本幅度估计,差异随 π_g↓ 增大。

- **假设**: ①残差 e=y−ŷ_BASE 在事件组内重尾;②事件组由真实 y 定义(仅训练/评估);③延迟 L 不使事件标签错配。
- **证明草图**: step1 建立事件组条件残差分布;step2 用条件中位数性质(Koenker-Bassett)得组内幅度最优;step3 对比全样本估计的偏差-方差;step4 得 MSE 差。
- **状态**: [需证明];核心难点在"位置偏移 θ_g 的可辨识性"(是否被重尾/稀疏淹没)。

### 1.5 两周证伪实验

- **目标**: 证明"事件级延迟标签"给出不可替代的幅度增益。
- **实验**: 山东数据(或 Lago DE),固定基座。对照: ①事件组条件幅度(候选)vs ②全样本幅度 vs ③漂移响应(Drift2Act 式)vs ④无校正。指标: 事件组内 |e_post−e_pre|(幅度误差),漏判率,harm。
- **证伪条件**: 若 ③(漂移响应)在事件组幅度上不劣于 ①,或 ②(全样本)已足够,则候选1 不可还原点消失 → **NO-GO**。

### 1.6 所需数据

- 山东(内部,动机)+ Lago DE(公开,负价重)+ NEM SA1(公开,负价最重)。需: 日前+实时双价、结算延迟结构(逐时/结算时滞)、事件组标签。

### 1.7 最强反例

> 反例: 电价残差的"事件组位置偏移"可能主要是**阈值效应**(y_t≤L⁻ 时残差被截断),而非独立于 occurrence 的 magnitude 结构。若如此,"事件级延迟标签"只是分位数回归在截断分布上的应用(已有),无独立辨识性 → 候选1 还原为"截断分位数回归 + Drift2Act 门控"。

## 5. Codex 更新(2026-08-07): DA 全轨迹 + RT 前缀 → RT 后缀极端修复

### 5.1 候选1′(更新): DA-全轨迹先验 + RT-前缀观测 → RT-后缀极端校正

**正式 problem statement**:
```
市场结构(电价特有): 
  - DA(日前)24h 轨迹 ŷ^{DA}_{1..24} 在当日已知(免费先验,已出清);
  - RT(实时)只观测到截止 14:00 的前缀 y^{RT}_{≤T0}, T0=14:00;
  - 目标: 预测/校正 RT 剩余后缀(15:00-24:00)的极端价格(负价/尖峰)。

校正策略 π: (DA全轨迹, RT前缀, 基座ŷ_BASE) → 动作 A_t ∈ {BASE,NEG,POS} + 幅度 δ_t
信息边界: DA_{1..24} 全可用(非仅前缀!); RT_{≤T0} 可用; RT_{>T0} 是目标(不可观测)。
```

**为什么电价特有**: 大多数市场只有一个价格序列(预测未来用过去前缀)。电价双市场(DA+RT)使**同日 DA 全轨迹成为免费先验**——这不是 TTA 的"用前缀适配",而是"用完整的前市轨迹校准后市后缀"。这是 **dual-market asymmetric-information** 结构。

**学习算子**(允许轻量联合训练):
```
min_θ Σ_{t>T0} ℓ( y^{RT}_t − (ŷ^{RT,base}_t + δ_θ(DA_{1..24}, RT_{≤T0}, z_t)) )
   s.t. 组级风险约束(沿用 v4)
联合训练: 基座可轻量微调(若需),校正头访问 DA/RT 中间表示。
```

### 5.2 与 2021-2026 最近邻的公式级差异

| 近邻 | 机制 | 与候选1′差异 |
|---|---|---|
| **Towards Principled TTA for TSF**(2605.17250, FAC) | 已成熟真值 + 频率域校正 | 用**前缀观测**适配通用时序;**无 DA 全轨迹免费先验**、无双市场 |

### 5.3 潜在不可还原点(需证明)

> **命题(需证明)**: 设 DA 全轨迹 D = ŷ^{DA}_{1..24} 是 RT 后缀的**部分信息**(存在函数使 RT 后缀的极端概率由 D 部分预测),且 RT 前缀 P=RT_{≤T0} 是**补充信息**。则存在校正头 δ_θ(D,P) 使 RT 后缀极端校正的组级 MSE 严格优于: ①只用 P(等价 TTA 单市场)②只用 D(等价 DA-only 预测)③D、P 直接拼接(无信息融合)。且该增益随"DA-RT 偏差的时变结构"增大。

- **假设**: ①DA 与 RT 存在系统性偏差(市场规则/实时供需);②该偏差在日内有结构(非白噪声);③RT 前缀与后缀在该结构上相关。
- **证明难度**: [需证明]——需刻画"DA 作为先验 + RT 前缀作为观测"的信息融合增益(非平凡,可能需两阶段辨识性定理)。
- **可证伪(两周实验)**: 对照 ①仅RT前缀(单市场TTA)②仅DA轨迹(DA-only)③DA+RT拼接④候选1′(信息融合),在 Lago DE/NEM SA1/山东(内部)上测 RT 后缀极端校正的组级幅度误差与漏判率。证伪条件: 若 ③拼接已不劣于④,则无"信息融合"增益 → 候选1′ 还原为特征拼接 → NO-GO。

### 5.4 最强反例

> 反例: DA 与 RT 的偏差可能主要由**全局机制因素**(燃料价/负荷水平)驱动,而非"日内结构"驱动。若偏差在日内近似常数(DA 整体偏高/偏低),则"DA 全轨迹"信息约等于"DA 均值",信息融合退化为"均值偏移校正"(标准 bias correction),候选1′ 还原为"DA-RT 偏差校准"(已知)。**反例成立与否取决于山东/Lago 数据上 DA-RT 偏差的日内结构强度**——两周实验直接测。

### 5.5 与候选1(原版)的关系

- 原候选1(事件级延迟标签 magnitude)被 Drift2Act 强邻挤压,保留为次级;
- **候选1′(DA→RT 双市场)更强**: 它利用电价**特有的信息边界**(DA 全轨迹免费已知),是 TTA/online 单市场不存在的结构。若信息融合增益可证,这是 KDD/AAAI/IJCAI 级算法对象(新算子=双市场信息融合校正,非冻结后处理)。
- **模型无关性代价**: 允许轻量联合训练后,"模型无关"声明需弱化——只保留"基座可替换性"验证(跨 3+ 基座同增益)。

### 5.6 候选1′ 裁决

**裁决: 候选1′ 提升为第一候选(条件性 GO)**,因其利用电价特有"DA 全轨迹免费先验 + RT 前缀观测"的 dual-market asymmetric-information 结构,是 TTA/CSA/Drift2Act 未覆盖的市场结构(非仅"应用位置")。**但必须过两周证伪实验**(信息融合增益 vs 拼接/DA-only/RT-only)与辨识性证明。若失败 → 还原为 DA-RT 偏差校准 → NO-GO,走 Route E。
