## 2. 候选 C1：基座相对结构化损失（base-relative structured loss）

### 2.1 定义与假设
- 训练目标：`min_g E_{S2}[ L_epi( R(b, A_g(b,Z)), y ) ]`，其中 `L_epi` 为事件级损失（如匹配代价、episode recall、IoU 加和），`A_g` 为校正头预测的编辑脚本（18_v7 §3.6），监督来自匹配导出脚本。
- 假设：S2/S3 独立；y 仅作标签；推理无 y。

### 2.2 候选定理
"在冻结基座下，用事件级损失 L_epi 训练与用逐点残差损失训练的 Bayes 最优校正器等价"（等价性）或"L_epi 的 Bayes 一致解存在且可由损失增广推断实现"（一致性）。

### 2.3 证明路线与最近定理族
- 一致性路线：结构化预测的损失分解定理（Ciliberto et al. 2016-2020 "consistent structured prediction" 框架；severe metric regression）——损失可分解为标量损失与映射的复合时可证一致；不可分解时需 loss-augmented inference（SSVM，Tsochantaridis et al. 2005/Joachims 2009）。
- 等价性路线：L_epi 若不含事件间耦合项（如惩罚逐点偏差的总和），则对任意输出，L_epi 与逐点 MAE 差一个仅依赖匹配的常数 → 最优点相同。

### 2.4 还原攻击
事件级匹配损失 = structured prediction 的标准实例（输出空间=编辑脚本，损失=匹配代价）。等价性命题在损失可分解时是教科书事实；不可分解时退化为 SSVM/结构化 SVM。二者均已被占。

### 2.5 反例
L_epi 含"完整事件命中奖励"（recall 型，非可加）时，逐点最小化与事件级最小化不等价：逐点最优（条件中位数逐点）可产生部分覆盖事件，事件级最优要求整事件一致动作 → 等价性不成立。该反例同时说明：等价性只在可分解损失下成立——正是 Ciliberto 框架的适用范围，无新内容。

### 2.6 分类
**standard**（结构化预测一致性的直接例化；等价的分解条件是标准引理）。

## 3. 候选 C2：动作依赖弃权（action-dependent abstention）

### 3.1 定义与假设
- 每个候选动作（REPLACE/DELETE/INSERT，18_v7 §3.4）独立门 λ_a∈{0,1}；风险按动作类型分组控制。
- 假设：门决策仅依赖 S3 校准；动作类型 a 由 g 输出。

### 3.2 候选定理
"按动作类型分组的 selective risk 可同时受控：P(所有组的选择性风险 ≤ α_g) ≥ 1−δ"。

### 3.3 证明路线与最近定理族
分组 RCPS/LTT（风险控制预测集，Bates et al. 2021；learn-to-test，Angelopoulos et al. 2021/2022）+ Bonferroni 预分配（22 号 §3.7 已明确：组少时用预注册 Bonferroni；e-BH 只控 FDR 不适用）。选择性风险（selected risk）本身就是 RCPS 的原生对象。

### 3.4 还原攻击
按动作分组 = 按组做 RCPS/LTT + Bonferroni 校正。22 号 §3.8 已列出 CSA/SCORC/Anytime-Valid CRC 占据"风险控制+动作选择"通用位置；本对象只是把组定义为动作类型。

### 3.5 反例
组间样本量极不平衡（DELETE 在 S3 几乎不出现）时，Bonferroni 分配使稀组保守到无动作——这是已知功效问题，不构成新定理反例，只是实现警告（P0 §4 停损条件 3 已覆盖）。

### 3.6 分类
**standard**（分组 RCPS/LTT+Bonferroni 例化）。

## 4. 候选 C3：事件级伤害预算（episode-level harm budgets）

### 4.1 定义与假设
- 事件级伤害 `H_epi(S) = Σ_{t∈S}( |f̂_t−y_t| − |b_t−y_t| )`（S 为编辑支持内一个事件区间）。
- 预算主张：`Σ_S H_epi(S) ≤ B`（总事件级伤害有界）。

### 4.2 候选定理
"事件级总伤害 ≤ 逐点伤害之和的转化不等式：Σ_S H_epi(S) ≤ ρ·Σ_{t∈U}|b_t−y_t|，其中 ρ 为安全层幅度比 |f̂−b| ≤ ρ·|b−y|"。

### 4.3 证明路线
三角不等式逐点成立后求和（18_v7 §5.1 已列：`|f̂−y|−|b−y| ≤ |f̂−b|`）。一步代数。

### 4.4 还原攻击
这是 18_v7 §5.1 的 harm 分解性质本身；无需外部文献——已经在 v7-C 审计中列为 standard fact（§5 表项 8 + §6 矩阵行）。

### 4.5 反例
事件级"预算"若定义为非加性项（如"最多 2 个事件被改坏"）则不再是转化不等式的对象，而变成组合约束——后者回到 C2 的分组风险或单纯约束优化，仍标准。

### 4.6 分类
**standard**（三角不等式；已在 18_v7 审计为支持性质，不得写成定理）。

## 5. 候选 C4：支持-值耦合决策（support-value coupled decisions）★最佳候选

### 5.1 定义与假设
- 输出 `ŷ_t = b_t + δ_t·s_t`，`s_t∈{0,1}` 支持决策，`δ_t∈R` 值决策（幅度头输出；18_v7 §3.6 的门 λ 即支持决策的事件版）。
- 损失：日级逐点可加损失 `L(ŷ,y) = Σ_t ℓ_t(ŷ_t,y_t)`，`ℓ_t = |·|`（MAE）；校正成本 `c·Σ_t s_t`（每支持点代价，c≥0 常数或特征条件）。
- 假设：(A4-1) 条件分布 `y|Z` 有有限一阶矩；(A4-2) 决策对 `(s,δ)` 逐点独立可行；(A4-3) c 为 S1/S3 预注册。

### 5.2 候选定理（分离定理）
> **定理 C4（MAE 下支持-值决策分离）**：在 A4-1~A4-3 下，日损失 `E[Σ_t(|b_t+δ_t s_t−y_t|) + c Σ_t s_t | Z]` 的 Bayes 最优策略逐点独立：对每个 t，
> `s_t* = 1{ E[|b_t−y_t| | Z] − E[|m_t−y_t| | Z] > c }`，`δ_t* = m_t` 当 `s_t*=1`，
> 其中 `m_t = Med(y_t | Z)` 为条件中位数。等价地，`s_t* = 1{ c < E[|b_t−y_t|−|m_t−y_t| | Z] }`。
> 事件结构（episode 拓扑）不进入最优解：**支持决策与值决策在最优点上解耦**。

### 5.3 证明骨架（完整）
1. **可加性**：期望损失 = `Σ_t E[ |b_t+δ_t s_t−y_t| | Z ] + c Σ_t E[s_t]`——日损失逐点可加、成本线性 → 线性期望交换（Fubini/有限和）。固定 Z 条件下各项只含 t 坐标变量。
2. **逐点最小化**：对每个 t，决策变量 `(s_t,δ_t)` 只出现在第 t 项 → 日级最小化 = 逐点最小化（加法下 argmin 可分离；标准事实）。
3. **值决策**：固定 `s_t=1`，`min_δ E|b_t+δ−y_t|` 的唯一解 `δ_t* = m_t−b_t`（等价地校正后值 = 条件中位数）。这是 Koenzer–Bassett (1978) 条件分位数回归的基本性质：MAE 的 Bayes 点预测为条件中位数【文献事实钩子 1，10c 报告已核验引用】。
4. **支持决策**：`s_t=1` 优于 `s_t=0` iff `E|m_t−y_t| + c < E|b_t−y_t|`；整理得阈值形式。这是 Elkan (2001) 非对称代价分类阈值的回归版：收益=基座与中位数期望绝对偏差之差，代价=c【文献事实钩子 2，10c 报告已核验引用】。
5. **解耦**：步骤 2-4 未使用任何事件间/跨时耦合项（A4-2）→ 最优策略是 P 个独立二元+连续决策，事件拓扑对最优解无影响。
6. **推论 C4.1（编辑-逐点策略重合）**：当校正头可逐点输出 `(s_t,δ_t)` 时（18_v7 P3b 的 C3 值复现性满足），事件编辑算子在 MAE 下的 Bayes 最优策略 = 逐点 BECH 的 Bayes 最优策略——**编辑监督在 MAE 下不改变最优输出**（差异只在训练信号/估计，非策略类）。

### 5.4 最近定理族与还原攻击
- Koenker–Bassett 1978（条件中位数最优性）；Elkan 2001（代价敏感阈值）；Chow 1970（reject option）；损失可加性下决策分离（决策理论教科书）。
- 还原攻击：定理 C4 的每一行都是上述经典结果的直接组合；"分离"本身是加性损失的平凡推论。**不构成新定理**。
- 唯一"非教科书"内容：把它转成**对冻结基座校正器的负面设计定理**（推论 C4.1）——这是对项目设计的有用结论（说明耦合门 λ×δ 在 MAE 下无理论增益），但属于工程推论。

### 5.5 反例
损失含事件级项时（如 `L = Σ_S 1{recall(S)<1}`），步骤 2 的可加性失效，最优策略可能耦合（例：两个相邻事件共享一个校正动作的代价低于分开两个动作）。该反例正是 C1 的领域（结构化预测），且 Ciliberto 框架已覆盖其一致性分析——不使 C4 变新，只说明 C4 的适用边界 = 可加损失。

### 5.6 分类
**standard**（组合经典结果；作为"负面设计定理"对项目有价值——v8-C 最佳候选）。

## 6. 候选 C5：分布偏移感知回退（distribution-shift-aware fallback）

### 6.1 定义与假设
- 对象：检测器 D(Z,b 历史)→偏移信号 + 回退规则（偏移大时输出=b）。
- 假设：S3 校准检测器阈值；检测特征均为截止安全（≥24h 滞后）。

### 6.2 候选定理
"偏移检测报警后回退基座，任意时序的期望 harm 不劣于持续校正"——即回退规则的无退化保证。

### 6.3 证明路线与最近定理族
无退化 = 条件于报警事件的选择性期望比较，标准（E[harm|alarm] ≤ 0 由 S3 检验给出，或由构造恒等 trivially）。检测器族：DAD（drift 检测）、Drift2Act(2603.08578)、Anytime-Valid CRC(2602.04364) 的随流校准。回退本身 = 18_v7 的 exact fallback identity（构造恒等，v7-C 已审为 standard）。

### 6.4 还原攻击
"检测→回退" = drift detection + identity fallback 的组合；任意部分都被 2602.04364/2603.08578/ARC-STAR 占据（22 号 §3.8）。无条件无退化 = 恒等构造的直接推论（已拒类别：fallback identity）。

### 6.5 反例
报警时刻本身不可预测（检测器延迟）时，报警前已发生的 harm 无法回退——这正是 22 号 §3.3 对 B1′ 的"监控器不是 barrier"批评；说明该对象至多提供未来期保护，不是路径保证。

### 6.6 分类
**standard**（drift detection + 构造恒等组合；核心主张落入已拒的 fallback identity）。

## 7. 候选 C6：事件↔点指标转化不等式（episode-to-point metric transfer）

### 7.1 定义与假设
- 事件命中定义（P0 口径）：事件 `S∈E_0(y)` 被预测覆盖 iff `∃ t∈S: ŷ_t<0`（存在命中）或 `∀t∈S: ŷ_t<0`（完整命中）。设点级 recall `r_pt = |{t: y_t<0 且 ŷ_t<0}| / |{t: y_t<0}|`；事件级 recall `r_ev^∃`、`r_ev^∀` 按两种命中定义。

### 7.2 候选定理（确定性转化不等式）
> **定理 C6**：对任意 b、y、τ=0：
> (i) 存在命中口径：`r_ev^∃ ≥ r_pt`（点命中事件必含于被覆盖事件，故事件被覆盖的概率不降）；
> (ii) 完整命中口径：`r_ev^∀ ≤ r_pt ≤ r_pt^+`，且 `r_pt ≥ r_ev^∀ · (1/ℓ_max)` 的精确形式为
> `r_pt ≥ r_ev^∀ / max_S ℓ(S)`（一个完整命中事件贡献 ℓ(S) 个点命中）；
> (iii) 合并：`r_ev^∀ ≤ r_pt ≤ r_ev^∃`，且 `r_pt ≤ r_ev^∃` 紧（交替单点负价时等号）。

### 7.3 证明骨架
纯集合计数：
(i) 若 t 点命中（ŷ_t<0 且 y_t<0），t 属于某真值事件 S；ŷ_t<0 ⇒ S 存在命中 ⇒ S 计入 r_ev^∃ 分子 → 点命中集合 ⊆ 存在命中事件集合并（逐点包含）→ 计数比不等式。
(ii) 完整命中事件 S 的全部 ℓ(S) 个点都是点命中 → 点命中数 ≥ Σ_{S 完整命中} ℓ(S) ≥ r_ev^∀·(min 事件长) 的方向相反：实际 `点命中数 ≥ r_ev^∀ · (Σℓ 的加权)`，取 min ℓ=1 得平凡；用 max_S ℓ(S) 得 `r_pt ≥ r_ev^∀ / ℓ_max`（反例：单点事件，ℓ_max=1，等号）。
(iii) 由定义 (i)+(ii) 直接。

### 7.4 还原攻击与最近族
事件/点指标转化属于事件检测评估文献的常识（Numenta 事件检测评估、pinball 之外的事件指标分析），但**本会话未核验到给出这三条显式不等式的原文**【需证明：检索确认】。即使无原文，推导为一步计数，属集合论标准推论。

### 7.5 反例
(ii) 的下界用 ℓ_max 而非 ℓ_min 反直觉：若所有完整命中事件都很长、漏的全是短事件，则 r_pt 可能远高于 r_ev^∀——如 1 个 20 点事件完整命中 + 20 个 1 点事件漏：r_ev^∀=1/21≈0.048，r_pt=20/40=0.5 → 差距达 10 倍，不等式 r_pt ≥ r_ev^∀/20=0.0024 远非紧。该反例说明转化不等式只能给粗糙下界，实际评估必须双报（P0 已双报）。

### 7.6 分类
**new corollary**（集合计数推论；对 P0 事件评估协议有规范价值——可写入方法附录"指标关系"，不得写成定理贡献）。这是本轮唯一非 standard 分类，但明确为"标准推论的规范化整理"，不达 plausibly new。
