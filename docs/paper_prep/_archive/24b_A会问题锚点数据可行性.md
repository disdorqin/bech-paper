## 二、A会问题锚点候选

### 锚点1：Signed-Tail Selective Correction Benchmark（电价双尾选择性校正基准）

**正式问题陈述**：
> 给定冻结电价预测器，如何构建一个**公开可复现、跨市场×跨基座的严格样本外基准**，系统评估 signed-tail occurrence-magnitude selective correction 的增益、代价与失败模式？

**为什么不是组合**：
- 不是 hurdle/two-part（不建新模型，只做后校正评估）
- 不是 CRC/δ-Adapter/PIR（不做逐点校正，做事件级选择性校正评估）
- 不是 RCPS/CSA（不做序贯风险控制，做事后审计评估）
- **独特性**：电价 signed-tail（负尾可预测/正尖峰稀疏）的事件级后校正评估框架 = **benchmark paper**

**输入输出**：
- 输入：冻结基座预测 + 原始特征 + 事件标签（负尾/正常/正尖峰）
- 输出：三组 harm-utility Pareto + 漏判率/命中率/假阳/逐点伤害 + 失败地图
- 学习算子：无（纯评估框架）

**可独立陈述的性质/定理**：
- **性质**：在 matched-coverage 条件下，signed-tail selective correction 的 harm-utility Pareto 严格优于 unselective correction（即"全校正"），当且仅当负尾可预测性（AP）显著高于正尖峰（AP 差 ≥ 2 倍）
- **可证伪**：若负尾 AP - 尖峰 AP < 2 倍（在任一市场×基座组合），则性质不成立

**两周证伪实验**：
1. 选 3 个公开市场（NEM SA1 / Lago DE / UniElecPrice 某负价国）
2. 选 3 个基座（Linear / LightGBM / LSTM）
3. 计算各市场×基座的负尾 AP 和尖峰 AP
4. 验证 AP 差 ≥ 2 倍的条件是否成立
5. 若任一市场×基座不成立 → 证伪

**所需数据**：
| 数据 | 来源 | 时间 | 粒度 |
|------|------|------|------|
| NEM SA1 DA/RT价格 | AEMO官网 | 2020-2025 | 30min |
| Lago DE DA价格 | Zenodo | 2019-2023 | 1h |
| UniElecPrice 某负价国 | Zenodo | 2019-2023 | 1h |

**最强反例**：
- 某市场×基座组合下，负尾 AP 与尖峰 AP 差 < 2 倍 → 性质不成立
- 或：某基座对负尾的 AP 已经很高（>0.95），选择性校正增益边际递减 → benchmark 无意义

**2021-2026 最近邻原文**：
- CRC (Xie et al., arXiv 2512.22428, 2025)：冻结基座+后校正，但不做事件级选择性评估
- PIR (NeurIPS 2025)：选择性细化，但不做事件级评估
- δ-Adapter (ICLR 2026)：trust-region 校正，但不做事件级评估

### 锚点2：Market-Rule-Aware Selective Correction（市场规则感知的选择性校正）

**正式问题陈述**：
> 给定电价日前预测器和**逐时市场规则注册表**（floor/cap 随市场×产品×时间变化），如何利用规则边界作为**硬可行性约束**，构建一个**零配置、跨市场通用**的选择性校正器，使其在规则变更时无需重新训练？

**为什么不是组合**：
- 不是 clamp/投影（不只是后处理，而是校正器的**动作空间约束**）
- 不是 CRC/δ-Adapter（不学习校正幅度的约束，而是利用**外生规则**作为约束）
- 不是 RCPS/CSA（不做序贯风险控制，做**规则约束下的静态校正**）
- **独特性**：将市场规则注册表作为校正器的**动作空间先验**——这是电价领域的特有结构

**输入输出**：
- 输入：冻结基座预测 + 市场规则注册表（market×product×effective_start×effective_end×floor×cap）
- 输出：校正后的预测（满足规则约束）+ 校正幅度 δ + 是否执行（act/abstain）
- 学习算子：
  - 投影算子：Proj_{[floor_t, cap_t]}(ŷ_base + δ)
  - 选择算子：仅在 base < floor 或 base > cap 时执行（负价漏报检测）

**可独立陈述的性质/定理**：
- **性质**：在规则边界满足 |floor_t - cap_t| ≥ τ（最小价差）的条件下，投影校正器的 harm（base-relative）≤ 未投影校正器的 harm，对任意单调损失函数成立
- **可证伪**：若某市场存在 |floor_t - cap_t| < τ 的时段，投影可能增加 harm

**两周证伪实验**：
1. 选 3 个公开市场（NEM / Lago DE / UniElecPrice 某国）
2. 构建规则注册表（逐市场×逐年×逐时段）
3. 计算各时段的 floor_t / cap_t
4. 验证 |floor_t - cap_t| ≥ τ 的条件
5. 若任一市场有 |floor_t - cap_t| < τ → 证伪

**所需数据**：
| 数据 | 来源 | 时间 | 粒度 |
|------|------|------|------|
| NEM DA/RT价格 | AEMO官网 | 2020-2025 | 30min |
| NEM market price cap/floor | AEMC官网 | 2019-2025 | 年度 |
| Lago DE DA价格 | Zenodo | 2019-2023 | 1h |
| ACER price cap/floor | ACER官网 | 2022-2026 | 年度 |
| UniElecPrice DA价格 | Zenodo | 2019-2023 | 1h |

**最强反例**：
- 某市场×时段 floor_t = cap_t（如负价触发后自动调整为零）→ 投影校正器无动作空间 → 性质不成立
- 或：规则变更频繁（如 ERCOT SWCAP 年年变）→ 零配置假设失效

**2021-2026 最近邻原文**：
- ARC-STAR (arXiv 2605.22222, 2026)：预算感知路由，但不利用市场规则
- CSA (arXiv 2605.20270, 2026)：选择性动作，但不利用市场规则
- δ-Adapter (ICLR 2026)：trust-region 校正，但约束是学习的非外生的

## 四、codex 更新：DA全轨迹+RT前缀→RT后缀极端修复

### 4.1 问题设定

**信息边界**：
- DA全轨迹：前一天发布的24/48时段DA价格（已知）
- RT前缀：当天0:00-14:00的RT价格（已观察）
- RT后缀：当天14:00-24:00的RT价格（待预测/修复）

**目标**：用 DA全轨迹 + RT前缀 → 预测/修复 RT后缀 的极端价格

### 4.3 关键问题：预测DA vs 预测RT 的泄漏风险

**必须区分**：
- **DA价格**：是"预测"还是"实际"？DA价格 = 前一天发布的日前市场出清价 = **实际DA结算价**
- **RT价格**：是"预测"还是"实际"？RT价格 = 当天实时结算价 = **实际RT结算价**

**泄漏风险**：
- 用同日DA价格作为预测RT的输入 = 合法（DA是RT的先验信息）
- 用同日RT前缀作为预测RT后缀的输入 = 合法（时序依赖）
- 用同日RT全量作为预测RT后缀的输入 = **泄漏**（RT后缀本身是目标）

**正确设定**：
```
输入：DA全轨迹（24/48时段）+ RT前缀（0:00-14:00）
输出：RT后缀（14:00-24:00）的极端价格预测/修复
```

### 4.5 数据表构造

**最小数据表 schema**：
```yaml
- timestamp: RT时间戳
- da_price: DA出清价（前一天发布）
- rt_price: RT结算价（实时）
- rt_prefix_available: 布尔（RT前缀是否已观察）

```

**时间切分**：
- 训练集：2020-2023（3年）

**样本功效**：

- 足够支撑统计检验

### 4.6 新锚点候选：DA-RT Prefix-to-Suffix Extreme Repair

**正式问题陈述**：
> 给定DA全轨迹和RT前缀（0:00-14:00），如何预测/修复RT后缀（14:00-24:00）的极端价格？关键挑战：DA-RT偏差在极端时段非线性放大。

**为什么不是组合**：
- 不是标准时序预测（用DA+RT前缀→RT后缀，双源输入）
- 不是在线适应（RT前缀是已观察的真实值，非模型输出）
- 不是漂移检测（极端价格 = 分布尾部，非分布漂移）

**2021-2026 最近邻**：
- DA-RT偏差建模：已有文献（但多为均值偏差，非极端价格）
- 前缀到后缀预测：时序infilling领域（但多为单一序列，非DA-RT双源）
- 极端价格预测：尾部分布建模（但多为DA本身，非DA→RT修复）

**数据可兑现性**：✅ NEM/PJM/EPEX/ENTSO-E 全公开，可复现
