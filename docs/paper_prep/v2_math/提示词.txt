一、必须保留的研究约束

宿主预测器始终冻结。HCH-v2 是模型无关的后处理模块，不修改宿主训练过程。

整体主线保持：

[\text{候选生成}\rightarrow\text{历史证据}\rightarrow\text{保守决策}]

分别对应 Bi-OMC、CAGM、DVG，但允许根据新数学重新定义其内部职责。

最终动作仍为：

[{\text{Identity},\text{Down},\text{Up}}.]

Identity 必须是零修正、零收益锚点，不能由网络学习或漂移。

连续事件按区间选择动作。一个被选中的区间内方向一致，但每小时修正幅度可以不同。所有候选区间可以重叠。

研究必须处理尖峰、低价、零价和负电价。不能因为数值方便而对价格加入任意 floor、clipping 或平移经济零点。

标准无 floor sMAPE、SCR、WSCR 和国内 RT/DA 套利只作为评价指标，不进入反向传播。

实验协议暂不展开。本轮不得读取或利用 S4 的真实标签、残差、损失或动作收益。

不得重新引入：

MAE 加多个辅助损失的拼接；

BCE occurrence + Smooth-L1 magnitude；

任意 tail/location/state loss 权重；

为了复杂而增加 Student-t、skew-t、HMM、copula；

CARA、KL 半径和多个温度参数的堆叠。

二、新数学主线

数学窗口建议的工作名称为：

Identity-Anchored Hyperbolic CRPS（IAH-CRPS）

它不是最终论文命名，也不能在查重完成前宣称首创。

1. 零保持双曲坐标

冻结宿主预测为 (x^0_{d,h})，真实价格为 (Y_{d,h})。

对每个预测日，以当日宿主预测计算：

[ s_d

\operatorname{Median}{|x^0_{d,h}|:|x^0_{d,h}|>0}.]

然后定义

[ \psi_d(p)

\operatorname{asinh}(p/s_d), \qquad d_d(y,x)

|\psi_d(y)-\psi_d(x)|.]

若全天宿主预测全为零，则不得加入任意 (\varepsilon)；应把该情况显式标记为不可识别并回退 Identity。

该距离满足：

[ 2\tanh\left(\frac{d_d(y,x)}2\right)

\frac{2|y-x|}{\sqrt{s_d^2+y^2}+\sqrt{s_d^2+x^2}},]

因此它被解释为标准 sMAPE 比例几何的零保持、非饱和展开，而不是尺度 MAE。

2. 三原子候选

令

[z^0_{d,h}=\psi_d(x^0_{d,h}),\qquadz^y_{d,h}=\psi_d(Y_{d,h}).]

网络每小时只输出两个非负幅度：

[m^-{d,h}\ge0,\qquadm^+{d,h}\ge0.]

定义

[z^-{d,h}=z^0{d,h}-m^-{d,h},\qquadz^+{d,h}=z^0_{d,h}+m^+_{d,h},]

并逆变换：

[x^\pm_{d,h}=s_d\sinh(z^\pm_{d,h}).]

由单调性自动保证

[x^-{d,h}\le x^0{d,h}\le x^+_{d,h}.]

3. 唯一训练准则

三原子条件分布为

[ \widehat P^\theta_{d,h}

\frac13\left(\delta_{z^-{d,h}}+\delta{z^0_{d,h}}+\delta_{z^+_{d,h}}\right).]

唯一逐时损失为

[ \mathcal L_{d,h}^{\mathrm{IAH}}

\frac13 \left( |z^y-z^-| + |z^y-z^0| + |z^y-z^+| \right)

\frac{2}{9}(m^-+m^+).]

全天目标为

[ \mathcal L(\theta)

\mathbb E_d\left[\frac1H\sum_{h=1}^{H}\mathcal L_{d,h}^{\mathrm{IAH}}\right].]

它是一个完整的三原子 CRPS，不得把其中第二项解释成可独立调权的 repulsion regularizer，也不得为它引入额外系数。

在总体条件分布下，两个方向候选具有解析解：

[ x^{-*}

\min\left{x^0,Q_{Y\mid Z}(1/6)\right},]

[ x^{+*}

\max\left{x^0,Q_{Y\mid Z}(5/6)\right}.]

均匀原子权重不是动作概率；DVG 是否执行动作仍由历史收益证据决定。

4. 同一几何下的动作收益

定义

[ g_{d,h,a}

d_d(Y_{d,h},x^0_{d,h})

d_d(Y_{d,h},x^a_{d,h}).]

它满足精确界：

[|g_{d,h,a}|\lem^a_{d,h}.]

后续 CAGM 和 DVG 必须继续使用该收益语义，不能又切回另一套 MAE gain、sMAPE gain 或状态评分。

5. CAGM 的候选分布距离

建议查询日 (q) 与历史日 (j) 的距离采用：

[ D(q,j)

\frac1{3H}\sum_{h=1}^{H}\sum_{a\in{-,0,+}}|z^a_{q,h}-z^a_{j,h}|.]

这是等权有序三原子分布的逐时 (W_1) 闭式距离，不需要学习 metric 权重或 temperature。

6. 查询剂量历史回放

不得直接使用历史日自身候选对应的 raw gain 评价今天的动作。

对于查询日产生的 (m^a_{q,h})，必须考虑能否在历史日 (j) 上回放：

[ \widetilde z^{q\rightarrow j,I,a}_{h}

z^0_{j,h}+\mathbf 1{h\in I}\operatorname{sgn}(a)m^a_{q,h}.]

然后使用历史真实结果重新计算：

[ g^{q\rightarrow j}_{h,I,a}

|z^y_{j,h}-z^0_{j,h}|

|z^y_{j,h}-\widetilde z^{q\rightarrow j,I,a}_{h}|.]

请重点审计现有数据管线和 memory schema 是否支持这种回放。

7. 连续区间与 DVG

全部区间为

[ \mathcal I_H

{[s,e]:1\le s\le e\le H}.]

区间选择发生在候选训练之后，因此不需要对起止点反向传播。

对区间收益定义：

[ G^{q\rightarrow j}_{I,a}

\sum_{h\in I}g^{q\rightarrow j}_{h,I,a},]

[ B^q_{I,a}

\sum_{h\in I} m^a_{q,h}, \qquad X^{q\rightarrow j}_{I,a}

G^{q\rightarrow j}{I,a}/B^q{I,a}\in[-1,1].]

DVG 候选下界为

[ \underline G_{I,a,k}

B^q_{I,a} \left[ \bar X_{I,a,k}

\sqrt{ \frac{2\log(M/\alpha)}{k} }

\rho_{q,I,a,k}\right].]

只有最大下界严格大于零时才执行对应区间和方向，否则返回 Identity。

(\alpha) 是置信水平；(\rho) 是显式跨市场偏移边界。不得把 (\rho=0) 默认为无条件跨市场安全。
