## 1. 项目不可违背的研究约束

### 1.1 主线与动作

- 宿主预测器始终冻结，HCH-v2 是模型无关后处理模块；
- 主线仍是“候选生成 → 历史证据 → 保守决策”；
- 最终逐时输出只能是 `Identity / Down / Up` 之一；
- Identity 是精确零修正锚点，不能学习、漂移或被数值近似替代；
- 候选生成同时服务低价/负价与高价/尖峰，不能只增强上尾；
- 一个预测日可能同时存在低价段和尖峰段，数学决策不能强迫整天只选一个方向；
- 避免人为价格 floor、经济零点平移、硬编码物理负价标签及任意损失拼接。

### 1.2 条件信息与连续状态

项目已经锁定的架构意图是：

- 用预测前可见信息形成连续的低—正常—高上下文，不做硬阈值三分类；
- 该连续状态由低尾和高尾候选共享，不是第三个独立创新点；
- 核心时刻 token 对任意数量外生 token 做交叉注意力；无外生变量时使用 learned-null token；
- 山东等富特征市场、欧洲/美国等少特征市场都要兼容；
- 历史实际外生量必须满足可用时滞，预测外生量必须在预测时可知；
- 允许市场内训练，也要允许多市场联合训练、目标市场校准迁移和真正零样本三种不同协议。

因此，上一版直接“删除 `ContinuousStateHead/state_loss`”只能删除**目标派生的监督状态损失**，不能未经论证地删除连续上下文本身。请在本轮给出正式裁决。

### 1.3 冻结阶段

最终完整架构必须能遵循：

1. S1：训练并冻结宿主；
2. S2：只用宿主样本外预测训练候选生成器；
3. S3：构建历史记忆，并仅在允许的协议下校准决策；
4. 冻结完整 corrector bundle；
5. S4：只读取预测前信息，不读取目标、残差、损失或动作收益。

数学设计中的每个量必须注明属于 `pre-outcome` 还是 `post-outcome`，以及它在哪个阶段生成。

## 2. 已确认成立、可以保留的数学部分

以下判断可作为 v0.2 的起点，但必须写明适用条件。

### 2.1 双曲恒等式与尺度等变

当 \(s>0\) 时，令 \(\psi_s(p)=\operatorname{asinh}(p/s)\)，则：

\[
2\tanh\!\left(\frac{|\psi_s(y)-\psi_s(x)|}{2}\right)
=
\frac{2|y-x|}{\sqrt{s^2+y^2}+\sqrt{s^2+x^2}}.
\]

同时，对任意 \(c>0\)：

\[
|\psi_{cs}(cy)-\psi_{cs}(cx)|=|\psi_s(y)-\psi_s(x)|.
\]

该几何能连续跨越零点，避免标准 sAPE 在异号区间直接饱和；这部分成立。但“由 sMAPE 唯一推导出该几何”仍是过强表述，除非补充公理化唯一性证明。更稳妥的说法是“由 sMAPE 比例结构启发并具有精确平滑对应”。

### 2.2 三原子 CRPS 公式

对有序三原子 \(z^-\le z^0\le z^+\)，等权重 \(1/3\) 时：

\[
\operatorname{CRPS}(P,z^y)
=\frac13\sum_{a\in\{-,0,+\}}|z^y-z^a|
-\frac{2}{9}(m^-+m^+).
\]

这里第二项是 CRPS 的固定组成，不是可调正则项；这一点成立。

### 2.3 受限族的总体投影

在条件分布连续等常规条件下，等权三原子、中央原子固定为宿主时，外侧位置的总体最优解对应 \(1/6\) 与 \(5/6\) 分位投影。它证明的是：

> 在“固定中央原子 + 等权三个原子”这一受限分布族内，CRPS 风险的总体投影。

它不证明三原子分布等于真实完整条件分布，也不自动证明尾部校准。

### 2.4 动作收益界与一维 W1

若动作在双曲坐标中的位移为 \(m^a\)，则由反三角不等式：

\[
|g_{h,a}|\le m^a_h.
\]

对等权、有序的一维原子分布，逐原子差的平均值确为 \(W_1\) 闭式。查询日剂量在历史日重新回放，也比复用历史自身 raw gain 更符合反事实语义。这两项可以保留。

## 3. 必须修订的十二个问题

### Q1. 等权三原子的 \(1/6,5/6\) 候选是否从根本上错过罕见尖峰？

这是最高优先级问题。

当前等权解只追踪第 16.7% 与 83.3% 条件分位。若尖峰在给定上下文后的发生率仍远低于 \(1/6\)，上侧原子可能收缩到 Identity，或者只覆盖普通高价而非真正尖峰。这与项目当前最严重的实证问题——尖峰召回、时序偏差和幅值误差——直接冲突。`asinh` 在大幅度区近似对数，也可能进一步压缩尖峰幅值差异。

请必须完成：

1. 推导一般权重 \((w_-,w_0,w_+)\) 下的外侧总体解；
2. 明确验证：

\[
F_Z(z^{-*})=\frac{w_-}{2},
\qquad
F_Z(z^{+*})=1-\frac{w_+}{2};
\]

3. 解释为何项目应采用等权、固定非等权或上下文自适应权重；
4. 如果引入权重，说明它是概率分布参数而非损失拼接系数，并处理可识别性、坍缩和 Identity 锚点；
5. 给出理论或预注册诊断，证明候选对 p95/p99 尖峰与下尾事件仍有足够剂量；
6. 比较双曲压缩对“相对误差稳健性”和“尖峰绝对幅值恢复”的冲突。

不能用“DVG 会决定是否执行”回避本问题：DVG 只能选择已有候选，无法弥补候选生成器根本没有给出尖峰剂量。

### Q2. properness 与 calibration 的主张必须降到准确边界

请区分三件事：

1. CRPS 对分布预测是 proper scoring rule；
2. 当 \(s\) 在给定预测信息与冻结宿主后固定、且变换可逆时，在变换空间使用 proper score具有合理性；
3. 当前模型只是“固定中央原子的三原子受限族”，总体解是投影，不是对任意真实条件分布的完整恢复。

必须重写主张：

- 不得把“训练使用 proper score”写成“三原子输出已校准”；
- 不得直接比较不同宿主各自使用不同 \(s_d\) 时的 transformed score，并声称它们是同一原始单位风险；
- 说明 \(s_d\) 是宿主可测的条件变换，何时严格 propriety 保留、何时只能说条件上的投影；
- 若权重或尺度也由网络学习，重新审计结论是否仍成立。

可参考 [Pic et al., 2025](https://ascmo.copernicus.org/articles/11/23/2025/) 关于可逆变换与 proper score 的条件，以及 [Bröcker, 2012](https://centaur.reading.ac.uk/29163/) 关于有限集合与分位点关系。

### Q3. 日尺度 \(s_d\) 仍带有经验裁量与数值边界

当前定义：

\[
s_d=\operatorname{Median}\{|x^0_{d,h}|:|x^0_{d,h}|>0\}
\]

具有正齐次性和稳健性，但仍有以下未解问题：

- 只用 24 点，单个日的尺度可能跳变；
- “排除精确零”在数值上不连续；
- 全天接近零但非零时，\(s_d\) 极小会放大噪声；
- 每个宿主产生自己的尺度，跨宿主 score 与检索语义不同；
- \(\sinh(z)\) 在极端坐标可能溢出。

请给出一个明确裁决：保留该尺度并给出公理/稳定性论证，或换成仍满足“预测前可得、正齐次、零点不平移、无需验证集调参”的尺度。必须定义：

- 全零日；
- 近零日；
- 缺失小时与 23/25 小时日；
- mixed precision 与逆变换稳定实现；
- 跨宿主、跨币种比较时的语义。

不得静默加入固定 \(\varepsilon\)。如果确需数值保护，应把数学定义与实现 guard 分开，并证明 guard 只触发显式 Identity fallback。

### Q4. `softplus` 与“精确 Identity 边界”冲突

上一版用 \(m^\pm=\operatorname{softplus}(r^\pm)\)，但 softplus 对有限输入严格大于零，因此网络无法精确给出 \(m=0\)。与此同时，解析解和非坍缩条件允许最优解位于边界 \(m=0\)。

请二选一并正式证明/说明：

- 使用允许精确零的参数化；或
- 明确理论优化在闭包 \(m\ge0\) 上成立、实现只能逼近，并分析对候选、memory 与 DVG 的影响。

Identity 动作本身必须仍是精确宿主值，不能因外侧候选的极小非零位移而漂移。

### Q5. 删除目标派生状态损失，不等于删除共享连续状态

旧代码的 `ContinuousStateHead` 有严重单位错误：normalized target 被拿去查询 raw S1 CDF，因此不能保留原实现。但是项目的连续状态是“低—正常—高软上下文”，目的是让低尾与高尾共享条件信息，并适配没有物理负价的数据集。

请裁决一个不使用未来目标的定义，例如可考虑但不限于：

\[
u_{d,h}=\widehat F^{\mathrm{S1}}_{m,h}(x^0_{d,h})\in(0,1),
\]

其中 CDF 只由市场/目标/小时的 S1 宿主预测建立；或从 IAH 候选分布本身导出连续尾部坐标。要求：

- S4 可计算；
- 不需要低/正常/高硬阈值；
- 上下尾共享；
- 不引入独立 state loss；
- 说明它进入候选网络、检索或两者何处；
- 未见市场如何处理。

如果你坚持完全删除连续状态，必须证明候选三原子几何已充分承担同一职责，并解释为何不损害“无负价数据也能自适应低价”的核心项目动机。

### Q6. 一个区间、一个方向不能覆盖同日双尾

当前 DVG 最终只选 \((I^*,a^*,k^*)\) 一个动作。若同一天凌晨出现负价、傍晚出现尖峰，单一区间同向动作必然漏掉其中一端，或用跨越正常时段的大区间造成伤害。

建议优先审计以下闭合方案：

1. 对所有 `interval × direction × k` 建立同时有效的下界；
2. 保留所有严格正 LCB 候选；
3. 用 weighted interval scheduling 在**互不重叠**候选中最大化 LCB 总和；
4. 因收益对不重叠小时可加，若所有单区间下界同时成立，则被数据依赖选出的任意不重叠集合也有总和下界；
5. 未选小时保持 Identity。

请给出正式定理条件，并说明同方向相邻区间是否合并、跨方向重叠如何裁决、一个日最多多少段。不要引入人为固定事件长度。

### Q7. 候选 W1 是否足以代替“当前情景 key”？

项目原本希望用当前宿主轨迹、周期语义、市场信息和任意外生变量生成 query key。上一版完全用三原子候选 W1 检索，优点是确定、无随机 metric；风险是：两个候选曲线相近但气象、供需或市场机制不同的日可能具有不同反事实收益。

请在以下两条中做唯一裁决：

- **充分表示路线**：证明/明确假设三原子输出近似条件分布，因此其几何足以作为动作收益检索表示；外生信息只通过候选生成器间接进入；或
- **条件检索路线**：保留 pre-outcome 条件 key，但给出不依赖未训练随机 metric、也不靠任意距离加权的 principled 构造。

无论选哪条，都必须保留：

- 任意数量外生变量与 learned-null；
- 周期信息/历史记忆只来自预测时可见信息；
- query 侧不得读取真实结果；
- memory 明确分离 `retrieval_key_pre_outcome` 与 `replay_outcome_post_outcome`。

### Q8. 查询日与历史日使用不同尺度时，W1 和剂量回放的语义是什么？

查询日在 \(s_q\) 下产生 \(m^q\)，历史日在 \(s_j\) 下拥有 \(z_j^0,z_j^y\)。将 dimensionless 的 \(m^q\) 直接加到历史 \(z_j^0\) 具有尺度等变直觉，但需要严谨说明：

- 它回放的是“相同双曲位移”还是“相同相对经济剂量”；
- 不同宿主与不同市场的 \(s\) 是否仍可比；
- W1 计算中两日各自坐标系是否可直接相减；
- 如果它们只是归一化语义相似度，应如何限制跨市场论文主张。

请给出变换群/等变性层面的解释，或修改距离与回放定义。

### Q9. Hoeffding LCB 的独立性条件与时间序列现实不匹配

历史近邻日不是 i.i.d. 抽样：电价存在周周期、季节、制度变化与连续极端事件。即使检索 key 不使用结果，近邻选择后的收益仍可能相关和分布漂移。

请把当前“条件独立或有界鞅差”的一句话扩展为可执行方案：

- 若用 martingale，请定义 filtration，并证明检索/排序不泄漏未来结果；
- 若用 \(\beta\)-mixing，请给 block 构造、有效样本量和相应半径；
- 若用 conformal/经验 Bernstein/confidence sequence，请说明与邻域选择和多重比较如何兼容；
- 训练、S3 校准和 S4 推理的时间顺序必须严格单向。

可参考有界 \(\beta\)-mixing 序列浓缩文献，如 [Banna et al.](https://arxiv.org/abs/1701.05380)。不要把 i.i.d. Hoeffding 直接包装成时间序列安全保证。

### Q10. 当前同时检验下界可能几乎永远拒绝动作

若 \(H=24\)、枚举 600 个“区间×方向”，并把所有 \(k=1,\ldots,N\) 都纳入选择，则 \(M=600N\)。仅 Hoeffding 惩罚项、尚未扣除 \(\rho\) 时：

| 可用历史日 \(N\) | 在 \(k=N\) 时的 \(\sqrt{2\log(M/0.05)/k}\) |
|---:|---:|
| 50 | 0.730 |
| 100 | 0.529 |
| 200 | 0.383 |
| 400 | 0.277 |

归一化收益 \(X\in[-1,1]\) 必须超过该值才会放行，短数据集上很可能退化为 Identity。请完成一个理论 power analysis，并给出**不以牺牲有效性为代价**的改进：例如预注册稀疏 \(\mathcal K\)、经验 Bernstein、共享前缀 confidence sequence、block-effective sample size 或其他闭合方法。

不得仅通过调大 \(\alpha\)、删除多重比较项或事后挑 \(k\) 让结果变好。

### Q11. \(\rho\) 在真正零样本目标市场不可识别

必须把协议拆成三种，不能混称“跨市场安全”：

| 协议 | 目标市场标签可见性 | 允许的主张 |
|---|---|---|
| 市场内冻结 | S2/S3 可见，S4 不可见 | 市场内历史条件下的经验/理论安全 |
| 目标校准迁移 | 源市场训练，目标市场 S3 可见 | 经目标校准的迁移安全 |
| 真零样本 | 目标市场任何结果均不可见 | 若无先验偏移界，不能给非平凡安全保证 |

请定义 \(\rho_{q,I,a,k}\) 到底约束哪两个条件期望、如何估计、估计不确定性如何进入下界。若真零样本没有可验证上界，应明确：要求保证时回退 Identity；否则只能做无保证的探索性预测，不能使用“safe”。

可参考最近邻在 covariate shift 下的条件与限制，例如 [JMLR 2024 的相关分析](https://www.jmlr.org/papers/volume25/24-0890/24-0890.pdf)。

### Q12. 名称与论文主张需要诚实对齐

上一版删除 occurrence head 后，`Bi-OMC` 已不再显式表示 occurrence–magnitude 分解；\(m^-\)、\(m^+\) 更接近“以 Identity 为锚的下/上条件分位位移”。请裁决：

- 重新定义名称与机制；或
- 给出 occurrence 如何从原子质量、边界坍缩或 DVG 动作概率中自然出现。

不得继续用一个已被删除的二分类器语义宣传“发生—幅值联合建模”。同时，`IAH-CRPS`、`CAGM`、`DVG` 都只能作为工作名，未完成查重前不得宣称首创。

## 4. 最新仓库证据：旧数学审计不能作为 IAH 的实证依据

最新仓库增加了 `experiments/00-data-exploration/math_loss/`，但当前脚本不能证明旧 Student-t/W2，也不能证明 IAH。v0.2 必须主动排除以下证据：

1. `run_math_evidence_audit.py` 使用 `pred-y`，而项目主残差语义是 `y-host`；
2. candidate audit 在同一 S3 上用真实残差符号决定 Down/Up，再在同一数据评分，属于 oracle/in-sample；
3. `student_t_cdf` 实现错误，例如 \(\nu=5,x=5\) 附近返回约 0.502，而正确 CDF 约 0.998；
4. block bootstrap 用有放回抽样日后再 `np.isin`，重复抽中的日被折叠，置信区间无效；
5. 配对差异被独立重采样，破坏 paired structure；
6. 日相关性用 `arange(n)//24` 伪造日期，未按真实 timestamp；
7. 未按小时/季节去中心的原始二阶矩被称为相关性，SVD 后又平方奇异值；
8. `rm3_*` 实际计算 median absolute residual，却被标成 skew；
9. 共享日尺度 latent 即便存在，也主要诱导误差幅值依赖，不能单独解释 signed residual 的共同偏差。

因此请不要引用仓库中“Student-t partial / W2 supported / partial moment viable”作为新架构前提。IAH 必须依赖自身推导，后续再由无泄漏实验验证。
