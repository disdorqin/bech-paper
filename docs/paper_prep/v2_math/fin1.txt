你的批评成立：把 (|Y-\hat Y|/s) 换个尺度，仍然只是归一化 MAE，既没有真正建模条件分布，也不能解析推出 Identity–Down–Up。它不应成为论文主方法。

我建议把数学主线正式收敛为：

[
\boxed{
\text{零保持电价几何}
\rightarrow
\text{Identity 锚定三原子分布}
\rightarrow
\text{单一 proper score}
\rightarrow
\text{解析双向候选}
\rightarrow
\text{同几何历史回放}
\rightarrow
\text{区间下置信路由}
}
]

暂定名称：**Identity-Anchored Hyperbolic CRPS，IAH-CRPS**。

## 一、不是修改 sMAPE，而是从 sMAPE 的几何出发

标准逐点 sAPE 为

[
\operatorname{sAPE}(y,x)
========================

\frac{2|y-x|}{|y|+|x|}.
]

它不适合直接反向传播：

* 当 (xy<0) 时，

[
|y-x|=|y|+|x|,
\qquad
\operatorname{sAPE}(y,x)=2,
]

因此只要预测和真实值仍异号，梯度恒为零。

* 在 ((y,x)=(0,0)) 处无定义。
* 接近零时，一个很小的绝对误差也可能直接饱和到 (200%)。

这些并非实现问题，而是公式本身的性质。sMAPE 等比例指标的退化问题在预测评价文献中也早有讨论，[Hyndman & Koehler, 2006](https://robjhyndman.com/publications/another-look-at-measures-of-forecast-accuracy/)。

### 1. 零保持双曲坐标

对第 (d) 天冻结宿主预测 (x^0_{d,1:H})，定义一个不使用真实标签的日级尺度：

[
s_d
===

\operatorname{Median}
\left{
|x^0_{d,h}|:\ |x^0_{d,h}|>0
\right}.
]

它等价于非零宿主价格绝对值的 (L_1) 最优中心，不通过验证集调参。如果全天宿主预测全为零，则 (s_d) 不可识别，模块直接返回 Identity，而不是人为加入 (\varepsilon)。

定义

[
\psi_d(p)=\operatorname{asinh}\left(\frac{p}{s_d}\right),
]

以及价格距离

[
d_d(y,x)
========

|\psi_d(y)-\psi_d(x)|.
]

电价文献已经使用 asinh 处理尖峰、近零和负价格；它的合理性有现成依据，但不能把“使用 asinh”本身宣称为创新。[Uniejewski, Weron & Ziel, 2018](https://doi.org/10.1109/TPWRS.2017.2734563)

### 2. 与 sMAPE 的精确关系

有恒等式

[
\boxed{
2\tanh\left(\frac{d_d(y,x)}2\right)
===================================

\frac{2|y-x|}
{\sqrt{s_d^2+y^2}+\sqrt{s_d^2+x^2}}
}
]

而当 (s_d\downarrow0) 时，右端趋于标准 sAPE：

[
\frac{2|y-x|}
{\sqrt{s_d^2+y^2}+\sqrt{s_d^2+x^2}}
\longrightarrow
\frac{2|y-x|}{|y|+|x|}.
]

所以 (d_d) 不是随意选择的尺度 MAE，而是：

> sMAPE 潜在比例几何的零保持、非饱和展开。

它具有三种自然行为：

[
d_d(y,x)
\approx
\begin{cases}
|y-x|/s_d, & |x|,|y|\ll s_d,[2mm]
|\log(|y|/|x|)|, & xy>0,\ |x|,|y|\gg s_d,[2mm]
\text{连续跨越零点}, & xy\le0.
\end{cases}
]

并且

[
\left|
\frac{\partial d_d(y,x)}{\partial x}
\right|
=======

\frac1{\sqrt{s_d^2+x^2}},
]

异号时不再出现 sMAPE 的零梯度。低价没有被 floor 掉，而是进入分辨率最高的线性区域。

若所有价格和 (s_d) 同时乘以正的单位转换系数 (c)，则

[
d_{cs_d}(cy,cx)=d_{s_d}(y,x),
]

因此它天然跨币种和跨价格量级等变。

## 二、真正的单一训练准则：Identity 锚定三原子 CRPS

关键点是：**(d_d) 只是底层价格几何，并不是训练损失本身。**

令

[
z^0_{d,h}=\psi_d(x^0_{d,h}),
\qquad
z^y_{d,h}=\psi_d(Y_{d,h}).
]

网络每小时只输出两个非负数：

[
m^-*{d,h}\ge0,
\qquad
m^+*{d,h}\ge0.
]

候选定义为

[
z^-*{d,h}=z^0*{d,h}-m^-*{d,h},
\qquad
z^+*{d,h}=z^0_{d,h}+m^+_{d,h}.
]

回到原始价格：

[
x^-*{d,h}=s_d\sinh(z^-*{d,h}),
\qquad
x^+*{d,h}=s_d\sinh(z^+*{d,h}).
]

由 (\sinh) 单调可得

[
x^-*{d,h}\le x^0*{d,h}\le x^+_{d,h},
]

所以 Down/Up 的符号约束不需要 BCE occurrence head。

### 1. 条件分布模型

用三个有序原子表示最小条件分布：

[
\widehat P^\theta_{d,h}
=======================

\frac13
\left(
\delta_{z^-*{d,h}}
+
\delta*{z^0_{d,h}}
+
\delta_{z^+_{d,h}}
\right).
]

三分之一不是动作发生概率，而是无额外概率参数的均匀求积权重。DVG 最终是否采取动作，仍由历史收益证据决定。

### 2. 唯一训练损失

对该三原子分布使用标准 CRPS：

[
\mathcal L_{d,h}^{\mathrm{IAH}}
===============================

\frac13
\sum_{a\in{-,0,+}}
|z^y_{d,h}-z^a_{d,h}|
---------------------

\frac1{18}
\sum_{a,b\in{-,0,+}}
|z^a_{d,h}-z^b_{d,h}|.
]

由于三个原子有序，可以化为

[
\boxed{
\mathcal L_{d,h}^{\mathrm{IAH}}
===============================

\frac13
\left(
|z^y-z^-|
+
|z^y-z^0|
+
|z^y-z^+|
\right)
-------

\frac{2}{9}(m^-+m^+)
}
]

全天训练目标仅为

[
\boxed{
\mathcal L(\theta)
==================

\mathbb E_d
\left[
\frac1H\sum_{h=1}^{H}
\mathcal L_{d,h}^{\mathrm{IAH}}
\right].
}
]

没有：

* BCE occurrence；
* Smooth-L1 magnitude；
* location/Wasserstein 辅助损失；
* state supervision；
* Student-(t) NLL；
* 手调损失权重。

虽然公式中有“观测吸引项”和“原子间分离项”，它们不是两项人为拼接的损失。第二项是 CRPS 成为 proper score 所必需的组成，系数 (1/3)、(1/18)、(2/9) 全部由三原子概率测度唯一确定。[Gneiting & Raftery, 2007](https://doi.org/10.1198/016214506000001437)

asinh 是单调双射，因此在条件尺度 (s_d) 已由宿主确定时，把观测和分布同时变换后使用 CRPS 仍保持 propriety；一般变换原则可见 [Pic et al., 2025](https://ascmo.copernicus.org/articles/11/23/2025/)。这里需要的尾部条件只是

[
\mathbb E\left[
\left|\operatorname{asinh}(Y/s_d)\right|
\mid Z
\right]<\infty,
]

远弱于要求原始电价具有有限方差。

## 三、候选具有解析总体解

设变换后真实价格的条件分布函数为 (F_Z)。固定 Identity 原子 (z^0)，对下侧原子求导：

[
\frac{\partial}{\partial z^-}
\mathbb E[
\mathcal L^{\mathrm{IAH}}\mid Z
]
=

\frac13\left(2F_Z(z^-)-1\right)+\frac29.
]

令其等于零：

[
F_Z(z^{-*})=\frac16.
]

同理，

[
\frac{\partial}{\partial z^+}
\mathbb E[
\mathcal L^{\mathrm{IAH}}\mid Z
]
=

\frac13\left(2F_Z(z^+)-1\right)-\frac29,
]

因此

[
F_Z(z^{+*})=\frac56.
]

加入相对宿主的方向约束后：

[
\boxed{
z^{-*}
======

\min\left{
z^0,Q_{\psi(Y)\mid Z}(1/6)
\right},
}
]

[
\boxed{
z^{+*}
======

\max\left{
z^0,Q_{\psi(Y)\mid Z}(5/6)
\right}.
}
]

由于 (\psi) 严格递增，回到原始电价就是

[
\boxed{
x^{-*}
======

\min\left{
x^0,Q_{Y\mid Z}(1/6)
\right},
\qquad
x^{+*}
======

\max\left{
x^0,Q_{Y\mid Z}(5/6)
\right}.
}
]

也可写成宿主残差 (R=Y-x^0)：

[
\Delta_-^*
==========

\min{0,Q_{R\mid Z}(1/6)},
\qquad
\Delta_+^*
==========

\max{0,Q_{R\mid Z}(5/6)}.
]

这正是用户所要求的“从条件分布建模，经方程推出专用动作”，而不是先拍脑袋定义 Down/Up 标签。

在连续分布下还得到非坍缩条件：

[
m^{-*}>0
\iff
\Pr(Y<x^0\mid Z)>\frac16,
]

[
m^{+*}>0
\iff
\Pr(Y>x^0\mid Z)>\frac16.
]

候选只有在一侧条件质量确实不足时才收缩到 Identity。CRPS 与有限集合分位点的关系属于已有理论，[Bröcker, 2012](https://doi.org/10.1002/qj.1891)；我们的贡献不能写成“发现了 (1/6,5/6)”，而应是固定宿主锚点后的双向动作投影及后续整条闭环。

标准 CRPS 应保留。所谓 fair CRPS 针对可交换的随机 ensemble draws；这里三个原子是确定性的动作支撑点，不是独立抽样成员。

## 四、同一个几何继续贯穿 CAGM 和 DVG

### 1. 动作收益与精确有界性

定义逐时动作收益：

[
g_{d,h,a}
=========

## d_d(Y_{d,h},x^0_{d,h})

d_d(Y_{d,h},x^a_{d,h}).
]

由反三角不等式：

[
\boxed{
|g_{d,h,a}|
\le
d_d(x^0_{d,h},x^a_{d,h})
========================

m^a_{d,h}.
}
]

这比“假设残差服从 Student-(t)”更强：即使原始残差无有限方差，有限动作产生的相对收益仍天然有界。

### 2. CAGM 不再学习一套未解释的 key metric

对查询日 (q) 和历史日 (j)，使用三原子分布的平均一维 (W_1)：

[
\boxed{
D(q,j)
======

\frac1{3H}
\sum_{h=1}^{H}
\sum_{a\in{-,0,+}}
|z^a_{q,h}-z^a_{j,h}|.
}
]

这是等权有序原子分布的一维 Wasserstein-1 闭式解，不需要 metric head、投影权重或 temperature。

### 3. 历史回访必须回放“今天的剂量”

对查询候选 (m^a_{q,h})，在历史日 (j) 上重新计算：

[
\widetilde z^{,q\rightarrow j,I,a}_{h}
======================================

z^0_{j,h}
+
\mathbf 1{h\in I}
,\operatorname{sgn}(a)m^a_{q,h}.
]

历史反事实收益：

[
g^{q\rightarrow j}_{h,I,a}
==========================

## |z^y_{j,h}-z^0_{j,h}|

|z^y_{j,h}-\widetilde z^{,q\rightarrow j,I,a}_{h}|.
]

这样历史日评价的是“如果当时施加今天这条修正曲线会怎样”，而不是把不同剂量的 raw gain 混在一起。

### 4. 连续区间不需要求导

枚举

[
\mathcal I_H
============

{[s,e]:1\le s\le e\le H}.
]

当 (H=24) 时只有 (300) 个区间，两个方向共 (600) 个候选。它们可以完全重叠。方向在区间内一致，但 (m^a_{q,h}) 逐小时不同。

区间选择属于冻结候选之后的决策，因此无需对起止点反向传播，也不需要 soft boundary。密集起止点枚举在时间区间检测中已有成熟先例，例如 [BMN, ICCV 2019](https://openaccess.thecvf.com/content_ICCV_2019/html/Lin_BMN_Boundary-Matching_Network_for_Temporal_Action_Proposal_Generation_ICCV_2019_paper.html)；这里不把枚举本身作为创新。

### 5. DVG 用下置信值自动选择区间、方向和邻域

定义

[
G^{q\rightarrow j}_{I,a}
========================

\sum_{h\in I}g^{q\rightarrow j}*{h,I,a},
\qquad
B^q*{I,a}
=========

\sum_{h\in I}m^a_{q,h}.
]

于是

[
X^{q\rightarrow j}_{I,a}
========================

\frac{G^{q\rightarrow j}*{I,a}}{B^q*{I,a}}
\in[-1,1].
]

对前 (k) 个邻居：

[
\bar X_{I,a,k}
==============

\frac1k\sum_{j\in N_k(q)}
X^{q\rightarrow j}_{I,a}.
]

若同时检验的区间、方向和邻域前缀总数为

[
M=H(H+1)|\mathcal K|,
]

则一侧 Hoeffding 下界为

[
\boxed{
\underline G_{I,a,k}
====================

B^q_{I,a}
\left[
\bar X_{I,a,k}
--------------

## \sqrt{\frac{2\log(M/\alpha)}{k}}

\rho_{q,I,a,k}
\right].
}
]

其中：

* (\alpha) 是唯一的决策置信水平，不是训练权重；
* (\rho) 是必须明示的源—目标条件增益偏移上界。

最终选择：

[
(I^*,a^*,k^*)
=============

\arg\max_{I,a,k}
\underline G_{I,a,k},
]

[
\boxed{
\text{若 }\underline G_{I^*,a^*,k^*}>0
\text{ 则执行；否则 Identity。}
}
]

在历史归一化收益为条件独立或有界鞅差、检索不使用结果信息，并且 (\rho) 有效的前提下，由 Hoeffding 不等式及 union bound 可保证：所选动作的**条件期望双曲收益为正**。[Hoeffding, 1963](https://doi.org/10.1080/01621459.1963.10500830)

它不保证：

* 每一天都改善；
* 每一天都套利盈利；
* 自动改善原始 sMAPE；
* 无条件跨市场安全。

零样本下若不能给出有效 (\rho)，非平凡安全保证在数学上不可识别；最坏情况下唯一普遍安全策略就是永远 Identity。这个边界应主动写进论文。

## 五、交给代码窗口的改造契约

在当前 [HCH-v2 实现](https://github.com/disdorqin/bech-paper/blob/main/src/hch_v2.py) 上建议这样融合：

1. 保留冻结宿主和现有 encoder。

2. Bi-OMC 删除四个 occurrence/magnitude 输出，改成每小时两个标量：

[
(r^-*{h},r^+*{h})
\mapsto
(m^-*{h},m^+*{h})
=================

(\operatorname{softplus}(r^-*{h}),
\operatorname{softplus}(r^+*{h})).
]

3. 删除 `candidate_loss = BCE + SmoothL1 + W1`，只实现完整 IAH-CRPS；不能为了少算一项而删除固定宿主项，否则数值不再是合法 CRPS。

4. 删除 target-derived `ContinuousStateHead/state_loss`。日内联合依赖交给整日历史回放，不再另建 HMM 或状态损失。

5. Encoder 可以继续使用标准化特征，但 loss、候选逆变换和收益必须基于原始价格。当前 [数据处理](https://github.com/disdorqin/bech-paper/blob/main/src/hch_v2_data.py) 的均值中心化会移动经济零点，不能直接拿其中心化价格计算本损失。

6. CAGM memory 保存：

[
(z_j^-,z_j^0,z_j^+,z_j^y,s_j,\text{pre-outcome metadata}),
]

不再只保存历史 raw gains。所有 key 必须在结果发生前生成。

7. 用闭式 (W_1) 替换 `key_net/cand_proj/fusion/metric_proj`。按当前 smoke 训练路径，这些检索部件没有明确进入候选监督链；确定性距离也消除了随机未训练 metric 的风险。

8. DVG 删除 CARA (\eta)、KL 半径、softmax temperature 和固定 (k)，改为全区间、全邻域前缀的同时 LCB。

最终核心自由度为：

| 对象               |               数量 |
| ---------------- | ---------------: |
| 每小时网络输出          |                2 |
| 损失组合权重           |                0 |
| Student-(t)/偏态参数 |                0 |
| 状态/HMM 参数        |                0 |
| 检索距离参数           |                0 |
| 决策参数             |       仅 (\alpha) |
| 跨市场假设            | 显式 (\rho)，不能暗中调参 |

## 六、论文主张边界

可以主张的潜在贡献是：

> 从标准 sMAPE 的比例结构推导零保持、非饱和的双曲价格几何；在该几何上构造以冻结宿主为中央原子的三点条件分布，以单一 CRPS 解析推出双向候选；继而用同一几何定义 Wasserstein 检索、查询剂量历史回放、有界区间收益和 Identity 下置信路由。

不能主张：

* 首次使用 asinh；
* 首次使用 CRPS；
* 首次发现 (1/6,5/6) 分位点；
* 残差真实服从某个分布；
* 零样本跨市场无条件安全。

我针对 asinh、CRPS、有限 ensemble 分位理论、WTA/MCL、区间选择和安全路由做的检索中，没有找到与上述整条链完全同构的工作；但目前只能写成“未发现完全同构方案”，正式投稿前仍需系统综述查重。旧版 WTA/min-loss 应保留为强消融，因为它与 [Stochastic Multiple Choice Learning](https://arxiv.org/abs/1606.07839) 及后续 WTA 量化理论已有明显重合，[Letzelter et al., ICML 2024](https://proceedings.mlr.press/v235/letzelter24a.html)。

标准、无 floor 的 sMAPE、SCR、WSCR 均只用于评价。若数据存在精确的 ((0,0))，论文必须单独声明该项如何定义，不能静默加入数值下限。国内 RT/DA 套利只作为应用结果；凡触发规则使用“明日实际日前价格”的，都只能称事后诊断或 oracle 分析，不能称可执行交易收益。

这版已经可以交给代码窗口实现原型，但还不能标记为“论文定理已验证”。冻结前只需在 S2→S3、绝不读取 S4 地核验三件事：(1/6,5/6) 校准、低价/异号区的梯度与收益、以及历史回放 LCB 的覆盖率。若这三项成立，这条线比尺度 MAE、Student-(t) NLL 或多损失拼接都更接近你最初想要的“由数据场景推出一个专用数学动作”。
