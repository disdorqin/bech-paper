## 1. 首要生死公式

对预测时可用输入 `x=(b,Z)`、动作 `a`、编辑算子 `T` 和 episode loss，定义

```math
H(a;x,Y)=L_{ep}(T(b,a),Y)-L_{ep}(b,Y).
```

由于第二项与动作 `a` 无关，

```math
\arg\min_a \mathbb E[H(a;x,Y)\mid x]
=\arg\min_a \mathbb E[L_{ep}(T(b,a),Y)\mid x].
```

因此，“直接学习相对基座 harm”本身**不会产生新的 Bayes 决策**。它通常可还原为绝对结构化风险最小化；`base-relative` 可能只在 S3 安全选择或论文解释中有意义。

候选必须额外找到至少一种严格差异：

1. 相同信息和动作类下的决策分离；
2. 可实现算法或计算复杂度分离；
3. 严格的有限样本半径/样本复杂度分离；
4. 现有 RCPS/LTT/CSA/structured prediction 无法直接推出的保证。

若做不到，必须在真实实验前判 `NO-GO`，不能靠扩大网络或数据集制造差异。

## 2. 冻结的 Phase-B 对象

以下对象由总指挥冻结。任何 Agent 发现其不自洽时只能报告 `SPEC INVALID`，不得静默修改。

### 2.1 数据、信息与切分

- 审计单位：一个完整交付日，优先 `H=24`。
- 输入：`b=f_0(I)\in\mathbb R^H` 为冻结基座输出；`Z=z(I,b)` 只能含预测截止时可得信息。
- 真值：`Y\in\mathbb R^H`，只可在 S2 构造监督、S3 标定和 S4 锁定评估时使用。
- 推理动作：`A=\pi(b,Z)` 必须对预测信息集可测；API 不得接收 `Y`。
- 协议：S1/S2/S3/S4=`50%/20%/10%/20%` rolling-origin。S1 冻结基座，S2 学策略，S3 只选策略/发证，S4 只测试。
- 跨日 episode：主方案按 24 小时窗口截断并记录 left/right censor 标志；若改用连续轴完整事件，必须在看 S3/S4 前预注册并全部方法共用。

### 2.2 Episode、动作与编辑器

```math
S(y)=\{t:y_t<0\},\qquad E(y)=CC(S(y)),
```

其中 `CC` 返回最大连续区间。零值不算负价，缺失与重复小时先处理。

- 动作词表：`KEEP/DELETE/REPLACE/INSERT`。`SHIFT/SCALE` 只是 `REPLACE` 的特例。
- 编辑器：`T(b,KEEP)=b`；区间重叠、越界、冲突、tie rule 必须确定。
- 主预算只选一种：最多编辑 `K` 个 episode，或 `||T(b,a)-b||_1<=B_amp`。另一种最多作为后续敏感性。
- 结构预算、风险容忍 `epsilon`、失败概率 `alpha` 三者必须分开。

### 2.3 有界非可加事件损失

```math
L_{ep}=w_mL_{miss}+w_fL_{fp}+w_bL_{boundary}+w_vL_{value}\in[0,1].
```

- 用带 dummy 的真正线性分配/Hungarian matching。
- 未匹配真实事件计 miss，未匹配预测事件计 false positive；匹配事件计起止边界，可选幅度/轨迹项。
- 权重、归一化、空集合约定和 tie rule 在查看 S3/S4 前固定。
- `Hungarian + non-additive loss` 只是问题定义，不得列为创新。

### 2.4 相对风险与零退化

```math
\Delta_\pi(D)=L_{ep}(T(f_0(I),\pi(f_0(I),Z)),Y)-L_{ep}(f_0(I),Y),
```

```math
R_{rel}(\pi)=\mathbb E[\Delta_\pi(D)].
```

目标保证为

```math
\Pr_{S3}\{R_{rel}(\hat\pi)\le\epsilon\mid S2\}\ge 1-\alpha.
```

`epsilon=0` 才可称高概率总体非退化；若只能得到 `epsilon>0`，必须称 `epsilon`-non-degradation。逐实例不劣、测试集经验零退化和事后报警都不是上述保证。

1. Agent A 尽力还原并杀死候选。
2. Agent B 在同一冻结对象上写 theorem sheet，先证明最低正确性，再寻找非平凡差异。

4. 总指挥逐式复算、核验来源、交叉检查三份报告，并做唯一的 `GO/PIVOT/NO-GO` 裁决。

## 4. Agent A：最强还原与不可约性红队

### 4.1 核心任务

尝试用以下成熟组合保持原对象地复制候选：

```text
absolute interval/set structured prediction
+ residual/value reconstruction
+ constrained decoding
+ paired selective risk control
```

分别裁决 object、algorithm、theory 三层，不得只攻击逐点分类器这一弱基线。

### 4.2 四个 reduction lemma

- R1 表示映射：候选动作输出能否双射为绝对结构化输出。
- R2 目标映射：利用第 1 节公式比较 Bayes 决策。
- R3 动作/预算映射：标准 constrained decoder 是否保持 support、边界、数值轨迹、预算和 identity。
- R4 保证映射：对成对 harm 使用相同 S3、相同候选族和 simultaneous validity 时，RCPS/LTT 类工具能否给出相同保证。

必须区分“oracle 可表示”与“已知可实现算法”：oracle 等价只能杀死新对象，不自动杀死算法贡献。

### 4.3 最强组合基线

```math
h_\eta(b,Z)=D_B(q_\theta(\cdot\mid b,Z),r_\phi(b,Z,\cdot),b),
```

- `q` 直接预测 interval/set/action；允许 DETR matching、ActionFormer/Yuan 边界、CRF/HMM duration 或一般 structured decoder。
- `r` 联合重建 residual/value。
- `D_B` 强制相同预算并含 identity。
- S3 用与候选相同的 paired risk controller；不可认证则返回基座。
- 输入、监督、模型容量、proposal 菜单、候选数和调参预算必须相同。

### 4.4 必做反例

至少完整构造：桥接合并、零阈值不连续、预算 top-K 失败、插入/删除/平移/拆分/合并、同 support 不同 value、无负价日、跨日 episode、S3 多策略选择偏差、长块依赖、恒等策略空洞安全。

每例必须给 `Y/b/Z/预算/候选输出/弱基线/强基线`；若强基线也能处理，则该反例只说明点级方法弱，不说明候选新。

### 4.5 Agent A 输出

保存为 `docs/paper_prep/35a_AgentA_PhaseB_reduction_audit.md`：

```text
0. Object/Algorithm/Theory verdict
1. Frozen specification
2. Strong composite baseline and pseudocode
3. R1-R4 reduction lemmas
4. Counterexample ledger
5. Guarantee audit
6. Formula-level collision table
7. Exact kill proof or one surviving property
8. Next action
```

只允许返回：`REDUCTION PASS/KILL`、`OBJECT KILL-ALGORITHM OPEN`、`THEORY KILL-METHOD OPEN`、`PARTIAL/PIVOT`、`REDUCTION FAIL/PROCEED`。最后一项只表示进入下一闸。

## 5. Agent B：理论对象、定理与反例

### 5.1 最弱假设分层

- A0：策略/候选网格在 S3 前冻结；日级有界损失；S3 与目标同分布且 exchangeable/i.i.d.。
- A1：若扩展弱依赖，明确 `alpha/beta`-mixing coefficient、block length、coupling error 和有效块数。
- A2：有限策略类或明确复杂度；自适应选择有 simultaneous validity。
- A3：episode 提取、matching、loss、budget 均为确定可测映射。
- A4：漂移必须给 density ratio、局部平稳或 drift budget；否则不声称跨分布安全。

起步只用 A0+A2+A3。exchangeability 与 weak-dependence 必须分成两张 theorem sheet。

### 5.2 T0：最低正确性，明确不是创新

对冻结有限策略族构造 simultaneous UCB，选择 `UCB_pi<=epsilon` 中效用最佳者，否则 no-op，证明

```math
\Pr\{R_{rel}(\hat\pi)\le\epsilon\}\ge1-\alpha.
```

T0 默认标记 `KNOWN-FRAMEWORK INSTANCE`。no-op 只证明可行集非空，不能证明存在可认证的非 BASE 策略。

### 5.3 T1：唯一可争取的非平凡门

只选一个方向，不能三个都写成“贡献”：

1. 不可约性/下界：同逐点边缘与残差统计、不同 episode 依赖，导致 Bayes 最优预算动作不同，并对某个明确策略类给正 excess-risk 下界。
2. 严格有限样本优势：paired episode harm 相比最强合法的绝对风险控制组合，得到非平凡的更小半径或样本复杂度；不能只是 paired Bernstein 常识。
3. 弱依赖新保证：在预算化结构动作下给出现有 RCPS/LTT/CSA 不能直接推出的有限样本界，并指出新 lemma。

方向 1 若只能击败逐点方法而一般 structured predictor 可表达，只算问题性质。方向 2/3 若只是 standard concentration、blocking 或 union bound，降级为已有例化。

### 5.4 原子证明义务

每个 theorem sheet 必须写：量词、概率来源、冻结时点、风险分母、有界常数、策略类规模、可计算 `epsilon(n,alpha)`、S3 选择后覆盖、依赖修正、空事件/跨日/tie、非 BASE power，以及每一步属于 identity/known lemma/new lemma/unproved gap。

必须从条件期望和不等式方向复算，不得通过“Ville/betting/conformal”关键词跳步。

### 5.5 排除的伪理论

以下不能计贡献：exact fallback、no-op 可行、连通分量、`<0` 阈值、Hungarian、投影非扩张、预算按定义满足、Hoeffding/Bernstein/union bound、标准 blocking、RCPS/LTT/CSA 换新 loss、手工反例、经验零退化、消融单调。

### 5.6 Agent B 输出

保存为 `docs/paper_prep/35b_AgentB_PhaseB_theorem_sheet.md`：

```text

1. Formal object and information set
2. Assumptions A0-A4
3. T0 statement and proof
4. One T1 statement
5. Proof dependency graph
```

## 6. Agent C：理论导出的方法与最小证伪

### 6.1 方法规格

只有 A/B 未判死才实现：

1. S2 训练结构化 proposal/value 模型并生成有限、非重叠动作菜单。
2. 用 S2 前向交叉拟合产生动作 harm 标签，禁止同样本拟合后自评。
3. 训练条件风险/伤害评分器。
4. 推理时在主预算内选择预测 harm 最小的动作。
5. S3 对预注册有限策略族执行 Agent B 的有效选择；无可认证非 identity 策略时返回基座。

proposal、value、risk scoring 和 S3 controller 必须拆开报告。

### 6.2 四个合成 DGP，真实数据前必跑

- Fragment/Merge：点误差改善但 episode loss 恶化。
- Budget-K：逐点置信度排序不是最优 episode 动作。
- Insert/Boundary：完整漏报与边界偏移，动作必须真实改变输出。
- Reduction/Equivalence：同一有限菜单上穷举绝对风险和相对 harm，检查候选与 risk-table reduction 是否完全同序。

每个 DGP 给 Bayes oracle。前 3 个成功只说明结构化损失必要；第 4 个若等价，直接 `NO-GO`。

### 6.3 强基线

- B0 Identity。
- B1 Point+Value+RC。
- B2 ABS-SET+VAL+RC：同一 `L_ep`、value head 和 S3 controller，是主要 reduction baseline。
- B3 Risk-table reduction：同一动作菜单估计绝对条件风险 `r_a`，用 `r_a-r_identity` 决策。

### 6.4 Decision-equivalence 审计

对每个样本保存并比较：

```text
action_signature
accept_or_abstain
final_24_vector
risk_ranking
certificate_decision
```

报告 exact action/acceptance/certificate agreement 和最大输出差。解析等价立即 `NO-GO`；若动作一致率至少 99%、最大差 `<1e-12` 且配对风险差 CI 含 0，也判经验等价。优化噪声导致的少量差异不算创新。

### 6.5 真实 pilot 的放行与范围

仅当 A 的 reduction 未闭合且 B 有非定义性命题时，允许：

- 数据：LAGO_DE 与 NEM_SA1。
- 基座：Linear 与 GBDT，共 4 个设置。
- 完整日历日；清理 23/25/缺失/重复小时后再切 S1-S4。
- 推理真值置乱/置零后输出 bit-exact 不变。
- 主指标：有界日级 `L_ep`；辅助为完整漏报、假事件、边界、幅值、MAE、正常期 harm、触发和 fallback。
- 统计：moving-block paired-day bootstrap；块长只由 S2/S3 自相关预先确定；主比较 Holm 校正。
- 消融：点损失、绝对风险评分、去 INSERT、去 REPLACE、去 DELETE、去 value、去 S3 门；每项先验证代码路径确实改变动作。

已归档的 `experiments/_archive/retired-methods/06-event-edit-prototype` 不修补复用；Phase C 必须新建目录。

## 7. 三闸裁决

### Gate 1：公式级碰撞

PASS 要求：同信息、监督、动作、预算、损失和假设下，强组合不能保持至少一个核心性质，并有严格分离而非检索空白。

KILL：目标、推理和保证都可还原；或差异仅来自信息/容量/调参不公平。

### Gate 2：理论诚实

PASS 要求：T0 正确且诚实降级；T1 有完整证明或清楚的新 lemma，`epsilon` 可计算且在真实有效样本量下非空泛。

KILL/PIVOT：T1 是换损失、标准 concentration、定义性事实，或只击败逐点稻草人。

### Gate 3：最小证伪

PASS 只意味着允许扩大研究：合成 oracle 出现强组合不能复制的决策差异；4 个真实设置无安全违例；相对 B2 至少 3/4 主事件损失同向且 paired CI 支持；关键动作消融有实际作用。

若解析/经验 decision-equivalence 成立，判 `NO-GO`。数据、泄漏或实现错误只判 `INVALID/BLOCKED`，修复后重跑，不能当科学结论。
